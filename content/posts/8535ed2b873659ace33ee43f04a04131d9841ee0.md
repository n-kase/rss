■【画像】1週間の着回しコーデをイッキ見！

「いつも同じ」を変える！秋の定番7アイテム

HALMEK up 今回着回すのは、白・グレー・黒・ネイビーを中心にした7アイテム。ベーシックな服に、素材感のあるベストやジレを組み合わせて、定番コーデを今年らしく更新します。

1：ネイビーのストライプシャツ

細めのネイビーストライプが爽やかな、ややオーバーサイズのシャツ。裾を出す、インする、羽織ると着方でも変化を楽しめます。／UP select

2：白のプルオーバー

着心地がよく、一枚でも重ね着にも使いやすい白トップス。裾を出してもバランスよく決まります。／UP select

3：シャギーニットベスト

ふわっとした毛足が秋らしく、重ねるだけで旬の表情に。グレーなら大人も取り入れやすい一枚です。／UP select

4：シアー素材の切り替えジレ

黒のきちんと感に、シアー素材で軽やかさをプラス。縦長シルエットですっきり見せにも活躍します。／UP select

5：ユニクロのブラッシュドジャージーワイドパンツ

ラクなジャージー素材ながら、フロントのピンタックできちんと感がある、オンにも使いやすい有能ワイドパンツ。／ユニクロ

6：GUのコージーメルトンスカート

すっきりしたナローシルエットのグレースカート。トップスを替えるだけで印象を変えやすい一枚です。／GU

7：デニム調パンツ

ウエストゴム＆薄手素材で動きやすいデニム調パンツ。休日のラクなカジュアルスタイルに活躍します。／UP select

【1日目】定番の白&times;グレーをシャギーで旬顔に

HALMEK up 白プルオーバー＋シャギーニットベスト＋ユニクロのブラッシュドジャージーワイドパンツ

着心地のいい白プルオーバーに、ユニクロのジャージー素材のパンツを合わせたラクなスタイル。パンツはフロントのピンタックが縦ラインを強調し、きちんと感もあるので、オフィスコーデにも活躍します。

シャギーニットベストを重ねて、秋らしい素材感をプラス。白〜グレーの落ち着いたトーンなら、トレンドも大人っぽく楽しめます。
