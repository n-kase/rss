OllamaがJevライクな意思決定モデルの実行をサポート

AI実行環境のOllamaが Jev と同じアイデアで設計された意思決定モデルの実行をサポートしました。記事作成時点では「 Nimble 」「 Tev1 」「 Tev1:0.8b 」の3種類を実行可能です。

Ollama now supports Jev-style decision models · Ollama Blog

https://ollama.com/blog/ollama-now-supports-jev-style-decision-models

Ollama now supports Jev-like decision models all locally.

Use decision models like Nimble for tasks like ticket triaging, model routing, and content moderation.

ollama pull nimble

Here’s Nimble playing Ollama racer through the new local /v1/systemone API by making decisions in… pic.twitter.com/HPLMmxcTSj

— ollama (@ollama) September 30, 2026

Jevは大規模言語モデル(LLM)とは根本的に異なるアプローチで開発されたAIモデルで、選択肢に対する「判断」と「信頼度スコア」を出力することができます。Jevは適切な用途では高速かつ低コストに実行可能であることから、既存のAIモデルやアプリなどと組み合わせて活用する動きが活発化しています。例えば、AIゲートウェイサービスのOpenRouterはJevを「タスクに最適なAIモデルを判断する」という用途で使用する「Jev Router」を提供しており、既存の自動選択システムと比べて高速かつ高精度な選択システムを実現しています。

どのAIを使うかをJevで自動選択する「Jev Router」が登場、タスク難易度から適切なAIモデルを瞬時に判断可能でOpenRouterの既存ルーターより高精度 - GIGAZINE

また、Jevと同様の仕組みで動作する「意思決定モデル」も続々と登場しており、2026年9月30日にはベンチマークテストでJev超えのスコアを達成した「d1」が登場しました。

ベンチマークでJev超えな意思決定モデル「d1」が登場 - GIGAZINE

新たにOllamaが意思決定モデルの実行に対応したことを発表しました。記事作成時点では「nimble」「tev1」「tev1:0.8b」の3種類がサポートされており、バージョン0.35にアップデートすることで各モデルを実行できます。各モデルの詳細は以下のリンク先で確認可能です。

Nimble

https://ollama.com/library/nimble

Tev1

https://ollama.com/library/tev1

Tev1:0.8b

https://ollama.com/library/tev1:0.8b

OllamaはNimbleを用いて「左もしくは右に移動する」という判断を実行してレースゲームをプレイする様子を公開しています。
