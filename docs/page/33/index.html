    シートの生地は引っかきに強く、防汚・防水性も高い。オプションで生地の変更も可能だ。（山崎 友貴）

    天井の木目パネルにLEDを配置。（山崎 友貴） バンコンのベース車両でベーシックなトヨタ・ハイエースの生産量が伸び悩んでいるため、キャンピングカー市場は現在、製造に苦労している。そんなハイエースの中でも、比較的納車期間が短いということで、昨今増えているのがワイドボディ車ベースのモデルだ。

    レクビィの「SOLAN（ソラン）」には、ハイエースの標準ボディ（標準ルーフ/ハイルーフ）、ワイドボディ・ミドルルーフ、スーパーロングをベースとする4タイプがある。今回取り上げたワイドミドルは、ハイエース・ワゴンGLがベースだ。もともと多人数乗車を身上としているワゴンは、車内スペースにゆとりがあるのが美点だ。その居住スペースを、余すところなく車中泊用に使っている。

    まず、ソランで紹介しておきたいのが、その可愛らしいエクステリアカラー。取材車両はミントグリーンとホワイトのツートーンに塗られており、ボディに合わせてホワイトのスチール調クラシカルアルミホイールとホワイトレタータイヤが奢られている。女性やファミリーにもフレンドリーな外観だ。

    車内は、北欧調のインテリアで統一されている。家具や飾り板に使われているのは、ホワイトウッド調の合板。見た目の風合いが柔らかく、心地よく優しいインテリアとなっている。

    サイドドアから入ると、まずシンクが備わっている。洗いものをするには小振りだが、歯磨きや給水なら実用的に使えそうだ。逆サイドには調理テーブルが。トップには洒落たタイルが張られ、作業スペースは十分に広い。これなら、コンロを置いたとしても調理スペースは残る。

    後部はカギ形にシートが配置され、さらにテーブルを囲むようにセカンドシート1脚がインストールされている。セカンドシートは前向きにするとリクライニングシートになるため、ゆったりと昼寝をしたり読書をするといった使い方ができるのがうれしい。

    後部のシートはマットを並べることで、縦183（最大210）cm、横165cmのベッドに変身。大人2名がゆったりと休むことができる就寝スペースだ。

    車内での快適性をサポートしてくれるのが、標準装備のエアコンだ。後部窓を出窓に改造することで、家庭用の100Vエアコンが装備されている。サブのリチウムイオンバッテリーは300Ah。1日中の使用とはいかなくても、就寝時から明け方までは涼しく寝られそうである。冬もエアコンが活躍してくれるが、FFヒーターも装備されているので、寒冷地はこちらの方が暖かい。

    なお、このソランはペットとの車中泊を考慮したモデルとなっている。シート生地に傷や汚れに強いものを使い、ペットを安心して同乗できる。また運転席と助手席の間に付けるペットベッドをオプションで用意。いつも愛犬と一緒にいたいという飼い主の気持ちに、見事に応えたモデルなのだ。

    それに内外観とも、雰囲気が非常にいい。北欧風のコーディネイトは四季を問わず気持ちが落ち着くし、同時に高級感も備えている。飽きがこないというのも、長く乗りたい人には魅力となるだろう。

    【社説】未成年選挙運動 重い違憲判決、禁止是正を(西日本新聞me)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:00 配信

    西日本新聞 社説 「未成年もこの国をつくる一員」という高校生の訴えが時代遅れの現状に風穴をあけたと言えるだろう。

    18歳未満の選挙運動を禁止する公選法の規定について、東京地裁は先週、違憲判決を下した。

    高校生ら17～20歳の4人が政治的表現の自由を保障する憲法に違反するとして、国に損害賠償などを求めて提訴していた。

    判決は、公選法の禁止規定が「表現の自由」を保障した憲法21条に反するとした。賠償責任は否定した。国会で具体的な検討がなく立法不作為は認めなかった。国は勝訴したことになり、原告が控訴しなければ判決は確定する。

    禁止規定を巡る司法判断は初めてだ。国会は重みを真摯（しんし）に受け止め、未成年でも選挙運動に加われるよう、法改正の議論を始めるべきだ。

    禁止規定は1952年に導入された。当時は小学生らを大量動員した人海戦術で有権者の関心を引こうとした例もあった。子どもを守り、選挙の公正さを保つために規制を急いだ。

    70年以上を経て社会状況は激変した。欧米では未成年の選挙運動を認める国が多い。若者が政治参画しやすい未来を開く画期的な判決だ。

    4人は18歳未満だった当時、選挙で特定の候補者を応援しようとするなどしたが、禁止規定を知り断念した。違反すれば1年以下の拘禁刑か30万円以下の罰金が科され、公民権も停止されるためだ。

    判決は投票権のない未成年でも表現の自由は保障され、禁止規定は「精神的自由に対する直接の制約で、それ自体が重大」として違憲判断に導いた。理にかなっている。

    国は「学業への支障も生じる」と主張したが、説得力に乏しかった。

    選挙運動は自らの関心や価値判断で取り組むもので、スポーツや音楽などの課外活動と変わらない。判決がそう指摘し、禁じる根拠を見いだし難いとした点も、国民の共感を得られるのではないか。

    一方、未成年の使用を禁じる規定は、意に沿わない選挙運動をさせられる可能性があることから合憲とした。自ら応援する意思があるか、線引きの明確化が必要だ。

    若者の政治参画を促すために2015年、選挙権年齢が18歳以上に引き下げられた。高校3年生の一部が有権者となり、学校現場では主権者教育が広がっている。

    だが、10代の投票率は低迷している。教室での学びだけで、18歳に達した途端に「主権者として投票せよ」と求めるのは無理がある。

    選挙運動に参加できれば、実践的に学ぶ機会が増え、政治参画意識も高まるはずだ。

    主権者教育も見直したい。投票行動を促すだけでなく、校則や学校行事など自分たちに関わることを自分たちで決める。そうした経験を小中学校の段階から積み重ねることこそ大切にしたい。

    多くの人は自分が幸せな人生を送っているかどうかにひとかたならぬ関心を寄せ、昨日より今日、今日より明日は幸せになれるよう努力を重ねる。

    ■「ソロ」の人生を選ぶひとたち

    橘玲より ソ・ウングクさまへ

    旧石器時代の閉鎖的なムラ社会で進化してきた人類は、共同体のなかでの評判やステイタスを過度に気にする一方で、家族や友人などとのつながりから幸福を感じるように進化したという進化心理学の説明は説得力があります。

    しかしその一方で、とりわけ第2次世界大戦が終わった1960年代以降(韓国では1987年の民主化以降でしょうか)、「自分らしく生きることは素晴らしい」というリベラルの価値観が支配的になり、地域や宗教などの伝統的な共同体は「自由な人生」の障害と見なされて解体していきました。

    そしていま、欧米や日本・韓国などで家族をもたない(結婚しない)ソロを選ぶひとたちが増えています。

    行動経済学者のピーター・マグロウは『「ソロ」という選択 自分だけの特別な人生を築く』(江口泰子訳/青土社)でソロとシングルを区別し、シングルを「いまは独り身だが、いずれ結婚して家族をもちたいと思っている」こと、ソロを「家族や恋人のような濃密な人間関係は自己実現を妨げるとして、自覚的に独身を選択する」ことと定義しています。

    ■「自分らしさ」と「絆」の狭間で

    このままリベラル化が進み、「自分らしく生きる」を最大化しようとするならば、必然的にソロ化が進み、人間関係は固定的なものから、流動的なアドホックなものに変わっていくのではないかと思います。世界中を旅しながら、リモートワークで収入を得て、その場かぎりの人間関係を楽しむノマドライフはその典型でしょう。

    「冠水路」はナビが自動で避けてくれる？

    大雨や台風などで道路が冠水したとき、頼りたくなるのがカーナビです。

    現在のカーナビはリアルタイムの渋滞情報や交通規制を取得し、状況に応じてルートを変更できるものも珍しくありません。

    【画像】この記事のフォトギャラリーを確認する

    では、走行ルートの先で道路が冠水していた場合、ナビはそれを把握して自動的に避けてくれるのでしょうか。

    各社のナビやコネクティッドサービスを調べてみると、「豪雨・災害情報を表示する」「実際に通行できた道路を表示する」「交通規制をルート探索へ反映する」といった機能は充実しています。

    しかし、「冠水している道路をリアルタイムに検知し、その道路を必ず自動的に避ける」という機能とは必ずしも同じではありません。

    例えばトヨタのコネクティッドナビでは、気象・災害情報を受信すると対象となるエリアを地図上に表示します。現在地や走行ルート周辺が警報の対象となった場合には、災害情報を通知する機能もあります。

    さらにトヨタには「通れた道マップ」（https://www.toyota.co.jp/jpn/auto/passable_route/map/）があり、コネクティッドカーなどの走行実績をもとに、実際に車両が通行した道路を確認できます。

    災害時に「どこが通れたのか」を判断する材料になりますが、「通行実績がある＝現在も安全に通行できる」という意味ではありません。豪雨時には短時間で水位や道路状況が変化する可能性があります。

    つまり、ナビが提供する「災害情報」と「冠水路の自動回避」は分けて考える必要があるのです。

    トヨタ、日産、ホンダ、スバル、マツダはどこまで対応？

    国産メーカーを見ると、提供される情報や機能には違いがあります。

    日産の一部純正ナビでは、VICSワイドから受信した気象・災害情報の対象エリアを地図上に表示できます。NissanConnectではリアルタイム交通情報などを活用したルート探索も提供されています。

    ただし、公式情報を見る限り、「冠水している道路を検知して自動的に回避する」とまでは明記されていません。

    ホンダのインターナビでは、ルートに影響する可能性がある豪雨や冠水、路面凍結、地震などの情報を通知する機能があります。

    また、災害発生時には「通行実績情報マップ」によって、インターナビ装着車が実際に走行した道路を確認できます。

    一方、交通規制を考慮したルート探索と、「冠水」という情報そのものを理由に道路を自動回避することは別です。確認できた公式情報では、冠水地点を必ず自動回避する機能までは確認できませんでした。

    マツダでも、VICSなどを利用した大雨を含む気象・災害情報を確認できます。また、一部の純正ナビでは「冠水注意地点」を地図上に表示する機能も存在します。

    ただし、これはすべての現行マツダ車に共通する機能という意味ではなく、ナビの世代や仕様によって異なります。

    スバルについては、確認できた現行の公式情報では、冠水地点を検知して表示したり、自動的に回避したりする機能を確認できませんでした。

    一方、スバル自身は冠水した道路には進入しないよう注意を呼びかけています。

    各社を比べると、「豪雨や災害を知らせる」「交通規制を反映する」「実際に通れた道路を示す」といった機能はあっても、それらがそのまま「冠水路を自動的に避けてくれる」という意味ではないことが分かります。

    「Y、Yes. I have…」

    「なぜ急にお金の話？」

    最初は聞き間違いかと思ったほどで、ほかの国の審査では一度もなかった問いに、意図がつかめなかったといいます。ところが現地に入ってすぐ、その理由を痛いほど実感することになりました。きっかけは、スウェーデンの物の価格でした。ちょっとしたカフェでのランチや、短い距離のタクシーが、日本の感覚をはるかに超えていたのです。
