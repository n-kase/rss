    写真で自分の歩みを振り返る、夢ふぉとが「教えない授業」を実施(こどもとIT)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 18:00 配信

    写真：こどもとIT（株式会社インプレス） 株式会社夢ふぉとは、一般社団法人HASSYADAI socialと連携し、思い出の写真から自分の歩みを振り返る「アルバムセラピー」を利用した「教えない」授業を2026年6月19日と7月15日に私立日星高等学校と東京都立鷺宮高等学校で実施した。

    【画像】授業の実施前後に行ったアンケート結果

    授業は、HASSYADAI socialが高校生に展開するキャリア教育プログラム「お仕事図鑑」の一環として実施したもの。思い出の写真を手がかりに、過去の出来事やそのときの気持ち、関わってくれた人を振り返る内容で、自分が好きだったことや頑張ったこと、大切にしたいものなどを言葉にする。

    こども家庭庁が2026年4月に公表した「こども・若者総合調査（令和7年度）」では、15歳から19歳の67.7％が「今の自分が好きだ」に肯定的に回答した一方で、32.2％は否定的に回答した。

    夢ふぉととHASSYADAI socialは、自分の歩みを振り返り、自分を支えてきたものを確かめる機会が十分に用意されているとは限らないと考察。社会に出る前に、自分が大切にされてきた記憶や、自分なりに頑張ってきた事実、好きだったことや心が動いた経験を振り返る時間が必要と捉えている。

    夢ふぉとは、写真と思い出を使った自己理解の機会として「教えない授業」を定義。授業だけで若者を取り巻く課題が解決するわけではないとしても、「自分はここまで歩いてきた」と思える機会を提供し、自分の経験や周囲との関わりを出会い直す時間をつくることが狙いだ。

    授業前後にはアンケートを実施。事前アンケートは297人、事後アンケートは247人が回答した。「自分に自信がある」への肯定回答は35.7％から48.0％、「今の自分のことが好きだ」は44.4％から55.9％となった。「自分はここまで頑張ってきたと思う」は57.6％から67.8％、「これからの人生に希望を感じている」は53.2％から60.7％となり、4項目すべてで事後の割合が事前を上回っている。

    アンケートは事前と事後で回答人数が異なり、高校生一人ひとりの変化を追跡した結果ではない。比較対象の非受講群も設定していないため、授業による因果効果や長期的な変化を示すものではなく、日本の中高生全体に一般化できるものでもないとしている。なお、授業全体については85.8％が「満足している」と回答した。

    授業後アンケートの自由記述には、以下のような声が寄せられている。

    ・自分は頑張ったことがないと思っていましたが、写真を見て、自分も頑張っていたんだなと知ることができました

    ・家族が今までたくさん愛してくれていた事がわかったし、今もいろんなところで助けてもらっていると感じることができました

    ・自分に自信がなくなったり、自分で下げてしまったり、ネガティブになってきたら、当時の楽しい写真を見返すこと

    夢ふぉと代表取締役の林 さゆり氏は、アルバムセラピーを届ける思いとして「大切にされていたと気づくことが、周りへの感謝や、自分を大切に思う気持ちにつながってほしい。その土台の上で、自分が何を好きで、何に心を動かされ、どんな人生を歩みたいのかを考えてほしい」と語っている。

    夢ふぉとは、アルバムセラピーの取り組みについて、自分に自信を持ちにくい若者や、将来に希望を見いだせずにいる若者にアプローチする1つの可能性として考えている。今後も高校での実践を重ね、中学生や高校生が思い出から自分自身を知り、将来を考える機会につなげていくという。

    なお、2026年10月23日には、京都府京都市の洛陽総合高等学校で1年生から3年生の希望者約30人を対象に同様の授業を実施する予定だ。

    生命誕生の鍵は「深海の岩石」にあり、40億年前の化学反応が解き明かす生物の起源(Forbes JAPAN)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 18:00 配信

    2 コメント 2 件

    stock.adobe.com（フォーブス ジャパン編集部） 地球上で生命が始まったのは、深海熱水噴出孔と、その周囲の金属のおかげかもしれない。これらの金属は、自力で化学反応を完結させられる最初の単細胞生物が誕生する前に、その化学反応を成立させる助けとなったと見られる。

    『Science Advances』に2026年8月5日付けで発表された研究によると、最初期の単細胞生物は、生命の核心となる化学反応の仕組みを深海熱水噴出孔の環境から得たが、その代謝システムは自律的には完結しておらず、熱水噴出孔に豊富に存在する金属（触媒）の助けを借りることで成り立っていた可能性がある。

    この画期的な研究は、生物学最大の謎に迫るものだ。その謎とは、酵素（タンパク質）が存在しなかった時代に、生物はいかにして生命の化学的プロセスを遂行し始めたのか、というものだ。

    ■2つの系統、2つの解決策

    単細胞生物の2大グループである細菌（バクテリア）と古細菌（アーキア）は、それぞれ独自の方法で、生命の化学反応を遂行するようになった。同じことを行う必要があったのだが、そのために異なる酵素を生み出したのだ。今回の研究では、数百種類の細菌と古細菌の遺伝子を解析し、生命の化学反応がどのように構築されてきたかを調べた。

    細菌群と古細菌群の遺伝子分析を行うことで、地球上のすべての生物の起源とされる「最終共通祖先（LUCA：Last Universal Common Ancestor）」までさかのぼることができる。LUCAは、約40億年以上前に生息し、今日のあらゆる生物に、基本的な細胞機能を伝えたと考えられている生命体だ。

    ある酵素が細菌と古細菌の両方に存在する場合、その酵素はLUCAにも存在していた可能性が高い。一方のグループにのみ存在する場合は、両グループが分岐した後に進化したと考えられる。

    細菌と古細菌が分岐したとき、その生命の根幹となる化学的仕組みはまだ完成していなかった。そして、両グループとも同じ課題に直面し、それぞれが独自の解決策を見いだした。例えば、アミノ酸の一つであるアラニンの合成を助ける酵素は、細菌と古細菌では全く異なる構造をしている。芳香族アミノ酸、葉酸、リボフラビン（ビタミンB2）の合成に関与する酵素についても同様だ。つまり、化学反応そのものは同じであるにもかかわらず、細菌と古細菌は、同じ仕事をするために異なる手段を編み出したのだ。

    ■酵素が存在する前には、金属がその役割を果たした

    現存する生物においては、全ての細胞に、化学反応を加速させる酵素が存在する。酵素がなければ、反応が遅すぎて生命活動を維持できない。もし最初期の細胞が、いかなる酵素も持っていなかったとしたら、何かほかのものが手助けする必要があった。その「何か」こそが、前述した金属だった。

    深海熱水噴出孔の壁を構成するニッケル、鉄、コバルトなどの金属は、化学反応の補助因子として機能する。今回の研究では、これらの金属が関与する37の主要な代謝反応が特定された。

    「Oracle JDK 21」は無償の「NFTC」ライセンスの対象外に、10月「CPU」以降で(窓の杜)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 17:51 配信

    写真：窓の杜（株式会社インプレス） 米Oracleが提供している「Oracle JDK 21」のライセンスが、10月より変更される予定。10月20日に予定されているセキュリティアップデート「Critical Patch Update」（CPU）以降、「Oracle JDK 21」のアップデートは無償の「Oracle No-Fee Terms and Conditions」（NFTC）ではなく、「Java SE OTN」ライセンスで提供される。

    同社は「Oracle JDK 17」より、最新のJavaリリースを許容的な「NFTC」ライセンスで無償提供している。ただし、旧バージョンの更新プログラムは「Java SE OTN」ライセンスでの提供となるのが原則だ。

    このライセンス変更の影響を緩和するため、現行のLTS（長期サポート）版が登場してからの1年間は、直前のLTS版も「NFTC」で提供する“重複期間”が設けられる。しかし、2025年9月の「Oracle JDK 25」（LTS）のリリースから1年が経過し、直前のLTS版である「Oracle JDK 21」の“重複期間”が終了する。今後は「Java SE OTN」ライセンスでの提供となる。

    「Java SE OTN」ライセンスは、個人利用や開発目的の利用であれば無料。一方、商用本番環境でアップデートを利用するには、「Oracle Java SE Universal Subscription」などの購入が必要となる（OCIやOracle製品の一部として提供されている場合などを除く）。同サブスクリプションでは、「Java 21」の商用サポートが少なくとも2031年9月まで提供される。

    つまり、「Oracle JDK」を「NFTC」の下、本番環境で無償利用したいのであれば、「Oracle JDK 25」へ移行する必要がある。「Oracle JDK 25」の更新は、次のLTS版として現在予定されている「Java 29」の1年後にあたる2028年10月まで、「NFTC」で提供される予定。

    なお、「GraalVM for JDK 21」の更新も10月のCPUからは「GraalVM OTN License Including License for Early Adopter Versions」での提供となる。「GraalVM」ユーザーには「Oracle JDK」または「Oracle OpenJDK」への移行が推奨されている。

    窓の杜,樽井 秀人

    Google、GPT-6 Astra対抗の「Gemini 4 Argon」発表の画像（CNET Japan） Googleは10月1日、新しいフロンティアAIモデル「Gemini 4 Argon」を発表した。7月に事前学習の開始を明かしていた次世代「Gemini 4」の名を冠するモデルだ。OpenAIの「GPT-6 Astra」やAnthropicの「Claude Opus 5.5」などと比較した評価では、長時間のソフトウェア開発や業務自動化など多くの項目で上回ったという。

    長時間のソフトウェア開発能力を測る「DeepSWE v1.1」では77.9％で、Opus 5.5の74.2％、Astraの74.1％を上回った。業務を最初から最後までこなせるかを測るZapierの「AutomationBench」も51.3％で、Opus 5.5の42.5％を約9ポイント上回った。Googleが公開した19項目の比較では、Argonが13項目で単独首位だった。一方、コーディングの「FrontierSWE v2」やPC操作の「OSWorld-2.0」ではAstra、ターミナル操作ではOpus 5.5が上回っている。

    まずはサイバーセキュリティ担当者に限定提供

    Argonは、ソフトウェア開発や法務、財務といった企業の知識労働、サイバーセキュリティの複雑な作業を想定する。ただし、当面は誰でも利用できるモデルではない。まずは「Fairwind Program」を通じ、Googleが「信頼できる」とするサイバーセキュリティ担当者に順次提供する。一般向けの公開時期は明らかにしていない。

    Fairwind Programは、同社が9月にサイバーセキュリティ特化の「Gemini 3.8 Flash Cyber」とともに設けた枠組みで、政府機関や重要インフラ事業者などにアクセスを提供する。一部のセキュリティ担当者とGoogle社内チームには、サイバー分野のガードレールを外したArgonも提供する。

    段階的に公開するのは、フロンティア級の能力を安全に提供するためだという。初期利用者からのフィードバックをもとに安全対策を改良し、将来的には開発者や企業、一般利用者にも広げる。本格公開後は、有料APIの利用者や「Google AI Ultra」の加入者への提供を想定する。導入価格は入力100万トークンあたり2ドル、出力100万トークンあたり10ドルで、キャッシュ済み入力は95％引きとなる。

    サイバーセキュリティでは、ソフトウェアの脆弱性を自律的に見つけ、検証し、修正パッチを作るところまでこなせるという。セキュリティ企業のWizは、病院で使われる医療用ソフトウェアから個人情報が漏れる重大な脆弱性をArgonで発見したとしている。脆弱性の修正能力を測る「CWE-bench v1」では、GPT-6 Astraと並ぶ68％だった。

    最大100万トークンを出力、Google社内でも活用

    仕様面では、1回に出力できるトークン数の上限を従来の6万4000トークンから100万トークンへ大幅に拡大した。数十万トークンを生成しながら長時間の推論を続けられるため、複雑なソフトウェア開発などに向くとしている。

    Google社内では、すでに数千人がArgonを利用している。量子コンピューターの研究では、ある処理の「時空間リソース」を従来の基準値から40％改善したほか、データセンターではArgonを使ったエージェントがメモリーの最適化方法を見つけ、300TiB以上を解放したという。C/C++で書かれたコードをRustに移植する作業にも利用し、数万行規模のライブラリから80万行を超えるFuchsiaのZirconカーネルまで対象を広げている。

    推論過程を監視、安全対策も強化

    安全面では、サイバー攻撃や化学・生物・放射性物質・核（CBRN）分野への悪用防止、プロンプトインジェクション対策、意図から外れた動きの監視、システムの堅牢化を進めている。Argonの思考過程と行動を監視し、利用者の意図から外れれば実行を止める仕組みも導入した。

    Googleは、この監視結果をあえてArgonの学習には使わなかったとしている。監視内容を学習させることで、モデル側が監視をすり抜ける方法を学ぶ可能性があるためだ。同社は、AIの推論過程を監視できる状態を維持することが重要だとしている。
