    高血圧を「測る」文化を社会へ――第48回日本高血圧学会総会が目指す未来(Medical Note)

    2026年10月1日 カテゴリー ニュース

    10/1(木) 10:00 配信

    第48回日本高血圧学会総会（先方提供） 日本には約4,300万人の高血圧患者さんがいるとされています。しかし、適切に診断や治療されていない人も多く、十分に血圧をコントロールできている人は全体の約27％にすぎません。こうした状況を変えるため、日本高血圧学会ではさまざまな取り組みを進めています。

    2026年10月10～12日にライトキューブ宇都宮（栃木県宇都宮市）で開催される第48回日本高血圧学会総会では「新時代のネットワーク高血圧学―時空間をつなぐ次世代医療へ」をテーマに、高血圧診療の新たな可能性が議論されます。日本高血圧学会理事長で同総会の会長を務める苅尾 七臣（かりお かずおみ）先生（自治医科大学内科学講座 循環器内科学部門 教授）に、高血圧診療の現状と学会の取り組み、総会に込めた思いについて伺いました。

    ◇「半分の半分」が示す日本の高血圧の課題

    高血圧は日本で最も患者数が多い病気の1つです。全国には約4,300万人の患者さんがいると推定されますが、そのうち約45％は治療を受けていません。治療を受けている約55％の方も良好にコントロールできているのはそのうち約半分です。全体で見ると血圧を十分にコントロールできている人は約27％にすぎません。

    つまり患者さんの半数近くは治療を受けておらず、治療を受けている人の中でも良好に血圧が管理できている人はさらにその約半分となる「半分の半分」という状況です。これが現在の日本における高血圧領域の大きな課題といえます。

    さらに血圧をより低く抑えるほうが予後の改善につながるというエビデンスが蓄積されており、 “高血圧管理・治療ガイドライン2025”では年齢によらず診察室血圧で130/80mmHg未満を目標とした管理が求められています。従来の140/90mmHg未満という基準でも達成できていた人は全体の約27％でしたから、130/80mmHg未満ではその割合はさらに低くなると考えられます。

    特に問題なのはご自身が高血圧であると気付いていない方の存在です。たとえば比較的若い40～50歳代で脳出血を起こした方を調べると80％以上に高血圧の背景があった一方、そのうち80％以上はそれまで血圧を測ったことがないか治療を受けていなかったのです。だからこそ、まずはご自身の血圧を「測る」ことが重要です。病気になって病院に来てからではなく、健康に生活している段階で高血圧を発見し、治療につなげていく必要があります。

    Anthropic、驚異的なハイペースで日常使いに最適な新モデルを発表

    2026年10月1日 カテゴリー ライフスタイル

    本文

    Oct 1,2026 10:00 4,247

    Webb Wright - GIZMODO US ［原文］ （ 岩田リョウコ / GIZMODOライター ）

    Image: Thrive Studios ID / Shutterstock.com

    開発ペース落とそうっていいながらも、バンバン出してくる！

    Anthropicが、かなりのハイペースで新しいモデルをリリースしています。CEOのダリオ・アモデイ氏は、AIの能力向上に安全対策が追いつく時間を確保するため、 業界全体で開発ペースを落とすべきだと訴えていましたが、今週月曜日、「Sonnet 5.5」を発表 しました。 1週間前に Opus 5.5 をリリースしたばかりなのに 。Opus 5.5よりも高速かつ低コストな選択肢という位置づけだそうです。

    どんなモデル？

    Anthropicは 発表 では、

    Opus 5.5が慎重な判断を必要とする複雑な作業向けに設計されているのに対し、Sonnet 5.5は 範囲が明確な日常的タスクやバグ修正、完成度の高い文書・スライド・スプレッドシートの作成で特に力を発揮する。

    と説明されています。さらにClaude 5.5シリーズの3つ目で最後のモデルとなる「Haiku 5.5」も、今後数週間以内にリリースされる予定です。

    OpenAIも先週、 GPT-6 SolとLunaという2つの新モデル を発表しています。こちらも、より大型で高性能なAstraに比べ、軽量でコストを抑えたモデルという位置づけとなっています。

    Advertisement

    Sonnet 5よりかなりパワーアップ！

    Anthropicが月曜日に発表した内容には、AI企業が新モデルを出す際によく見られる、性能向上のアピールもずらりと並んでいます。

    Anthropicによると、前モデルのSonnet 5と比べると、Sonnet 5.5はAIエージェントによる コーディング能力を測る評価でより高いスコアを記録、そして共同作業をする相手としても改善 されているほか、出力速度はSonnet 5より少なくとも30％高速になっているとのこと。そのため、それほど複雑ではないタスクを素早く繰り返し改善していく作業に適しているそうです。

    安全性とAIを人間の意図に沿わせる「アラインメント」について、Anthropicは「Sonnet 5.5は当社モデルの能力の最前線を押し広げるものではない」と説明しています。つまり、新たな安全対策は追加されていないということです。

    しかし、社内でテストしたAnthropicのモデルの中では、Sonnet 5.5がテスト用の隔離環境で脆弱性を積極的に探そうとする傾向が最も低かったとのことです。

    みんなペースを落とすことに賛成しながらも…

    こうして新しいモデルをどんどん出していながらも、CEOのダリオ・アモデイ氏は今月初め、 AI業界に対して開発競争の最前線を急ぎすぎないよう求める 「pace the frontier」という提言 を発表 。この呼びかけにはほかの大手AI企業のトップたちもすぐに賛同しましたが、今のところシリコンバレーの状況を大きく変える動きにはつながっていないというのが現状です。また、先週始まった国連総会でも、 制御不能なAIがもたらすリスク が重要なテーマのひとつとなっています。

    「おでこ」が尖ってる！ 新型90000系ついにデビュー

    新型の90000系を撮影するファンの姿（柴田東吾撮影） 東武鉄道の新形車両90000系が2026年9月26日より、東上線で営業運転を開始しました。

    【キレイ！】これが新型90000系の車内です（写真）

    東武90000系は、東上線沿線を流れる荒川や新河岸川で行われていた舟運に着想を得てデザインされた車両で、「地域と人と未来をつなぐ わたし舟」という考え方でつくられています。高瀬舟に着想を得た先頭部は、下から反り上がった形状で、他の鉄道車両ではあまり見られないデザインです。

    この新形車両が東武東上線の利用者にどのように受け入れられているのか、実際に乗車して確かめてみることにしました。

    今回乗車したのは営業運転開始から3日目のことで、池袋16時46分発の普通森林公園行きに乗りました。ちなみに、初日は土曜日で、臨時列車としてイベント運行が行われただけ。本格的な営業運転は2日目の日中からで、乗車した日は平日の初日に当たります。

    東武東上線の池袋駅は行き止まりの構造（頭端式）のため、到着する列車を真正面から撮影することができます。ホームの端には、90000系を撮影する多くのファンの姿が見られました。

    夕方のラッシュに登場

    4歳年下の女性とデートしていましたが、毎回割り勘にしていたら、割り勘が原因でフラれました。年齢差がある場合、男性がおごるのが普通なのでしょうか？（ファイナンシャルフィールド） デートの食事代を「おごるか、割り勘にするか」は、意見が分かれやすい問題です。特に相手が年下の場合、「年上なのだから多めに払ったほうがよかったのでは」と悩む男性もいるでしょう。

    一方、毎回男性が全額負担するとなれば、交際が続くほど出費も大きくなります。デート代をどちらが負担するかは、年齢だけで決められるものなのでしょうか。本記事では、4歳年下の女性とのデートを例に、年齢差とデート代の考え方について解説します。

    ▼会社員で「年収1000万円」以上の割合は？ 大企業ほど高年収を目指せる？

    年下女性とのデートでも男性がおごるべきとはかぎらない

    年上の男性だからといって、必ず女性におごらなければならないという決まりはありません。実際、デート代に対する考え方は人によって異なります。

    結婚相談所のオーネットが、2026年4月に25～34歳の独身男女373人を対象に実施した「初デート時の食事代支払いに関する意識調査」では、初デートの食事代について「時と場合により対応を考える」が27.1％、「男性が支払うことが基本」が26.0％、「割り勘が基本」が23.9％でした。

    この結果からも、「男性がおごるのが普通」と考える人がいる一方で、割り勘を妥当だと考える人も少なくないことが分かります。

    また、4歳程度の年齢差だけで、どちらが多く支払うべきかを決めるのは難しいでしょう。例えば、34歳の男性と30歳の女性で収入がほぼ同じであれば、割り勘にする方法も考えられます。

    一方、男性の収入が女性よりかなり高い場合や、男性から高額な店に誘った場合は、男性が多めに負担するという考え方もあります。

    そのため、デート代の支払い方を考える際は、年齢差だけで判断せず、収入や店の価格、誘った経緯、2人の関係性なども踏まえることが大切です。

    割り勘でフラれた原因は金額ではなく価値観の違いかもしれない

    「割り勘が嫌だった」と言われても、単純に「女性がお金を払いたくなかった」とはかぎりません。

    なぜなら、デート代の支払い方を、相手の好意や気遣いを判断する材料の一つとして捉える人もいるからです。男性がおごったり、多めに支払ったりする行動を見て、「自分を大切にしてくれている」「楽しませようとしてくれている」と感じる女性もいるでしょう。

    一方で、男性側は「お互い社会人なのだから、平等に負担するのがよい」と考えている場合もあります。こうしたケースでは、問題になっているのは数千円の食事代そのものではなく、お金の使い方に対する価値観の違いだと考えられます。

    前述のオーネットの調査では、異性との食事の支払いで不愉快に思った経験があると答えた人は全体の30.3％で、女性では34.1％に上りました。

    この結果からも、デート代の支払いは、相手との考え方の違いが表れやすい場面の一つといえます。

    そのため、「割り勘にした自分が間違っていた」と決めつける必要はありません。ただし、今後のデートでは、自分の考えだけで支払い方を決めるのではなく、相手がどのように考えているのかにも目を向けることが大切です。
