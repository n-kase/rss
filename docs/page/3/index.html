    観光防災 歩いて考えよう 中山道鳥居峠で15日に初の催し 長野県塩尻市・木曽郡木祖村(市民タイムスWEB)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:40 配信

    観光防災をキーワードにした初のイベントを周知するチラシ（株式会社市民タイムス） 中山道歩きを楽しむ多くの観光客らでにぎわう鳥居峠（長野県塩尻市・木曽郡木祖村境）で、観光防災について考える初のフィールドワーク型イベントが、15日に開かれる。専門家と一緒にトレッキングを楽しみながら危険箇所をチェックし、対策を考える取り組みで、参加者を募っている。

    塩尻市と木祖村の行政や観光団体などでつくる「中山道鳥居峠観光宣伝協議会」が主催する。「観光客でにぎわうのはありがたいことだが、万が一の災害の際にはどうするのか、観光の一歩先を考えなければならない」（塩尻市観光協会）と企画した。県の地域発元気づくり支援金を活用して実施する。

    松本大学観光ホスピタリティ学科地域防災科学研究所の入江さやか教授が講師を務める。参加者は塩尻市の奈良井公民館に集合し、木祖村側へ車で移動した後、鳥居峠の中山道を歩いて災害リスクや避難経路などを確認し、奈良井公民館で意見交換をする。各地の観光関係者に、自分の地域の観光防災について考えるきっかけを提供し、一般の参加者には観光地で災害に遭った場合の行動のヒントを提供する。

    参加費500円（税込み）で、昼食の弁当が付く。定員20人。問い合わせは塩尻市観光協会（電話0263・54・2001）へ。

    株式会社市民タイムス

    課題山積み“戒田ニデック”新体制始動、拡大路線で生じた歪みを修正できるか(ニュースイッチ)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:40 配信

    「ソフトウェア技術開発センター」の本拠地となるニデック新川崎テクノロジーセンター ニデックは29日、新たな経営体制を始動した。不正会計や品質問題への対応に加え、大規模減損処理の検討など課題が山積する中、社長執行役員最高経営責任者（CEO）兼最高技術責任者（CTO）に就いた戒田理夫氏が再建のかじを握る。M＆A（合併・買収）で拡大したグループにソフトで横串を通し、共通基盤の構築やAI（人工知能）駆動型開発などにより再統合を進める考えだ。創業以来の成長モデルを見直し、ハード中心からソフトとソリューションを融合した企業へ転換できるか。“戒田ニデック”の真価が問われる。（京都・阿部未沙子）

    【写真】ニデック社長に就任した戒田理夫氏

    「M＆Aで大きくなってきたため、一気通貫でガバナンス（統治）を通せと言われてもなかなか通らない」。ニデックの戒田社長はグループが抱える課題をこう表現する。同社は10月1日、グループ横断組織「ソフトウェア技術開発センター」を発足する。狙いはソフト開発力の強化だけではない。共通プラットフォーム（基盤）の整備や開発手法の標準化を進め、技術面からグループの団結を図る。

    戒田社長はシステムや開発基盤の分散が、一連の問題の背景の一つとの認識も示す。同センターでは事業部やグループ会社と連携しながら共通基盤の構築を進める考え。柱となるのがAIを活用した開発だ。単なるコード生成だけではなく、要件定義から設計、コーディング、デバッグ、テストに至るまで一貫したAI駆動型の開発を目指す。

    対象領域はモーター制御にとどまらない。「ヒューマノイド（ヒト型）ロボットをやろうと思っても、コンポーネンツは持っているが、システムソフトやAI関連ソフトが要る」（戒田社長）。欧州向け製品ではサイバーセキュリティー対応も不可欠だ。「共通のものを作っていくことが非常に重要なミッションになる」（同）と強調する。

    新たなセンターは日本側40人、インド側60人の計100人体制でスタートする。日本側40人のうち26人は事業部やグループ会社からの兼務者だ。組織の本拠地はニデック新川崎テクノロジーセンター（川崎市幸区）に置くが、各拠点から参加するバーチャル組織として運営する。

    ソフト人材の拡充も急ぐ。ニデック全体のソフト人材は現在約600人。2030年までに800人に増やし、インドも60人から250人規模に拡大する方針だ。外部パートナーを含めて1500人体制を目指す。人材確保に向けてはインドの大学などとの連携も進める。

    センターではモーター制御だけではなく、ソリューションに近いサービスの開発も行う方針。モーターやセンサーから取得したデータを解析し、予知保全や自律制御につなげる仕組みの構築を視野に入れる。

    不正会計や品質問題への対応を進めるニデックにとって、ソフト強化は単なる新規投資ではない。共通基盤とAI駆動型開発を通じてグループに横串を通し、拡大路線で生じた歪みを修正する改革でもある。新センターは、経営再建と次の成長モデル構築の成否を占う試金石となりそうだ。

    4歳年下の女性とデートしていましたが、毎回割り勘にしていたら、割り勘が原因でフラれました。年齢差がある場合、男性がおごるのが普通なのでしょうか？(ファイナンシャルフィールド)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:40 配信

    4歳年下の女性とデートしていましたが、毎回割り勘にしていたら、割り勘が原因でフラれました。年齢差がある場合、男性がおごるのが普通なのでしょうか？（ファイナンシャルフィールド） デートの食事代を「おごるか、割り勘にするか」は、意見が分かれやすい問題です。特に相手が年下の場合、「年上なのだから多めに払ったほうがよかったのでは」と悩む男性もいるでしょう。

    一方、毎回男性が全額負担するとなれば、交際が続くほど出費も大きくなります。デート代をどちらが負担するかは、年齢だけで決められるものなのでしょうか。本記事では、4歳年下の女性とのデートを例に、年齢差とデート代の考え方について解説します。

    ▼会社員で「年収1000万円」以上の割合は？ 大企業ほど高年収を目指せる？

    年下女性とのデートでも男性がおごるべきとはかぎらない

    年上の男性だからといって、必ず女性におごらなければならないという決まりはありません。実際、デート代に対する考え方は人によって異なります。

    結婚相談所のオーネットが、2026年4月に25～34歳の独身男女373人を対象に実施した「初デート時の食事代支払いに関する意識調査」では、初デートの食事代について「時と場合により対応を考える」が27.1％、「男性が支払うことが基本」が26.0％、「割り勘が基本」が23.9％でした。

    この結果からも、「男性がおごるのが普通」と考える人がいる一方で、割り勘を妥当だと考える人も少なくないことが分かります。

    また、4歳程度の年齢差だけで、どちらが多く支払うべきかを決めるのは難しいでしょう。例えば、34歳の男性と30歳の女性で収入がほぼ同じであれば、割り勘にする方法も考えられます。

    一方、男性の収入が女性よりかなり高い場合や、男性から高額な店に誘った場合は、男性が多めに負担するという考え方もあります。

    そのため、デート代の支払い方を考える際は、年齢差だけで判断せず、収入や店の価格、誘った経緯、2人の関係性なども踏まえることが大切です。

    割り勘でフラれた原因は金額ではなく価値観の違いかもしれない

    「割り勘が嫌だった」と言われても、単純に「女性がお金を払いたくなかった」とはかぎりません。

    なぜなら、デート代の支払い方を、相手の好意や気遣いを判断する材料の一つとして捉える人もいるからです。男性がおごったり、多めに支払ったりする行動を見て、「自分を大切にしてくれている」「楽しませようとしてくれている」と感じる女性もいるでしょう。

    一方で、男性側は「お互い社会人なのだから、平等に負担するのがよい」と考えている場合もあります。こうしたケースでは、問題になっているのは数千円の食事代そのものではなく、お金の使い方に対する価値観の違いだと考えられます。

    前述のオーネットの調査では、異性との食事の支払いで不愉快に思った経験があると答えた人は全体の30.3％で、女性では34.1％に上りました。

    この結果からも、デート代の支払いは、相手との考え方の違いが表れやすい場面の一つといえます。

    そのため、「割り勘にした自分が間違っていた」と決めつける必要はありません。ただし、今後のデートでは、自分の考えだけで支払い方を決めるのではなく、相手がどのように考えているのかにも目を向けることが大切です。

    ラーメン店に謎の“手紙”、大量ペットボトル…ネットあ然 “ありがた迷惑”な差し入れに店側困惑(ENCOUNT)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:40 配信

    「『差し入れではない』と思いました」

    ラーメン店の前に置かれた大量の1.5リッターペットボトル【写真：投稿者提供】（ENCOUNT） 熱烈なファンによるものか、それとも、クレーマーによるものか……。ある日突然、ラーメン店の裏手に大量の1.5リットルのペットボトルが置かれ、店のドアには“お節介“とも取れるアドバイスが延々と書かれた手紙が挟まれていた。SNSで明かしたラーメン店の投稿には多くの反響が寄せられていたが、一体何があったのか。店主に詳細を聞いた。

    【写真】いったい誰が？ネットも首をかしげる…ラーメン店に挟まれていた実際の手紙

    「店の裏にお茶置いたり、店の裏のドアに手紙挟んだりするのは辞めてください。これ以上続くようでしたら警察に相談します。防犯カメラも設置します」

    9月23日にSNSに投稿したのは、千葉・木更津市で開店4年目を迎えたラーメン店「麺やギブタンクス」のアカウントだ。投稿には、路上に置かれたペットボトルの数々の画像と、「飲食経営しているギブタンクスファンより」から始まる“店へのアドバイス”を延々と書き連ねた手紙の画像が添えられていた。

    大量のペットボトルが事の発端だ。「最初に発見した時は、正直かなり驚きました。おそらく、深夜から明け方にかけて置かれたと考えています。従業員が作業していたので店の明かりはついていたはずで、直接渡せばいいのにやらなかったということは『差し入れではない』と思いました」と、店主は振り返る。

    ペットボトルは「いっさい飲まずに処分しました。量が多く捨てるのが大変で、正直、気持ち悪かったです」と明かすが、その1週間?2週間後には、店のドアに手紙が挟まれていた。かなりの文量が書き込まれており、「顧客満足度の向上」と題した項目では「食券をせめて受け取るようにしたほうが良い。その時に確実に挨拶できます」、「値段設定を大幅に変えたくなければ、ノーマルの値段で大盛まで無料にする」など、事細かな文言が続いている。

    投稿への反応では「良いこと書いてもらってるじゃないですか」「手紙の意見参考にして改善したほうがいい」と“手紙の主”に理解を示す声もあったが、店主は「内容については改善すべき点もあります。ただ、明らかに事実と異なる点があり、アンチ的要素が強いと感じました」との受け止めを伝える。実際、投稿に対して「言いたいことはわかるけどこれを実践し始めてデカい顔する常連さんがいると思うとやりづらいね」と、店側を気遣う反応もあった。

    今回の投稿をした理由は「匿名で無断で飲み物を置いたり、手紙を挟んだりするのは、従業員並びに建物にお住まいの方にも迷惑がかかるのでやめていただきたいと思ったからです」と店主。たとえ店への思いやりであったとしても、振る舞いによっては“ありがた迷惑”になりうることを、客側も肝に銘じておくべきだ。

    ハリ・弾力ラインを強化 「バイオヒールボ」がJO1 白岩瑠姫をアンバサダーに起用(FASHIONSNAP)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:38 配信

    Image by: FASHIONSNAP（FASHIONSNAP） 韓国オリーブヤングのプライベートブランド（PB）「バイオヒールボ（BIOHEAL BOH）」が、ハリ・弾力に特化した「3Dリフティング」ラインから、「プロバイオダーム™ 3Dリフティング クレンジングオイル」（150mL 2200円）と、「3Dリフティング クリームインバブルセラム」（110mL 2750円）を11月1日に発売する。

    【画像】アンバサダーに就任したJO1の白岩瑠姫

    また、3Dリフティングラインのアンバサダーに、グローバルボーイズグループ JO1の白岩瑠姫を起用し、ヴィジュアルと動画を公開した。

    3Dリフティングは、“ハリ活乳酸菌”と呼ばれる独自成分プロバイオダーム処方をメインに据えるエイジングケアライン。中でも“タンタンクリーム”の愛称で知られる「プロバイオダーム™ 3Dリフティングクリーム」（50mL 3300円）は、累計販売数625万個を超える人気アイテムだ（2018年10月〜2025年10月 オリーブヤングのクリームカテゴリにおけるハリ・弾力ケアに関する商品売り上げ）。

    CJ Olive Young Japan パク ジンス代表は、「3Dリフティングラインはこれまで、クリーム単体を中心に展開していたが、今後はラインナップを拡充する。クリームを塗る前のケアを新たに提案することで、ハリ・弾力悩みにより効果的にアプローチする基盤を整えていく。新アンバサダーや、ヒーローアイテムであるクリームを接点に、ラインでの購入を狙っていきたい」と語った。

    3Dリフティング クレンジングオイルは、ハリ・弾力低下の原因となる角層の糖化に着目。カルノシン配合で、酸化した角層を整え、洗顔後、なめらかな肌印象に導く。このほか、ペプチドや植物由来オイルをブレンドし、洗顔後の乾燥を抑えた。3Dリフティング クリームインバブルセラムは、うるおいケアとハリケアを追求。高密度のクリームバブルが肌に密着し、ベタつかずに肌キメを整える。

    ステージ上では圧倒的な存在感を放ち、”王子様”と称される一方で、作詞・作曲やセルフプロデュースなど、日々のトレーニングや自己管理を怠らないストイックさとプロ意識を持つ白岩さんの、「完成された姿」の裏側にある、日々の小さな努力や積み重ねに着目。“輝いて見える人ほど、見えないところで努力している”、そんな白岩さんの姿勢と、毎日のケアを通じて理想の肌を目指すブランドの価値を重ね合わせアンバサダーに起用した。

    ヴィジュアルは「白岩瑠姫（JO1）さんのON/OFF」「忙しいアイドルのスキンケアルーティン」「朝のハリ感は、夜のケアから。」「翌日の輝き」をベースに、忙しいスケジュールの中で“朝からハリのあるお肌”を保つ秘訣を教えるコンセプトとしている。

    白岩さんは、グローバルボーイズグループJO1のメンバー。JO1は昨年、世界6都市を巡るワールドツアーや初の単独東京ドーム公演も開催し、延べ25万人を動員。今年は初の3大ドームツアーを完走。10月には全米デビュー、北米ツアーも控える。
