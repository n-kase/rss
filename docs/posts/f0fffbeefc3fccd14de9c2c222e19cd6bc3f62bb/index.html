    犬が苦手だったマルチーズ子犬は約6年後→お散歩で会う仲良しのお友達もできて、たくさんの人にかわいがられるコに成長！(いぬのきもち WEB MAGAZINE)

    生後5カ月の太郎くん（Benesse Corporation） 犬が苦手な生後2カ月子犬の成長エピソード

    紹介するのは、X（旧Twitter）ユーザー@sjPZa1PAyWPXBDxさんの愛犬・太郎くん（取材時6才/マルチーズ）。こちらは、太郎くんが生後5カ月の頃に撮影された一枚です。当時の状況を飼い主さんに聞いてみると…

    【画像】6才になった太郎くん！ぐんと大きく重たくなった成長ビフォーアフターに注目！

    飼い主さん：

    「生後2カ月で家に迎えたときから、このキッチンスケールと洗面器で体重測定をしてきました。毎回夜ゴハンの前に量るので、終わったらゴハン！とわかっていて喜んで量らせてくれます」

    そんな太郎くんは約6年後、どんなコに成長したのでしょうか。

    こんなに大きくなりました！

    こちらは6才の誕生日を迎えた太郎くんです。飼い主さんは2枚の写真を見比べて、太郎くんの成長をこのように振り返ります。

    飼い主さん：

    「1枚目の頃は余裕がありましたが、今は大きく育って洗面器にみっちり詰まっている状態です。抱っこしていて重いと感じることもありますが、それが幸せの重さだなぁと思います」

    大きく成長した太郎くん。行動面では、このような成長も見られるようで…

    飼い主さん：

    「ほかの犬が苦手で、多分怖さから先に吠えてしまうコでした。最近は少しずつですが慣れてきて、お散歩で会う仲良しの犬も増えたのは成長だと思います」

    太郎くんは人が大好きなコ！

    人が大好きという太郎くんは、近所の方にもかわいがってもらっているのだそう。

    飼い主さん：

    「特に、以前は犬を飼っていたものの今はご高齢で犬を飼えない犬好きの方にかわいがられます。あまり人見知りしないのは太郎の良いところです」

    また、太郎くんには、こんな特技があると飼い主さんは教えてくれました。

    飼い主さん：

    「トリックをすぐに覚えて賢いと思うのですが、外では全くしないので近所の方に披露できないのが残念です（ベルを鳴らしたり、バーンで寝転んだり、前足をクロスしたり色々できます）」

    わがままなところも愛らしい「子どものようにかわいい存在」

    最後に、飼い主さんにとって太郎くんはどのような存在か、また、これから太郎くんとどのように暮らしていきたいかを伺いました。

    飼い主さん：

    「留守番が苦手で、長くても30分くらいしかさせていないのですが、ゴミ捨てに行った2～3分でも、久々の再会のように喜んでくれます。

    また、太郎の気が乗らないときにお手入れをしようとすると、噛むふりをするなどわがままな面もありますが、それも含めて本当に子どものようにかわいいです。

    私達の子供は成長して家を出ているので、夫婦2人なら寂しかっただろうなと思います。

    健康に気を配りつつ、2人と1匹のお散歩を楽しく続けたいです」

    写真提供・取材協力/@sjPZa1PAyWPXBDxさん/X（旧Twitter）
