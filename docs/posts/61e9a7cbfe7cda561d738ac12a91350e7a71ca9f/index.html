    米アンソロピック「Claude for Government」が正式提供、FedRAMP Highで席料なし(ビジネス＋IT)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 20:50 配信

    米アンソロピックが一般提供を始めた「Claude for Government」（出典：米アンソロピック）（ビジネス+IT） 米アンソロピックは、米国の連邦・州政府機関向けAIサービス「Claude for Government」の一般提供を開始した。米政府のクラウド調達基準FedRAMPで最も厳しい「High」の認可環境で動き、商用版と同等の機能を使える。利用者1人ごとの席料は取らず、上限付きの従量課金とした。

    米アンソロピックは2026年9月30日、米国の連邦政府機関と州政府機関に向けたAIサービス「Claude for Government」の一般提供を始めたと発表した。2026年7月からパブリックベータとして提供してきたもので、米政府のクラウドサービス調達におけるセキュリティ基準であるFedRAMPのうち、最も厳格な「High」の認可を受けた環境で稼働する。

    同社によると、政府機関はコンプライアンス要件を満たしたまま、商用の顧客とほぼ同等の機能を利用できるという。ファイルを直接扱えるClaudeのデスクトップアプリに加え、既存システムの刷新などソフトウェア開発に使うClaude Codeを提供する。スキルやプラグイン、プロジェクトの機能を使えば、メモの作成や提案依頼書（RFP）の審査、個別案件の処理といった行政の業務にも対応できるとしている。

    料金体系にも特徴がある。利用者1人ごとに課金する「席料」は設けず、政府機関は一定の単位で利用量を購入し、超えてはならない上限額を設定したうえで支払う仕組み。管理者はユーザーの区分ごとの設定やモデルごとの利用制限、支出アラートによって費用を管理できる。

    データの扱いについては、会話の履歴は政府機関が管理する端末内にとどまるという。利用状況のエクスポートには利用量の計測データだけを含めるため、運用許可（ATO）の申請や監察総監室からの求めに対し、機密情報を開示せずに対応できるとしている。アプリは政府機関が使う標準的なモバイル端末管理（MDM）の仕組みで配布できる。

    さらに、コマンドライン版のClaude Codeと、Microsoft 365の中でClaudeを使える「Claude for Microsoft 365」も、同じFedRAMP Highの環境で早期アクセスとして順次提供を始める。利用を希望する政府機関は、同社の政府向けページから申し込む。
