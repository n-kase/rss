    円山応挙の国宝《雪松図屏風》が公開。三井記念美術館で「国宝 雪松図と四季」が開催(美術手帖)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 8:08 配信

    東京・日本橋の三井記念美術館で、展覧会「国宝 雪松図と四季」が開催される。会期は12月12日〜2027年1月30日。

    同館で年末年始の恒例となっている、国宝の円山応挙

    （1733〜95）《雪松図屏風》公開。本展では、この《雪松図屏風》をはじめ同館が所蔵する書画・工芸品を中心に、移りゆく四季や気象を表す技法、見立てなどに着目した展示が展開される。

    全5章で紐解く「四季」の表現

    本展は全5章で構成される。「茶道具にみる四季」では、うつわに描かれた草花や焼き物の景色・かたちに季節を見出し、銘によって象徴させた茶道具が取り上げられる。《唐物丸壺茶入

    銘淡雪》（12〜13世紀）や《瀬戸橋姫手水指 銘有明》（16〜17世紀）、応挙の下絵による蒔絵が施された《桜木地茶箱》（18世紀）などが並ぶ。

    「四季と気象を描く」では、画家や作品による気象表現の違いに焦点を当てる。国宝である応挙の《雪松図屏風》（18世紀）をはじめ、白い絵具の塗り重ねや銀砂子で応挙の《雪松図屏風》と対照的な表現を見せる山口素絢の《雪中松に鹿図屏風》（18〜19世紀）、木目を強風に見立てた酒井抱一の《秋草に兎図襖》（19世紀）、湿気を帯びた夏の夜を描いた川端玉章の「京都名所十二ヶ月」より《六月

    四条納涼》（1898）などが紹介される。また、円山派のレパートリーを示す作品として「四季海辺図屏風」4点が初展示される。

    「四季を詠む」では、古来より人々に感興をもたらしてきた詩歌を収めた書を展示。古筆のなかでも「三色紙」として尊ばれる《伝小野道風

    継色紙》（10〜11世紀）、《伝紀貫之 寸松庵色紙》（11世紀）、《伝藤原行成

    升色紙》（11世紀）の3点が同館として約6年ぶりに同時公開されるほか、古典文学にゆかりの深い蒔絵調度も紹介される。

    「四季と暮らし」では、明治の浮世絵師・水野年方による連作「三井好 都のにしき」から、雪景色のなかを出かける女性を描いた《朝の雪》（1904）などが展示される。本連作は、三井呉服店の商品広告も兼ねていたとされ、画中の女性の着用アイテムには当時の流行を見ることができる。

    「四季を束ねる」では、ひとつの画面や1組の作品に春夏秋冬をあしらった作品に着目する。春から秋、昼から夜へのときの流れを金地や金属板で収めた重要文化財《日月松鶴図屏風》（16世紀）のほか、大小の花々を描き込んだ川端玉章の《草花図額》（19〜20世紀）、中国絵画の図像を再構成した狩野栄信の《四季山水図》（19世紀）、異界としての「四方四季の庭」を描いた亀岡規礼の《酒呑童子絵巻》（19世紀）などが一堂に会する。

    東京バーゲンマニア ヘルシー・ロンジェビティ（健康長寿）への関心が高まっている昨今。情報や選択肢が増えるあまり、健康について考えることが負担になってしまう"健康疲れ"に陥る生活者が増えています。

    この問題に着目したネスレ日本は、2026年10月1日に「大人の健康計画」シリーズを発売。いつもの一杯を自分の健康ニーズに合わせて置き換える、頑張らずに始められる新たな健康習慣を提案します。

    9月29日に都内で行われた新製品発表会で、第1弾となるドリンク3種がお披露目されました。

    無理なく楽しく！健康管理の概念が変わる

    東京バーゲンマニア 新シリーズとして登場したのは、「ネスカフェ」と「ミロ」からスティックタイプの3製品。意識しないと不足しがちな栄養成分を、お湯もしくは牛乳を注いで飲むだけで、気軽に摂取できるんです。

    東京バーゲンマニア ●ネスカフェ プロテイン カフェラテ（4本入り375円～）

    1杯につきたんぱく質（4.0g）とビタミンB6（0.70mg）が配合されたカフェラテは、たんぱく質を意識した食事や運動にハードルを感じる人にぴったりです。

    感動したのは、プロテイン特有の粉っぽさや臭みを全く感じない、驚きの飲みやすさ。

    優しい甘みとなめらかな口当たり、そしてコーヒーのコクと苦みがグッと増すような後味。シーンを問わず置き換えられる、上質な味わいです。

    東京バーゲンマニア ●ネスカフェ GABA カフェインレス ラテ（4本入り375円～）

    睡眠や休息の質を高めたい時は、夕方以降の一杯をカフェインレスラテに置き換えてみて。

    カフェイン97％カットのほか、GABA（1本当たり100mg）、ビタミンB6（1本当たり0.70mg）、ビタミンB12（1本当たり0.60μg）を配合。負荷なく、日々頑張る自分の身体を労わることができます。

    じんわりとほぐれるような、ミルクのクリーミーかつマイルドな口当たりと、ほのかな甘み。それでいて、コーヒー本来の香りがゆっくりと続きます。夜のリラックスタイムに飲みたくなる一杯です。

    東京バーゲンマニア ●ネスレ おとなミロ 1日分の鉄分（ネスレ おとなミロ 1日分の鉄分）

    女性にとって特に重要な栄養素のひとつといえば、「鉄分」。食事だけで摂ることはなかなか難しい「鉄分」を、なんと懐かしの「ミロ」を飲むことで手軽に補えるのだとか。

    事業を止めない「究極のバランサー」であれ - Visional 若井氏(ITmedia エンタープライズ)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 8:05 配信

    （写真：ITmedia エグゼクティブ）（写真：ITmedia ビジネスオンライン） 企業の成長に欠かせない、事業スピードとセキュリティ。往々にしてトレードオフと捉えられがちな両者を、セキュリティリーダーはいかに両立させるべきか。

    【その他の画像】

    Visionalグループ全体のITインフラ・セキュリティを統括する若井大佑氏は、自らの役割を「究極のバランサー」と表現する。ガチガチにルールで固めるのではなく、地震の揺れを吸収する免震ダンパーのように、状況に応じて柔軟に対応しながら事業に寄り添い続けるスタンスだ。

    大学時代にプログラミングの面白さに惹かれ、インフラ、そしてセキュリティの領域へ。「何か起きてから動くのでは遅すぎる」という考えのもと、常に半年先、1年先を見据え、必要な打ち手を"引き出し"として備えてきた。その戦略と、ITとセキュリティの垣根をなくす組織づくりについて話を聞いた。

    若井 大佑（WAKAI Daisuke）

    ――ビジョナル株式会社 グループ最高情報セキュリティ責任者 兼 ITプラットフォーム本部 本部長

    1999年、銀行のシステム子会社に入社し、技術開発、インフラ業務に従事。2007年よりソフトバンクBB株式会社（現ソフトバンク）で情報セキュリティを中心としたソリューションの導入・運用やSOC（Security Operation Center）の開設を担当。2015年、セキュリティ戦略部部長に就任。2017年、株式会社ビズリーチに入社し、2019年にCISO兼情報システム本部本部長に就任。2022年8月より現職。

    プログラミングへの興味から「1円の計算ミスも許されない世界」へ

    ――大学卒業後、銀行のシステム子会社に入社されたとのことですが、どのような思いからITの道を選ばれたのでしょうか。

    若井氏： 私が大学に入学した1995年は、まだ世の中にPCやインターネットが広く普及する前の時代でした。しかし、「将来はITが社会の基盤になるだろう」と考え、専門的に学べる学部へ進学し、C言語やJavaなどでプログラミングを4年間がっつりと学びました。

    卒業後の進路を考えたとき、プログラミングが純粋に面白かったので、もう少し続けたい、どうせやるなら1円の計算ミスも許されないようなミッションクリティカルなシステムに携わりたいと考えました。そうした厳しい世界で、システムがどう作られ、どのように運用されているのかを経験してみたくて、銀行のシステム子会社を選びました。

    ――配属は希望どおりの開発部門だったのでしょうか。

    若井氏： いえ、実はインフラの部隊でした。当時は1人1台のPCやメールが普及し始めた頃で、社内LANの構築やオープン系システムへの移行が進むなか、インフラが分かる人材が少なかったのだと思います。

    正直なところ、目に見えないネットワークや裏側の仕組みには食わず嫌いなところがありました。しかし、職場の先輩に恵まれたこともあり、インフラならではの面白さに気づいていきました。

    ――インフラの知識はどのように身につけていきましたか？

    若井氏： 最初は、先輩方に教わりながら、自分で調べて手を動かして覚えていきました。配属されて3カ月ほどでWindows Serverに関するマイクロソフトの資格を取得し、その後もシスコやLinuxなど、20代のうちにかなりの数の資格を取りました。

    資格の勉強は実務とかけ離れていると嫌う人も多いのですが、私は普段使わない機能まで一通り体系的に学べる場として有意義だと考えています。「こんな機能があるんだ」「こんな使い方もできるのか」と知っておくことで、自分の中の"引き出し"が増えるからです。実務で日常的に使うのはごく一部の機能だとしても、いざというときに「あの機能が使えるかもしれない」と思い出せる。この引き出しを増やすという感覚は、今のセキュリティの仕事にも通じています。

    半径75m内で6件の不審火

    81歳女性が住む住宅への現住建造物等放火の疑いで逮捕された土田容疑者。髪はピンク色に染められていた（FRIDAYデジタル） 8月の下旬から9月の初めにかけて、東京都足立区の半径75m内で連続6件の不審火が発生。周囲の住民たちを恐怖に陥れたこの火事を起こした容疑者として逮捕されたのは、すぐ近くに住む、髪をピンク色に染めた男だった。

    ひどい、ドロドロに溶けて……足立区で起きた連続不審火の“凄惨現場”

    一連の不審火は8月24日の夜にポスター2枚が相次いで燃やされたのが始まりだった。その約10日後、9月3日の未明には物置に火がつけられる。このときはすぐ近くに住む男性が「夜中に外が明るい」ことから火事に気づき、119番をすると同時に近所の人たちがバケツや洗面器で水をかけて消火活動に当たったそうだ。

    さらに4日未明から早朝にかけて自動販売機や自転車カバーが燃やされ、さらに木造2階建ての住宅に火がつけられ、この家で一人暮らしをしていた81歳の女性が顔にやけどを負い、病院に搬送される。ついにケガ人が出る事態にまでなってしまった。

    そして、この日の夜に警視庁綾瀬署に現住建造物等放火の疑いで逮捕されたのが土田健一容疑者(58)だった。目撃証言や防犯カメラなどの映像から一連の不審火に関与しているとみられた。

    9月6日の朝8時ごろに綾瀬署の護送口に姿を現した土田容疑者は集まった報道陣をチラッと見ると、そのまま表情を変えることなく護送車に乗り込んだのだった。

    逮捕された土田容疑者とはどのような人物なのだろうか。生まれ育ったのは足立区内の事件があった場所の近くだったようだ。幼少期から彼を知る女性は、「3人兄弟の末っ子でした」と振り返る。

    「ケン坊(土田容疑者)は小さいときは大人しい子でしたよ。でもね、小学校1年とか小さい頃には、よくその辺のゴミとかに火をつけて遊んでいたんです。だから近所のおばさんたちが、『ケンちゃん、そんな火遊びしてると、火事になったら大変だよ』ってよく注意していました。さすがに高学年になるとやめていましたが」

    以前にも逮捕されていた

    送検では表情を変えることなく、淡々と歩いていた（FRIDAYデジタル） その後、土田容疑者は愛知県で働き、家族もできたという。前出の女性が続ける。

    「(土田容疑者の)お母さんが亡くなったときに、久しぶりに帰ってきたんです。その時には2人の子供とお腹が大きくなった奥さんを連れていました。3人のお父さんになるなんて、『ケン坊も立派になったねえ』と声をかけたんですよ。

    でも結局、向こう(愛知)で事件を起こして、離婚して帰ってきたでしょう。帰ってきてからは上のお兄ちゃんと2人で暮らしているんですが、どんな生活をしているんだか。3年ほど前に物干しから落ちた洗濯物がドロドロになったまま、今でもそこに落ちているんですよ」

    「事件」とは’22年3月に愛知県で資材置き場やビニールハウスなどにライターで火をつけ器物損壊の罪で逮捕された事件のことだ。当時、土田容疑者は「妻のLINEに腹が立って、むしゃくしゃして火をつけた」と供述したという。

    4年ほど前に実家に帰ってきてからはどのような生活をしてたのだろうか。別の近所に住む女性はこう話してくれた。

    「よくその辺をフラフラしていましたよ。すぐ近くの中華屋さんで上司のような人と食事をしていたと聞いたので、何か仕事をしていたんだとは思いますが、朝とか夕方とかよくフラフラと歩いていました。

    気になったのはタバコです。タバコを吸いながら歩いているんですが、火がついたままポイ捨てするんです。それが元で火事になったらどうしよう、怖いなと思っていました」

    この女性によると、髪をピンクにしたのは最近だという。

    「私が見たときはオレンジでした。しかもきれいに染まってないし、なんであんな色にしたんだろうねと近所の人とも話したんです。その前は白髪交じりのごく普通のおじさんという風貌でした」

    幼少期から「火遊び」に興味があり、4年前には放火で逮捕されていた土田容疑者。

    警察の取り調べには「まったく身に覚えがありません。1人で散歩していただけです」と容疑を否認しているという。これまでの行いからすればどうしても彼の仕業だと思えてしまうのだが……。真相はどうなのだろうか。

    2026年10月1日 カテゴリー ニュース

    独立行政法人情報処理推進機構（IPA）および一般社団法人JPCERT コーディネーションセンター（JPCERT/CC）は9月28日、NetScaler ADCおよびNetScaler Gatewayの脆弱性について発表した。影響を受けるシステムは以下の通り。

    Citrix NetScaler ADCおよびCitrix NetScaler Gateway 14.1-73.37 より前のバージョンの14.1系

    Citrix NetScaler ADCおよびCitrix NetScaler Gateway 13.1-64.23 より前のバージョンの13.1系

    Citrix NetScaler ADC FIPS ：14.1-73.37 FIPS より前のバージョン

    Citrix NetScaler ADC FIPS and NDcPP：13.1-37.279 より前のバージョン

    ネットワークを構築するためのアプライアンス製品 NetScaler ADC（旧Citrix ADC）およびNetScaler Gateway（旧Citrix Gateway）には、複数の脆弱性（CVE-2026-88771、CVE-2026-88772、CVE-2026-88773、CVE-2026-88774、CVE-2026-88775、CVE-2026-88776、CVE-2026-88777、CVE-2026-88778）が確認されている。

    CISAの情報によれば、CVE-2026-88771とCVE-2026-88772については、世界中で脅威アクターが積極的に脆弱性を悪用しているとの報告・情報があり、今後被害が拡大するおそれがあるため、早急にアップデートを実施するようIPAおよびJPCERT/CCでは呼びかけている。なお、これらの脆弱性を悪用された場合、遠隔の第三者により任意のコードが実行されたり、サービス運用妨害（DoS）の被害を受ける可能性がある。
