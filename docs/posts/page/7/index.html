    メダカを“枯れ葉”で育てたら……（写真：ねとらぼ） メダカの水槽にクヌギの葉を入れてみると……？ 「驚きの結果が出ました」として公開した飼育動画が、YouTubeに投稿されました。動画の再生数は記事執筆時点で3万3000回を超えています。

    【画像】2カ月後

    投稿者は、親子でさまざまな生き物を探して収集・飼育する様子を発信しているYouTuberの森川サンチ（@morikawasanchi）さん。今回は、友人から譲ってもらったメダカの成魚と卵の飼育に挑戦します。

    大きな2つの水槽にカルキ抜きした水をそれぞれ張ったら、譲り受けたメダカの卵をスポンジ製の産卵床ごと導入。ふ化寸前だったらしく、次の日には早くも赤ちゃんメダカが誕生しました。

    餌としてグリーンウォーターを与えながら1週間が過ぎた段階で、あらかじめアク抜きしておいた「クヌギの枯れ葉」を片方の水槽に数枚入れました。葉に含まれる成分が病気の予防に有効な他、表面にいる微生物が餌になるとのこと。あえて片方にだけ入れて、葉っぱの有無がメダカの生育にどれほどの影響を与えるか調べてみます。

    その後赤ちゃんメダカたちはすくすくと成長し、別の水槽で飼っている成魚たちも元気いっぱいの様子。ここで森川さんはさらなる実験を思いつき、成魚用の水槽に産卵床を入れました。

    メダカの飼育を始めてから1カ月。水槽にクヌギの葉を入れたグループと何も入れていないグループを見比べると、前者の方が明らかに大きく育っています。どちらも動きは活発で餌をよく食べる点は同じですが、肉眼でも分かるほどにサイズの差は明確。

    そして森川さんは成魚が産んだ卵を採取。無事に新しい赤ちゃんメダカたちが生まれたので、世話をしている最中に思いついた実験を行うことにしました。今回は息子くんにも協力してもらいます。

    現時点で、森川さんの元にはメダカの成魚と、水槽に何も入れず1カ月育てたメダカ、クヌギの葉を入れて1カ月育てたメダカ、生まれて間もない赤ちゃんメダカの4グループがいます。このうち、赤ちゃんメダカのグループがいる4つ目の水槽にカブトムシ用の枯れ葉を追加。1カ月遅れで生まれたこのグループが、枯れ葉の力でどれほど早く大きくなるのか調べてみます。

    アク抜きした枯れ葉を入れてから十数日が経過した段階で、各水槽の稚魚たちを比較。一番大きい個体を代表として選び出し、観察用ケースに入れました。また、何も入れず育てたメダカのグループからは小さめの個体もケースへ入れておきます。

    3グループの稚魚を横並びにすると、その差は歴然。クヌギを入れて育てたメダカは腹部がパンパンに膨らんでおり、体表には模様が出始めています。また、何も入れずに育てたグループの小さい個体より、1カ月遅れで生まれたグループの方が既に大きいという結果も明らかとなりました。一目瞭然な体格差を前に息子くんは「クヌギの力はヤバイね」と驚きのコメント。

    この比較を行った17日後には、クヌギを入れて育てたグループの中からなんと卵を抱えている個体も現れました。飼育開始から75日が経過した時点で再び比較すると、枯れ葉の効果はより明確に。1カ月遅れで生まれたグループのメダカも、何も入れずに育てたグループと同等かそれ以上の大きさに育っています。

    同チャンネルではこの他にも、森や川、公園、田んぼに囲まれた水路などさまざまな場所で生き物を採取する動画が公開中です。

    秋に「抜け毛」が激増するのはなぜ？ 自宅でやってはいけないNGケアと対策【美容師解説】(オトナンサー)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 21:15 配信

    秋に抜け毛が増えるのはなぜ？（画像はイメージ）（オトナンサー） 10月1日は「頭皮ケアの日」です。秋の深まりとともに、「最近、シャンプーのときやブラッシングのあとに抜け毛が増えた気がする」と悩む人が急増する傾向にあります。実は9月から10月は、1年で抜け毛が激増するタイミングといわれています。

    【画像】「えっ…！？」 これが抜け毛の原因となる“NG行為”です！

    なぜ秋に抜け毛が増えるのか、そしてこの時期にやってはいけないNGケアと正しい対策について、美容室「Grace Avenue」（東京都港区）サロンマネジャーで美容師の原木佳祐さんに聞きました。

    「夏の蓄積ダメージ」が原因で抜け毛に

    Q.なぜ9月、10月は1年の中で最も抜け毛が増える時期と言われているのでしょうか。

    原木さん「季節の変わり目によるホルモンバランスの乱れに加え、7月、8月に受けた『夏の紫外線ダメージ』が、数カ月遅れて一気に現れるからです。

    夏の強烈な紫外線によって毛根がダメージを受けると、本来ならそのまま成長を続けるはずだった髪の毛が、成長をやめて『休止期』に入ってしまいます。休止期に入った髪はすぐに抜けるわけではなく、数週間から数カ月かけて徐々に抜け落ちていきます。

    つまり、『夏の間はそんなに抜けなかったから大丈夫』と思っていても、毛根が受けたダメージは確実に蓄積されており、そのタイムラグとして9月、10月に『遅れてやってくる抜け毛』となって現れるのです」

    美容室や自宅でやってはいけない「NG行動」とは？

    Q.抜け毛が気になる時期に、美容室でのカラー・パーマや、自宅でのスカルプケアで「絶対にやってはいけないNG行動」はありますか。

    原木さん「美容室では『頭皮に負担のかかる施術』、自宅では『熱いお湯と摩擦』が絶対NGです。夏のダメージを引きずった9月・10月の頭皮は非常にデリケートになっているため、以下のような行動は追い打ちをかけてしまいます。

    【美容室でのNG】

    ・頭皮に負担のかかる薬剤・施術

    ブリーチ、ダブルカラー、頭皮にベタ塗りする白髪染めなどは毛根に負担をかけます。また、縮毛矯正や強めのパーマなど、髪を強く引っ張る施術も要注意です。

    ・強すぎるヘッドスパ

    頭皮が傷んだり炎症を起こしたりしている状態での力強いマッサージは、かえって負担になります。

    【自宅でのNG】

    ・42度以上の熱いお湯で洗う

    頭皮の必要な皮脂まで奪い、深刻な乾燥を招きます。

    ・爪を立てたゴシゴシ洗い・強いブラッシング

    弱った頭皮を傷つけてしまいます。

    強く結ぶポニーテールやヘアアレンジも、抜け毛が気になる場合は少し控えた方がいいでしょう。

    美容室のカラーやパーマ自体が直接的な抜け毛の原因になるわけではありませんが、頭皮環境が悪い状態で行うと薬剤がダメージを増幅させてしまいます。秋は美容師にとっても、お客さまの頭皮や髪のコンディションを見極めるのが難しい季節なのです。

    Satoko Katsuyama ■ひとえの素材感や透け感、帯合わせを意識し、場に応じた装いを心掛けています

    京都・西陣の機屋に生まれ、現在は自身のブランドを立ち上げ、着物や帯の制作を行っている勝山さと子さん。「2月の展示会にひとえの発表があるため、昨年はその頃からひとえを着て、秋は10月いっぱい楽しみました」

    先取りひとえを着用する場合は、「帯合わせや小物には季節感を意識し、全体の印象が先走り過ぎないように心掛けています」

    作り手としては、今の時代の気候や暮らしに合ったひとえ用着尺を提案されています。「素材の開発、糸選び、精練を工夫し、例えば一般的に緯糸に使う糸を経糸に用いたりして快適な素材を研究しています。軽やかな『春ひとえ』、涼やかな『ひとえ』、生地に落ち着き感や、深みのある表情を重視した『秋ひとえ』とひとえを細分化し、それぞれの時季に適した作品を制作しています」

    北見雅子さん（裏千家正教授）

    Masako Kitami ■お稽古では5月の連休後から容認される傾向に。無理のない範囲でルールを守ればいいと思います

    衣替えに厳格といわれる茶道の世界でも、昨今の気候などにより少し緩和傾向にあるという見解の北見雅子さん。「最近では5月の大型連休後のお稽古は、ひとえが大活躍です。秋も、9月中旬から10月中旬まで着用しました。この時季に歴代宗匠の恩忌の茶会があるのですが、こうした正式な茶事・茶会には昔ながらの時季の装いを守ります」
