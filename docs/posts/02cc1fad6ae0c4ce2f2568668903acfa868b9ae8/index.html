    歩行中でも目の前の人に気づくとすぐにピタッと止まり、道を譲れる人型ロボットが話題だ。

    米オレゴン州拠点のロボット企業、Agility Robotics（アジリティ・ロボティクス）が、人型ロボットの最新モデル「Digit 5」を発表した。

    Digit 5は、人を検知すると、とっさに自ら回避したり、立ち止まったり、しゃがみ込んだりできる。

    これまで工場や倉庫内の作業において、安全柵が必要だった人型ロボット（ヒューマノイド）だが、人間のそばで働く時代がついにやってくる。

    人を検知すると自ら止まる機能

    Agility Roboticsが2026年9月15日公開した動画によると、二足歩行する人型ロボット Digit 5 の新たな機能はこのようなもの。

    歩いてるときに物陰から出て来た人に気づいたとたん、すぐ止まる。

    この画像を大きなサイズで見る image credit:youtube

    向かい側から歩いてきた人に対し、その場ですぐにしゃがみ込むこともできる。

    この画像を大きなサイズで見る image credit:youtube

    人の存在を認識し、自ら判断して行動を変えるDigit 5。安全のための臨機応変な動きが可能になったのだ。

    Digit 5の発表

    人間のそばで安全に働けるよう設計

    Agility Roboticsが発表した最新人型ロボットDigit 5は、同社にとって、人間のすぐそばで安全に働けるよう設計された初めてのモデルだ。

    この画像を大きなサイズで見る image credit:youtube

    注目の回避や停止、しゃがみ込みという3つの行動は、搭載のAIアルゴリズムと複数の視覚センサーが周囲の人を継続的に監視することで実現した。なお3つの中でどの動きをするかは、Digit 5が自律的に選択する。

    この画像を大きなサイズで見る image credit:youtube

    Agility Robotics最高技術責任者のプラス・ヴェラガプディ氏は、この機能に関して、検知した人間の存在の種類に応じて、さまざまな回避行動を取る複雑な安全動作システムを設計した、と述べている。

    人型ロボットに必須だった安全柵

    今までは、人型ロボットを工場や倉庫で稼働させる場合、ロボットが誤動作で人にぶつかったり、荷物を落下させるリスクをなくすため、物理的な安全柵で囲うのが一般的だった。

    リスク回避のため、人とロボットの動線を柵で完全に分ける方法は確かに安全だ。ただ一方で、ロボットが担当できる作業の幅が狭まるというデメリットもあった。

    たとえば人がパレットを交換するときや、ロボットと人が同じ通路を通るときなどは接触や衝突事故が起こりうるため、毎回ロボットの動きを止めるか、人を柵の外に出すしかなかった。

    だがDigit 5は従来と違い、安全柵への依存を減らす方向で設計された。そのメインとなるのが、米エヌビディア（NVIDIA）社との技術連携だという。

    この画像を大きなサイズで見る image credit:youtube

    Digit 5には、ロボットや医療機器向けの演算装置「NVIDIA IGX Thor」が搭載され、安全性を確保するシステム「NVIDIA Halos」も統合されている。

    ヴェラガプディ氏は、ロボットの演算能力を担うのは主にNVIDIA IGX Thorだとし、機能安全（実用レベルの安全性を実現する技術）としては、最も初期の採用例になると語る。

    Agility Roboticsは、独自の安全機能の開発と並行し、国際標準化機構（ISO）が推進する人型ロボット向けの国際安全規格「ISO 25785-1」の策定にも参加している。…
