GPT-6 Astraを8倍速で動かすUltrafastモードが登場＆トークン上限を引き上げた月額8万4000円のPro 500プランも登場

OpenAIのAI高速処理サービス「 Ultrafast 」で GPT-6 Astra が利用可能になりました。GPT-6 AstraのUltrafastは、標準モードの最大8倍の速度を実現するそうです。

Ultrafast mode | OpenAI API

https://developers.openai.com/api/docs/guides/ultrafast-mode

Ultrafast is available today for GPT-6 Astra in Codex, ChatGPT Work, and the API, with GPT-6.1 Sol coming soon.

To access it in Codex and ChatGPT Work, we’re introducing Pro 500—a new plan with our highest usage limits (25x Plus) and access to Ultrafast. https://t.co/AjmAVwyUQI

— OpenAI (@OpenAI) 2026年9月29日

Ultrafastは2026年8月に GPT-5.6 Solで登場 した高速推論技術で、出力トークン辺りの料金が高くなる代わりに処理速度を挙げる「Fastモード」よりもさらに超高速処理を可能とするものです。 GPT-5.6 Solではプレビュー版が提供されていますが、GPT-6 AstraではUltrafastが広く利用可能となっています。

以下はOpenAI Developersが投稿した標準モードとUltrafastを比較したムービー。同じプロンプトを入力しても、Ultrafastの方が圧倒的に速くコンテンツの生成や質問への回答を出力しているのが分かります。

Ultrafast is our fastest way to build with Astra yet: in Codex, it runs up to 8x faster than Astra Standard and 4x faster than Astra Fast.

Bring your ideas to life as fast as you can type them. pic.twitter.com/FSk8eNRmWz

— OpenAI Developers (@OpenAIDevs) 2026年9月29日

また、以下はロケットを3Dレンダリングして空に飛ばすアニメーションを作成する速度を標準モードとUltrafastで比較したムービー。OpenAIによると、UltrafastはCodexで最大8倍高速なトークン生成(1秒当たり300トークン)を提供し、APIでは最大6倍高速であるとのこと。

This is Ultrafast.

Our premium speed tier, Ultrafast offers up to 8x faster token generation (300 tokens per second) in Codex and up to 6x in the API. pic.twitter.com/ekyzT1vFan

— OpenAI (@OpenAI) 2026年9月29日

使用するには、「response.create」イベントのリクエスト設定時に「model」を「gpt-6-astra」に、「service_tier」を「ultrafast」にすればOK。また、UltrafastはSDKを介したHTTPリクエストもサポートしています。
