【33%OFF】Amazonで「UGREEN FineTrack Pro」がセール中〜ソーラー充電で電池交換不要

2026/09/22

Amazonで、ソーラー充電に対応したUGREENの紛失防止タグ「 UGREEN FineTrack Pro 」が、タイムセールで 33%OFF の 税込1,997円 になっています。

【追記】 このセールは終了しました。また、当サイトのTwitterを フォロー 、またはFacebookの「 いいね！ 」すると、次回のセール情報をタイムリーに受け取れます。 現在開催中のセールはこちら をどうぞ。

ソーラー充電するApple「探す」対応タグ

本体の表面がソーラーパネルになっており、光が当たれば自動で充電される仕組み。一度フル充電すれば最大2年使用でき、ボタン電池の交換もUSB-Cケーブルでの充電も不要です。

Apple「探す」ネットワークに対応し、セットアップも日常の操作もiPhone標準の「探す」アプリだけで完結。専用アプリは不要な一方、iOS専用のためAndroidでは使えません。

IP68の防水防塵と最大110dBのブザーを搭載し、キーリングと一体になった形状。位置情報は最大5人のAppleデバイスと共有でき、家族の荷物や共用の鍵の管理にも使えます。

33%OFFの税込1,997円

Amazonの参考価格は 税込2,999円 で、セール価格は 33%OFF の 税込1,997円 。プライムデーや8月中旬のタイムセールと同じ価格です。

光が当たるだけで勝手に充電されるソーラー式は、バッテリー交換の手間を省けることはもちろん、いざ探すときにバッテリーが切れていた、というリスクを回避してくれるというメリットもあります。
