    SamsungタブレットGalaxy Tab S12シリーズ発表。上位モデルは27万円から、予想以上の値上げでした…（そうこ） Samsungがタブレットの新モデルGalaxy Tab S12シリーズを発表しました。14.6インチの「Galaxy Tab S12 Ultra」と、2年ぶりに復活のプラスモデル「Galaxy Tab S12+」は12.6インチ。

    【全画像をみる】SamsungタブレットGalaxy Tab S12シリーズ発表。上位モデルは27万円から、予想以上の値上げでした…

    両モデルともに10月7日発売。カラバリはグレーのみ。

    発売は10月7日ですが、Samsungの体験ストアGalaxy HarajukuやGalaxy Studio Osakaなど、一部店舗で今日から展示スタートしています。

    両モデル共通で、採用チップはMediaTek Dimensity 9500。MediaTek Dimensity 9400+搭載のGalaxy Tab S11 Ultraと比較し、NPU処理は最大61%、CPU性能は19%、GPU性能は17%向上の全方位的にパフォーマンスをあげています。これとあわせて、3Dベイパーチャンバーが新たな設計で、より効率的に熱を処理。性能に見合って負荷の高いタスクでもオーバーヒートも回避。Adobe PhotoshopやLightroomなど、クリエイティブ系アプリでのタスクを使う人には嬉しいアプデです。

    防水防塵仕様はIP68。スピーカーは4基搭載。メモリは12GB（Ultraの1TBモデルのみ16GB）。容量は256GBから。

    もちろんS Penは同梱で、タブレット上部に磁石でくっつきます。モニター接続のDeXモードや、AirDropにも対応したQuick Share機能もあり。

    その他、外観やチップ以外の基本スペックは、前モデルから大きなアップデートなし。今回は、マイナーアプデと言っていいかと。

    Galaxy Tab S12 Ultra

    バッテリーもカメラもサイズも前モデルからキープで、バッテリー11600mAh、リアカメラ13MP＋８MP。このサイズで厚さ5.1ミリはさすがSamsungです。

    容量オプションは3つ。256GBモデルが27万1490円（税込）。512GBモデルが30万5580円（税込）。1TBモデルが37万3780円（税込）。
