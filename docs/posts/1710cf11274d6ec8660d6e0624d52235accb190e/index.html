    2026-09-30

    Webモーターマガジン編集部

    @ Webモーターマガジン

    PR クラウドファンディング 音楽 ロック ポップス 雑誌

    音楽雑誌『MUSIC LIFE』と自動車雑誌『Motor Magazine』。長年、それぞれの分野において時代を映し出してきた2誌がコラボレーションする、新しい雑誌プロジェクトが始まります。

    Facebook

    タイトルは『GOLDEN M』。テーマは「70s-80s あの頃、僕らを夢中にさせた クルマと洋楽。」

    1970〜80年代を中心に、スーパーカーやF1など当時のクルマ文化と、ロック／ポップスをはじめとする洋楽シーンを、『Motor Magazine』『MUSIC LIFE』が蓄積してきた歴史やアーカイブをもとに再構成します。

    今回のプロジェクトには、『Motor Magazine』を発行するモーターマガジン社と、『MUSIC LIFE』の版元であるシンコーミュージック・エンタテイメントが協力。両誌が長年蓄積してきた写真や記事などのアーカイブを持ち寄り、これまでの自動車雑誌とも音楽雑誌とも異なる一冊を目指します。

    『GOLDEN M』発起人は編集者・河西啓介。自動車雑誌『NAVI』編集部を経て、『MOTO NAVI』『NAVI CARS』などの創刊・編集に携わってきた経験をもとに、「音楽雑誌とクルマ雑誌が一緒に一冊をつくったら面白い」という発想から本プロジェクトを立ち上げました。

    2027年春の刊行に向けたクラウドファンディングは、2026年10月1日18時よりGREEN FUNDINGでスタート。

    支援プランには、雑誌・デジタル版の先行提供のほか、オリジナルグッズ、出版記念イベントへの招待、『MUSIC LIFE』『Motor Magazine』の表紙を使ったカバーアート、撮影体験、スーパーカー体験などを用意しています。
