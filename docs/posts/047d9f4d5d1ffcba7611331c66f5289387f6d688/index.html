    MicrosoftのナディラCEOは言いました。「Copilot、刷新します」

    2026年10月1日 カテゴリー ライフスタイル

    本文

    Oct 1,2026 10:15

    ヤマダユウス型 ( GIZMODOライター )

    Image: Microsoft

    機能充実！

    Microsoft（マイクロソフト）のAIアシスタント Copilot が、 ガラりと変わります 。新しいCopilotは Home 、 Code 、 Autopilot の3カテゴリに分かれて展開されていくようです。

    Home…従来のチャット機能やCoworkが統合された場所。Officeソフトの操作もここから。

    Code…自然言語でアプリやツール開発ができる場所。GitHub Copilotと同じ技術を採用している。

    Autopilot…ユーザーがPCから離れていても自律的に動くAIエージェント。以前は Scout の名称で提供されていた。

    Advertisement

    HomeとCodeについてはFrontier（一般より早期にアクセスできるプログラム）にて今後数週間以内に 順次提供予定 。AutopilotはPrivate Previewにて限られた対象に9月末から提供されます。

    Officeソフト類はOffice in Copilotにより統合され、Homeからアプリを横断して層が可能。ライトな操作ならHomeで完結するし、より深く突っ込みたいならCodeでアプリを開発する、という感じかな？

    MicrosoftのナディラCEOも、大々的に発表しています。

    We’re building Copilot as a new OS for work that spans every model, every form factor, and every task. Today, we’re announcing our biggest update to Copilot to date, bringing four things together:

    · Autopilot: proactive and long-running agent built for the enterprise

    · Code:… pic.twitter.com/W2ClHHkCK3

    — Satya Nadella (@satyanadella) September 25, 2026

    さらに、 Today というコマンドセンターも近日登場予定。メール、カレンダー、Teamsなどの日常アプリを横断するパーソナライズ管理機能のようですね。

    Video: Microsoft Copilot / YouTube

    全体的に ビジネスフレンドリー になった感じがします、新しいCopilot。仕事で使う諸機能との融和はChat GPTやClaudeとの差別化にもなりますし、独自性も強まりました。Microsoftは 人力でプロンプトや画像のチェック もしてるみたいですし、企業からの信頼では他AIフロンティアにリードしていくかもしれません。

    Source: Microsoft
