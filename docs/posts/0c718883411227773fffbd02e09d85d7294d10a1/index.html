    レディー・ガガが「スタッフ募集」のCMに

    映画『プラダを着た悪魔2』のワールドプレミアに出席したレディー・ガガ（2026年4月20日、米ニューヨーク） Photo： Gilbert Carrasquillo / GC Images / Getty Images（COURRiER Japon） ファミリーマートが、レディー・ガガを起用したスタッフ募集のCMを2026年9月25日から全国で放映している。CMでは、ガガがモップ掛けや品出し、レジ打ちをライブさながらの熱量でこなしている。

    【動画】レディー・ガガがレジ打ち！品出し！ 話題のファミマ新CM

    英紙「フィナンシャル・タイムズ」は、世界的スターに30秒間踊ってもらい「ファミマではたらく？」と呼びかけさせたことは、日本企業にとって新たな局面の始まりだと報じる。

    タイのマーケティング専門メディア「ブランド・バッフェ」によれば、世界的スターの起用は通常、新商品の宣伝やブランドの演出が目的だ。だが今回の起用は、ファミリーマートが切実に必要としているパートを募集するためのものだ。

    パート仕事のイメージを塗り替える

    ブランド・バッフェは、この起用が話題づくりにとどまらず、パート仕事を楽しく、多様性に開かれたものとして描き直す試みだと書く。ファミリーマートは9月1日に新ユニフォームを導入し、個性を尊重する身だしなみ基準「ファミマコーデ」も打ち出した。創業45周年を迎え、人が加わりたくなる場所をめざしているという。

    その背景にあるのは深刻な人手不足だ。前出のフィナンシャル・タイムズによれば、2026年7月の有効求人倍率は全産業で1.2倍近くに達し、建設業の一部では7.9倍にのぼった。

    ファミリーマートは国内で約1万人のパート従業員を募集しており、セブンイレブンはその倍ほどを求めている。セルフレジやロボットを導入しても、24時間営業の店舗網を回すには大量の人手が欠かせないと同紙は伝える。
