    「下着姿を見られるかと…」自宅アパートの1階に住む女性をベランダ越しに10回にわたり盗撮 26歳消防士長を懲戒免職(東海テレビ)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 19:08 配信

    3 コメント 3 件

    東海テレビ 盗撮・ストーカーにけんか、名古屋市消防の消防士らが懲戒処分を受けました。

    名古屋市の中消防署の男性消防士長(26)は、自宅アパートの1階に住む女性を、およそ10回にわたってベランダ越しにスマートフォンで盗撮していたということです。

    その後、警察からこの女性に対するストーカー行為の警告書を交付されていて、聞き取りに対して、「日中、室内が見えて女性がいることを知った」「下着姿を見られるかと思い、行為に及んだ」などと話しているということです。

    名古屋市消防局は、極めて悪質で再犯性が高いと判断し、10月1日付けで懲戒免職処分としました。

    このほか、中区錦3丁目で飲酒後に複数の通行人と殴り合いのけんかをした32歳の男性消防士長ら2人も、減給の懲戒処分となっています。
