    アルファロメオの新型限定車発表を記念して、一夜限りのカルチャー＆ナイトパーティを開催【イベント】

    2026-09-29

    篠原政明

    @ Webモーターマガジン

    ニュース アルファロメオ ジュニア トナーレ 特別限定車 ステランティス イベント

    2026年9月24日、ステランティス ジャパンは同社がプロデュースする「アルファロメオ」ブランドのジュニアとトナーレに設定された特別限定車の発表を記念して、東京・渋谷で一夜限りのカルチャー＆ナイトパーティ「アルファロメオ ウナ ノッテ スペチアーレ」を開催した。

    Facebook

    ▶▶▶写真はこちら｜アルファロメオのパーティ【画像8枚】

    ホワイトとシルバーをアクセントに用いた特別限定車

    アルファロメオ トナーレの特別限定車「スポルトスペチアーレ」。

    ステランティス ジャパンは、2026年8月6日にコンパクトSUV「ジュニア」に、そして同年9月24日にミドルサイズSUV「トナーレ」に、それぞれ特別限定車の「スポルトスペチアーレ」を設定して発売した。まずは2台の概要を簡単に紹介しておこう。

    ジュニアのスポルトスペチアーレは、直3の1.2Lターボ＋モーターの ハイブリッド車「イブリダ」がベース。ホワイトとシルバーをアクセントカラーとして採用し、アルファロメオならではのパッションに、クリーンで洗練された印象を添えている。ボディカラーと限定台数は、ブレラレッドが50台、アレーゼ グレーとセンピオーネ ホワイトが各45台の計140台。車両価格は525万円。

    トナーレのスポルトスペチアーレは、直4の1.5Lターボ＋モーターのハイブリッド車「イブリダ ヴェローチェ」がベース。ジュニア スポルトスペチアーレと同様にシルバーアクセントをあしらった専用エクステリアや、ホワイトステッチを採用した上質なインテリアを装備している。ボディカラーと限定台数は、ブレラ レッドが45台、アルファ ホワイトが15台の計60台。車両価格は688万円。どちらの限定車も、詳細に関してはステランティス ジャパンのWebサイトを参照して欲しい。

    斎藤工氏らによるトークショーやDJプレイも展開

    写真左から、黒川進一氏、斎藤工氏、そして田中知之氏によるトークショーも行われた。

    イタリア語で「アルファロメオの特別な夜」を意味する「アルファロメオ ウナ ノッテ スペチアーレ」と名づけられた、一夜限りのカルチャー＆ナイトパーティ。開会前から会場入口や会場内にはブレラ レッドの特別限定車「スポルトスペチアーレ」が展示されており、ギャラリーは記念写真を撮るなど注目度は高い。

    まずはステランティス ジャパンのアルファロメオ ブランドヘッドである黒川進一氏による特別限定車のプレゼンテーション。アルファロメオというブランドや、今回の特別限定車の特徴などについて黒川氏が熱く語る。

    続いて、俳優でありフィルムメーカーでもある斎藤工氏と黒川氏による、イタリア映画やデザイン、ライフスタイルとアルファロメオをテーマにしたトークショー。イタリア映画に登場するアルファロメオ車なども紹介された。さらには音楽プロデューサーの田中知之氏も加わり、なかなか興味深い話も多くトークショーは大いに盛り上がった。

    斎藤氏と特別限定車のフォトセッションの後は、田中氏によるDJプレイやイタリアン フード＆ドリンクの提供など、アルファロメオとイタリアン カルチャーの熱い情熱をタップリと感じさせてくれるナイトパーティ。ギャラリーには若いゲストも多く、会場内のアルファロメオと音楽、そしてイタリアンフードを存分に楽しんでいた。

    田中知之氏によるDJプレイなども行われ、ナイトパーティは大いに盛り上がった。
