    沖縄のアパートで23歳女性死亡、元交際相手につきまとい禁止命令（毎日新聞） - Yahoo!ニュース

    30日午前8時半ごろ、沖縄県宜野湾市嘉数2のアパートで「人が刺されている」と、110番があった。警察が駆けつけたところ、 アパートの外階段で女性が意識不明の状態で倒れており、その場で死亡が確認された。県警は殺人事件と断定。那覇市内でけがをした状態で見つかった元交際相手の男性が何らかの事情を知っているとみて回復を待って聴取する。 男性にはストーカー規制法に基づくつきまとい行為などの禁止命令が出ていた。

    県警によると、亡くなったのは、宜野湾市嘉数2の 座間味凜（ざまみりん）さん （23）。首などに複数の刺し傷があり、司法解剖して死因などを調べる。那覇市内で見つかった男性の近くでは血の付いた刃物が見つかった。

    女性は2025年12月、県警に「別れた彼氏からの電話やLINEをやめさせてほしい」と相談していた。県警はストーカー規制法に基づき、男性に警告。その後も連絡があったため、26年2月に同法に基づく禁止命令を出した。
