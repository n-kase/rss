    Google、お前もか。Pixel 10aが1万2900円の値上げ。9万円超えに

    2026年10月1日 カテゴリー ライフスタイル

    本文

    Oct 1,2026 18:15

    小暮ひさのり ( GIZMODOライター )

    Photo: 小暮ひさのり

    ついに、来てしまった。

    2026年10月1日から、Googleのスマートフォンのベースモデル 「Google Pixel 10a」の価格が変更されました 。

    Image: Google Advertisement

    最安の128GBモデルの価格は、発売当時の7万9900円から9万2800円へ 。

    256GBモデルは、9万4900円から10万7800円へ。どちらも 1万2900円の値上げ となっています。

    うーむ… 発売当初 は、

    この物価高、メモリ高の時代ですが、Pixel 9aと価格据え置きはありがたや…。

    と、感謝し拝みまくったのですが、世界的なメモリ高騰にはやはり抗えなかったのね…。

    でも、 コスパが武器なベースモデルが約10万からは、やっぱちょっとつらい 。

    同じくベースモデルのiPhone 17eは、今や12万4800円からなので、それよりもだいぶ安いのは事実ですが、 もうベースモデルのスマホでも10万円は覚悟しておかないといけない時代 なんだなぁ。

    スマホは今が一番安い。あとで買おうは悪手

    ちなみに、今回値上げとなったのは、Google Pixelシリーズの中でGoogle Pixel 10aのみ。

    今のところ、2ヶ月ほど前に発売された、Google Pixel 11／11Pro／11Pro XL／11 Pro Foldなど、 フラッグシップラインの値段は変わっていません 。

    でも、RAM高騰の流れが落ち着いたという話しもサッパリ聞こえてこないので、今後値上げされる可能性は十分にあります。 もし今後スマホをリニュる意思があるのであれば、年末とかセールとか待たずに、今すぐに動いた方が良いと思いますね。

    待てば待つほど高くなる。いま、そんな時代になってしまったので…。
