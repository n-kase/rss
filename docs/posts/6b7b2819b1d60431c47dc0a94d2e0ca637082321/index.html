    OpenAI、「DevDay 2026」を開催 ～常時稼働エージェント「dots」や「ChatGPT Space」などを発表(窓の杜)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 18:37 配信

    写真：窓の杜（株式会社インプレス） 米OpenAIは9月29日（現地時間）、開発者向けイベント「DevDay 2026」を開催した。「GPT-6.1 Sol」以外にも、20以上もの新機能が発表されている。

    【画像】“質問に答える”だけでなく、接続したアプリの情報を活用しながら自律的にタスクを進める相棒。目標や好みを学習しながら継続的に支援してくれる

    なかでも注目は、常時稼働エージェント「dots」だろう。「dots」は、ユーザーが自分専用のクラウドコンピューター「dot」を作成可能なほか、「GPT-6 Astra」を頭脳にもち、専用のクラウドコンピューターとブラウザーを備える。さらに、クラウド上で動作し続けるため、24時間稼働可能だ。

    “質問に答える”だけでなく、接続したアプリの情報を活用しながら自律的にタスクを進めることが可能で、複数のプロジェクトを並行して処理することもできる。まさにユーザーの代わりに自律的に仕事を進めてくれる相棒と言えるだろう。目標や好みを学習しながら継続的に支援してくれるのが特徴で、キャラクターも愛らしい。

    なお、ユーザーは作業の進捗を確認でき、アプリへのアクセスや実行できる操作も管理できる。ユーザーが操作していない間の自発的な情報収集は、接続アプリの読み取り専用機能に制限されるため、重要な操作には承認を求める仕組みも設けられている。

    提供は対象地域の「Pro」「Business Premium」プランから順次開始される。「Enterprise」などでは、管理者が有効にした場合にベータ版を試用可能だ、」。

    そのほかにも、以下の新要素がアナウンスされた。

    ・Ultrafast：速度を最優先するプレミアムなティア。トークン生成が「Codex」で最大8倍（毎秒300トークン）、APIで最大6倍に高速化する。「GPT-6 Astra Ultrafast」はAPIで提供開始。月額500米ドルの新プラン「Pro 500」と「Enterprise」では、「ChatGPT Work」「Codex」でも利用できる。「GPT-6.1 Sol Ultrafast」も近日中に登場予定

    ・Private Intelligence：ゼロデータ保持と「Private Inference」（プレビュー版）を組み合わせ、企業がプライバシーを守りながらフロンティアAIを利用できる

    ・Codexクラウド：自分のPCやスマートフォンからのリモート操作、クラウドなど、必要な場所で「Codex」を実行できる。すべてのプランで利用可能

    ・刷新された「Codex CLI」：音声チャットに対応。複数のエージェントの進捗を確認できる「/agents」ビューやworktreeの組み込みサポートも追加された

    ・コードレビュー：「ChatGPT」デスクトップアプリに追加。「GitHub」のプルリクエストと「GitLab」のマージリクエストに対応し、不在中に「Codex」がクラウドで初回レビューを進める自動レビューも使える

    ・Codex Security Cloud：新しいコミットの継続的なチェックに加え、「GitHub」リポジトリ全体を指定したスケジュールなどでスキャンできる

    ・Decisions API：あらかじめ決めた有限の回答候補の中から答えを選ばせる“即断”向けのAPI。「Jev AI」のような、文章を生成せず判断だけを素早く返すAIに近い発想だが、テキストだけでなく画像も渡せる。コンテンツの分類、リクエストの振り分け、エージェントの次の行動の選択などに使え、「Luna」の知能をリアルタイムの意思決定に活用可能。限定プレビューで、数日以内に広く公開する予定

    ・Agents APIのコンピューター操作：「Codex」のハーネスをマネージドサービスとして使える「Agents API」が、コンピューター操作に対応した。「Amazon Bedrock」向けの「Bedrock Managed Agents for OpenAI」も発表された

    ・プラグイン拡張機能：サイドバーのプラグイン専用スペース、会話と並行して使えるインタラクティブなパネル、ファイルビューアーなどを、開発者が「ChatGPT」内に構築できる。すべてのプランで利用可能

    ・作成・申請・検索の改善：開発を支援する「Plugin Creator」、刷新された申請フロー、ディレクトリや会話内での表示順位の改善
