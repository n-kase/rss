千鳥・大悟×ディズニープラス『THE ONE SHOT』シーズン2決定「私が一番驚いています」 挑戦者を募集(オリコン)

本文

10/1(木) 9:00 配信

千鳥・大悟×ディズニープラス『THE ONE SHOT』シーズン2決定（C）FANY Studio（オリコン） ディズニー公式動画配信サービス「Disney+ （ディズニープラス）」のスターにて配信中のオリジナルバラエティ番組『THE ONE SHOT』（ザ・ワンショット）。お笑いコンビ・千鳥の大悟が企画・プロデュースし、エグゼクティブプロデューサーを務める同番組のシーズン2制作が決定した。大悟は「なんと、もうシーズン2をやることになりました。私が一番驚いています」とコメントを寄せた。

【動画】『THE ONE SHOT』シーズン2決定、千鳥・大悟コメント映像

日本のディズニープラス初のオリジナルバラエティ番組となる本作は、「映画」と「お笑い」を掛け合わせた新たな笑いの大会。芸人たちが自ら脚本・監督を務めてショートフィルムを制作し、「作品の中に“1つ”だけボケを入れろ」というルールのもと、考え抜いたフリと一つのボケで競い合う。

ディズニーによると、2026年にディズニープラスで配信された日本発のバラエティ作品の中で、配信開始後14日間の視聴実績に基づき、世界・アジア・日本のすべてで視聴数1位を記録。この反響を受け、早くも続編の制作が決まった。

全話独占配信中のシーズン1には、大悟が選んだ堀内健（ネプチューン）、秋山竜次（ロバート）、又吉直樹（ピース）、後藤淳平（ジャルジャル）、山内健司（かまいたち）、天竺川原、じろう（シソンヌ）、国崎和也（ランジャタイ）の8人が参加。3か月をかけて作品を制作し、初代王者の称号「GOLDEN ONE SHOT」を目指して戦った。

シーズン2の出演者や配信時期など、詳細は未定。大悟は「次はどんな芸人が出てくるのか。そのへんは相変わらずまだ何も決まっていません。でも、だからこそ楽しみにしてもらえたらうれしいです」と語り、「もし『我こそは！』という方がおったら、ぜひ私まで連絡ください」と呼びかけている。

また、視聴者に向けて「まだ『THE ONE SHOT』を観たことがないという方も、シーズン2が始まるまでにまだ時間があります。ぜひディズニープラスでシーズン1をお楽しみください」とメッセージを送り、「芸人のみなさん、新しい挑戦待ってます！」と呼びかけている。

■エグゼクティブプロデューサー：大悟（千鳥）のコメント

「THE ONE SHOT」エグゼクティブプロデューサーの千鳥・大悟です。

なんと、もうシーズン2をやることになりました。私が一番驚いています。

世界でも、アジアでも、日本でも、ディズニープラスのバラエティ作品としてたくさんの方に観ていただいているそうで、本当にありがとうございます！

まさかこんなに早くシーズン2をやることになるとは思っていませんでした。

次はどんな芸人が出てくるのか。そのへんは相変わらずまだ何も決まっていません。

でも、だからこそ楽しみにしてもらえたらうれしいです。

もし「我こそは！」という方がおったら、ぜひ私まで連絡ください。

そして、まだ「THE ONE SHOT」を観たことがないという方も、シーズン2が始まるまでにまだ時間があります。ぜひディズニープラスでシーズン1をお楽しみください。

芸人のみなさん、新しい挑戦待ってます！
