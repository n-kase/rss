    【2026年クリスマスコフレ】ボビイ ブラウン：メトロポリタン美術館とコラボ(FASHIONSNAP)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 21:00 配信

    Image by: BOBBI BROWN（BOBBI BROWN） 2026年クリスマスコフレ特集、第45回は「ボビイ ブラウン（BOBBI BROWN）」のラインナップを紹介します。

    Image by: BOBBI BROWN（BOBBI BROWN） ボビイ ブラウンのホリデーは、世界有数の美術館のひとつである、ニューヨークのメトロポリタン美術館（The Met）からインスピレーションを得た限定カラーコレクション。アイコニックなメイクアイテムと、メトロポリタン美術館のアート作品の組み合わせで、エフォートレスな美しさを届けてくれます。さらに、シーズンを祝うためのギフトセットシリーズも登場。

    ボビイ ブラウン 2026年クリスマスコフレ 発売情報

    先行発売日：2026年10月16日（金）※公式オンラインショップのみ

    発売日：2026年10月31日（土）

    アイシャドウ パレット

    ザ メット ホリデイ アイシャドウ パレット Image by: BOBBI BROWN（BOBBI BROWN） ニュートラルなマットやシマーに輝くゴールド、ブラウン、ブロンズなどが揃ったアイシャドウ パレット。アンリ・エドモン・クロスの絵画「星のある風景」のディティールが入っている、限定コンパクトがポイントです。

    ◼️ザ メット ホリデイ アイシャドウ パレット（限定品、1万1000円）

    単色アイシャドウ

    リュクス アイシャドウ リッチ スパークル ローズイリュージョン Image by: BOBBI BROWN（BOBBI BROWN） 瞬時にホリデーの輝きを演出してくれる、ローズカラーのシマーなアイシャドウ。ケースには、アイシャドウパレットと同じ作品の、細部が描かれています。

    ◼️リュクス アイシャドウ リッチ スパークル（限定1色、5940円）

    ・ローズイリュージョン

    ブラッシュ

    ブライトニング ブラッシュ ブラッシュドバーガンディ Image by: BOBBI BROWN（BOBBI BROWN） 頬を自然な血色感で満たし、内側から光を放つようなホリデーの輝きを添えてくれる、3色展開のチーク。限定コンパクトには、グフタフ・クリムトの絵画「メーダ・プリマヴェージの肖像」が描かれています。

    ◼️ブライトニング ブラッシュ（限定2色、各7480円）

    ・ブラッシュドバーガンディ

    ・ブラッシュドピーチ

    リップ バーム

    エクストラ リップ ティンテッド バーム ベアマホガニー Image by: BOBBI BROWN（BOBBI BROWN） フェスティブムードとうるおいが口元に宿るリップ バーム。唇のPHに合わせて自然な血色感が生まれ、保湿成分で唇がふっくらに。クロード・モネの「ひまわりの花束」のディテールを使用した限定デザイン。

    ◼️エクストラ リップ ティンテッド バーム（限定2色、各5060円）

    ・ベアマホガニー

    ・ベアローズ
