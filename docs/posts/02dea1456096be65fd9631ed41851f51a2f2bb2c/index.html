    猪俣周杜 STARTOが契約解除「重大な違反」 「timelesz」7人体制で活動継続、再出発へ(スポニチアネックス)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:25 配信

    28 コメント 28 件

    釈放された猪俣周杜（撮影・郡司 修）（スポーツニッポン新聞社） STARTO ENTERTAINMENTは1日、契約タレントの猪俣周杜との専属契約を9月30日付で解除したと発表した。これに伴い、timeleszは猪俣が脱退し、今後は7人で活動を継続する。

    【写真】釈放された猪俣周杜は車に乗る前に頭を下げた

    同社は猪俣について、本人への聞き取りや事実関係の確認を実施した上で対応を協議。9月29日の取締役会で「猪俣に弊社との専属契約上の重大な違反が認められ、契約に定める解除事由に該当すると判断し、契約解除を決定いたしました」と説明した。

    一方、猪俣は現在、処分保留で釈放され、捜査が継続している段階だとし「刑事上の処分は確定しておりません」と明記。今回の契約解除については「刑事処分とは別に弊社の専属契約に基づき判断したもの」としている。

    また、今回の契約解除は「会社としての経営判断」とし、「その最終判断は他のメンバー7名に委ねたものではなく、かつメンバーに処分の責任を負わせるものではありません」と説明した。

    メンバーについては、今回問題となっている行為を事前に把握しておらず、関与もしていないと説明。「弊社が現時点で確認している限り、これを具体的に予見できるような兆候を認識していた事実も確認されておりません」とした。

    同社はメンバーに契約解除に至った経緯や判断について説明し、メンバーも今回の決定を受け入れたと経緯を明かした。

    STARTO社は「被害を受けられた方に対しまして、改めて心より深くお詫び申し上げます」と謝罪。ファンやスポンサー、関係者、これまでtimeleszの活動を支えてきたすべての人にも「多大なご心配とご迷惑をおかけしておりますことを、重ねてお詫び申し上げます」と改めて謝罪した。

    今後については、今回の事案を「極めて重大な事態」と受け止め、「エンターテイメント業界で活動していくことはファンの皆様をはじめとするご関係の皆様に支えられて初めて成り立つものという基本的な考え方を改めて所属タレント全員に徹底すべく、弊社としての取り組みの拡充を図ってまいります」と方針を示した。

    最後に「以後、猪俣本人および被害にあわれた方への過度な取材および誹謗中傷等はお控えいただきますようお願い申し上げます」と呼びかけた。

    猪俣は、東京都江東区にあるコンビニエンスストアの駐車場の車内で、知人女性の顔面を殴打してケガをさせた疑いがあるとして、傷害の容疑で9月19日に逮捕され、同25日に釈放されていた。
