    2026年6月にベネズエラを襲った大地震で、瓦礫の下に取り残された人々を探し続けた救助犬「 ツナミ 」を覚えているだろうか。

    あれから約3か月。災害現場の第一線から引退したツナミは、今もベネズエラ各地を訪れ、今度は多くの人の心を救っている。

    2026年9月16日、ベネズエラ北西部の都市マラカイボにあるベレダ・デル・ラゴ公園で、ツナミを称える記念像のお披露目が行われた。

    式典にはツナミ本人ならぬ本犬も登場。大勢の人々が見守る中、自分そっくりの像と並んで記念撮影するという、なんとも微笑ましい光景が繰り広げられた。

    地震で活躍した災害救助犬ツナミの銅像が完成

    2026年6月のベネズエラ地震で、瓦礫の下に取り残された人々の捜索に活躍した救助犬「ツナミ」の記念像が完成した。

    2026年9月16日、ベネズエラ北西部マラカイボのベレダ・デル・ラゴ公園で行われた除幕式には、もちろん主役のツナミも出席した。

    View this post on Instagram

    像はツナミが前脚をまっすぐ伸ばして座る姿をかたどったもので、救助犬として着用するハーネスまで再現されている。

    作品を手がけたフィゲロアさんはまだ17歳。若き彫刻家が制作したツナミ像には「希望の守護者」という名前が付けられた。

    View this post on Instagram

    除幕式にはツナミとハンドラーのホルヘ・ビーンズ氏のほか、マラカイボ市長のジャンカルロ・ディ・マルティーノ氏、消防・救助関係者らが出席した。

    自分をモデルにした像の隣で、ツナミは集まった人々の注目を一身に浴び、ちょっぴり誇らしそうな顔をしていたそうだ。

    ディ・マルティーノ市長は除幕式後、 自身のInstagram にこうつづった。

    マラカイボは、真の4本足の英雄を永遠にたたえます

    さらに市長は、ツナミが6月24日の地震だけでなく、トルコやシリアでの国際救助活動でも人命救助に貢献したことにも触れた。

    そして、この像を通して多くの家族に「困難な状況にあっても、希望と助け合いは必ず力になる」ことを思い出してほしいとの思いを記している。

    View this post on Instagram

    虐待を受けていた子犬が救助犬になるまで

    ツナミについては以前カラパイアでも紹介しているのが、その後にわかったことを含めて簡単におさらいしておこう。

    最初は 捨て犬と報道されていた が、ビーンズ氏によると、ツナミはもともと首都カラカスの家庭で飼われていたが、「噛みつくから」と庭につながれたまま、十分な世話を受けていなかった。

    そのため健康状態が急速に悪化し、その家で働いていた女性が、見るに見かねて動物保護協会に匿名で通報した。

    それをきっかけに、ツナミは保護されることになったという。

    その後、APROA（動物保護協会）から連絡を受け、ツナミを引き取ったのが、「災害救助犬チーム訓練センター（ K-SAR ECID ）」の創設者、ビーンズ氏だった。

    K-SAR ECIDは、災害救助犬とそのハンドラーを育成する団体で、ビーンズ氏自身も消防士としての経歴を持っているんだそうだ。

    保護当時のツナミは、生後約9か月。皮膚には多くの傷があり、ビーンズ氏も最初は犬種を見分けられないほどだったそうだ。

    そこで体を洗い、薬や軟膏を使って傷を手当てしていくうちに、ツナミも次第に警戒心を解いていった。

    ツナミは、世話を受け入れれば早く良くなると理解したんです。それで、それほど警戒しなくなりました

    ちなみに、保護された際は「ロメオ」と呼ばれており、現在の「ツナミ」という名前になったのは、ビーンズ氏と暮らすようになってからなんだとか。

    View this post on Instagram

    国内外の災害現場で生存者を捜索

    すっかり元気になったツナミは、ビーンズ氏のもとで、災害現場で生存者を捜す救助犬としての訓練を受けるようになった。

    そして2022年には、ベネズエラ北部のアラグア州で相次いだ豪雨災害に出動。大規模な土石流と洪水に襲われた被災地での捜索活動にあたった。
