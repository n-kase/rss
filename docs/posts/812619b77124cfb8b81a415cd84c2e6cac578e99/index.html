    額・フェイスラインの悩みを解決！50代に似合う「秋のミディアムヘア」3選(Web eclat)

    夏の紫外線や汗、湿気などで、髪のパサつきや広がりが気になる季節の変わり目。秋は髪もきれいに見せたいもの。顔まわりをすっきり見せたり、気になる額を自然にカバーしたり、髪質を整えて扱いやすくしたり。大人の髪悩みに寄り添う、軽やかで洗練されたミディアムヘア。

    【写真】若々しい！50代に似合う「おしゃれな秋の髪型」

    気になる額を自然にカバー！外ハネミディアムヘア

    Web eclat ボリュームアップするように、トップから顔まわりまでレイヤーでつなげるカットでデザインされたミディアムヘア。肩についてハネる長さのIラインシルエットは、やせてきた首もとに添う毛流れで、年齢を感じさせるパーツをカバー。さらにやや薄めの前髪を中央だけにつくることで、額のシワもカバーしつつ、トレンド印象を与えてくれる。

    顔まわりをスッキリ見せる小顔ミディアムヘア

    Web eclat 硬くて多い髪質は、髪を伸ばすことでさらに重く見えやすくなるが、その回避術が顔まわりのカットライン。流し前髪＆サイドを斜めにつながるように、バックからは独立するようにカットすることで、耳が見えるくらいの広がりが生まれて自然と動きのあるひし形フォルムに。顔だちの変化で顔が四角く見えやすくなってきたというお悩み解消にも役立つスタイルだ。
