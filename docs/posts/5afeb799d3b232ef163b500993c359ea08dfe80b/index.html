    タブレットでフォトショップ、待ってました。新型Galaxy TabはSペンで編集できる

    2026年10月1日 カテゴリー ライフスタイル

    本文

    Oct 1,2026 10:30

    はらいさん ( GIZMODOライター )

    Photo: はらいさん

    Samsung（サムスン）からGalaxy タブレットの新製品として、 Galaxy Tab S12+ と Galaxy Tab S12 Ultra が発表されました。

    「外出先でちょっと作業したいけど、ノートPCを持ち歩くほどではないかなぁ。」ってときに便利な大画面タブレットですが、Galaxy Tab S12シリーズは旧モデルの完成度をより高めたタブレットに進化しています。

    Galaxy Tab S12+とGalaxy Tab S12 Ultraでできることは同じ

    Advertisement

    Photo: はらいさん 今回新たに登場した Galaxy Tab S12+ （以下、Tab S12+）と Galaxy Tab S12 Ultra （以下、Tab S12 Ultra）ですが、異なるのはサイズのみで、それぞれできることに関しては同じとのこと。

    そのため、 どちらのモデルが自分にピッタリなのか 、悩む方もいると思いますが、ここで両モデルの主なハードウェアの違いについてまとめてみました。

    Tab S12 Ultraは前モデルのTab S11 Ultraと比較すると、ハードウェア面ではマイナーアップデートですが、プラスシリーズのTab S12+に関しては、 Tab S10+以来のアップグレード になります。

    Tab S12+とTab S10+を比較すると、ディスプレイサイズは12.4→ 12.6インチ に、重さは571g→ 553g に、厚みは5.6mmから 5.3mm に、動画再生時間は最大16時間→ 最大21時間 に向上したため、ハードウェア的にかなり進化していることがわかります。ただ、アウトカメラの超広角カメラは最新モデルには搭載されていないようです。

    Photo: はらいさん

    Tab S12 UltraおよびTab S12+の共通のアップグレードとして、 本体スピーカー も改善されました。

    2つの信号から 4つの信号を発信する4スピーカーのステレオサウンド に進化したため、 Dolby Atmos をオンにした状態で組み合わせて聞くと、映画やドラマをより迫力ある音で楽しめるようになりました。これは嬉しいアップデートです。

    Photo: はらいさん Tab S12 Ultraの14.6インチサイズとなると、アプリを3分割で縦に表示した場合でも快適にマルチタスクをこなすことができます。

    画面上の情報を読み取って、シーンに合わせた提案をしてくれる Now Nudge に関しても、Samsung Galaxt Tabとしては、Tab S12シリーズから使えるようになりました。

    Photo: はらいさん また、Galaxy Tab S12シリーズは、Androidタブレットとしては初めて Adobe Photoshopに対応 、PC版とは異なる大画面タブレットの Tab S 12シリーズに最適化されたUIやUXになっている とのことです。

    もちろん同梱されている Sペン 操作にも対応しているため、併せて使いたいところですね。

    Photo: はらいさん

    ほかにも、Photoshopに触れたことがない人でも簡単に画像編集ができる機能も用意されていて、 AIアシスタント に「こういうことがしたい！」と伝えると色々と教えてくれるため、楽しく学びながら画像生成などもできるとのことです。

    Premium Accessプランは4ヶ月無料 とのことなので、普段あまりPhotoshopを利用しない方も、これをきっかけに画像編集の世界に一歩足を踏み入れてみるのも良いのかなと思いました。

    Photo: はらいさん Tab S12シリーズ向けアクセサリーとして、外付けキーボードも発売されます。 Pro Keyboard に関しては前作同様、 トラックパッド付き です。
