    韓国の年間輸出額 早くも過去最高更新＝9月時点で8千億ドル突破(聯合ニュース)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:39 配信

    釜山港に積み上げられたコンテナ（資料写真）＝（聯合ニュース）（Copyright YONHAPNEWS <転載、複製、AI学習禁止>） 【世宗聯合ニュース】韓国の年間輸出額が初めて8000億ドル（約125兆6700億円）を突破した。

    産業通商部は1日、9月の輸出額が1209億4000万ドルで前年同月比83.5％増加したと発表した。

    月間輸出額が1200億ドルを超えたのは初めて。これまでの最高は今年6月の1022億ドルだった。

    1～9月の累計輸出額は史上初の8000億ドルを突破し、これまで年間で最高だった昨年の輸出額（7093億ドル）を上回り、早くも年間ベースの過去最高を更新した。

    9月の半導体の輸出額は603億ドルで、初めて600億ドルを突破した。
