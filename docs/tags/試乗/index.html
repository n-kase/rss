    コンパクトでも妥協しないファミリーカーのお手本！

    日本でも根強い人気を誇るMINIは、ただオシャレなだけでなく、走りも楽しいクルマとしてお馴染みのモデル。ドリキン土屋圭市も「往年のFRマシンのようだ」と絶賛するほどだ。（佐藤靖彦） ハッチバックの新型は、全部車名がミニ・クーパーになったんだね。それはともかく、いまどき珍しく10年もモデルチェンジしなかったわけだけど、先代も先々代も含めてやっぱりこの大きさだろうな、長く売れ続ける理由は。小さいけどチープじゃないんだよな。コンパクトなのに居住性はいいし、インテリアにしても上質だし。足もよくて、ボディもしっかりしてる。作り込みがうまいよ。

    【写真】このセンターメーターの存在感半端ない！ 画像で見るドリキン絶賛な欧州スポーツ「MINI」の魅力とは

    それは新型でも共通している。今回は一番スタンダードな1.5リッターだけど、普段乗りはこれで十分。3気筒でもパワーは峠を走るのにも不足がないくらいだし、静かだし。アイドリング以外は、言われなきゃ4気筒だと思っちゃいそうだね。

    足は柔らかいんだけど、必要以上にロールさせないから不快じゃない。それにボディ剛性が高いから、逃げることがなくてよく動くし、入力の仕方もいいし、バンプの吸収もうまい。もっとドキドキするようなクルマが欲しければ、JCWを選びたくなるだろうけど、これはこれで、穏やかに楽しめるミニクーパーだよ。

    しかも、これまでにも増して室内の質感も高いし、これなら同乗者から文句が出ることはないだろうね。ドライバーが楽しいだけじゃない、ファミリーカーのお手本みたいなミニに仕上がってる。

    BMWになる前のクラシックミニにも乗ったことはあるけど、ゴーカートそのものっていうか、馬車みたいっていうか、足が全然動かなくて、メシ食ったあとにはとても乗れない感じだった。2007年のGT-Rや昔のタイプRと似たような、あまり乗り心地を考えていないクルマだった。オモチャっぽいところもあったしね。

    それが、BMW傘下になって、ちゃんとしたクルマになったよ。それまでFR一辺倒だったBMWが、あえてFFに挑んだあたりは、オリジナルのミニへのリスペクトを感じさせたけど、それ以外はまったくの別物。ボディ剛性が格段に上がったし、クルマとしての出来は全然変わったよね。

    Photo：堤晋一

    ボルボのコンパクトバッテリEV「EX30クロスカントリー」のRWDモデルに試乗する機会を得た

    ボルボで最もコンパクトなBEV（バッテリ電気自動車）「EX30」のアウトドア仕様となるのが「クロスカントリー（Cross Country）」。その特別仕様車として、RWD（後輪駆動）モデルが加わった。

    これまで日本に導入されていたEX30 クロスカントリーはツインモーターによる四輪駆動のみだったが、シングルモーターの後輪駆動が選べるのは初めて。価格はグレード名を改め、ツインモーターの「Ultra P8 AWD Electric」が649万円なのに対し、今回のシングルモーターで後輪駆動の特別仕様車「Ultra P5 Long Range Electric」は599万円で、50万円も安いプライスで導入された。

    EX30の2027年モデルは、グレード名の変更のほかにも、いくつかのトピック（変更）がある。ベーシックなグレードとして設定されていた「EX30 Plus Single Motor」は廃止。内装はブリーズインテリアが廃止された代わりに、柔らかなベージュのハーベストインテリアが追加され、外装色にはP8 AWDに爽やかなクラウドブルーが追加された。

    今回試乗したのは後輪駆動の特別仕様車「EX30 Cross Country Ultra P5 Long Lange Electric」

    ボディサイズは4235×1850×1565mm（全長×全幅×全高）、ホイールベースは2650mmで変更はなし。ただし、モーターが1個になったので車両重量は1790kg（AWDは1880kg）

    さらに、UX（ユーザー・エクスペリエンス）は、Android Ver15が導入され、インフォテイメント系の表示内容や使い勝手が改善された。EX30はソフトウェアのアップデートでクルマの機能を進化させていくSDVではあるが、クルマの機能と向き合う上でフラストレーションを感じていた点をモデルライフ中に細やかに改善してみせるスピード感は、既存のエンジン車とは違う世界にあるのだと実感させられる。

    OTA（Over The Air）アップデートが頻繁に行なわれ、常に最新のソフトウェアを享受できるのもポイント

    今回試乗した後輪駆動の特別仕様車「Ultra P5 Long Range Electric」は、四輪駆動モデルと比較して、モーターが1つ減ってはいるものの、それ以外の装備面は何も削られていない。

    エクステリアにおけるクロスカントリーの特徴として、フロントフェイスには黒い樹脂製のパーツを大胆にあしらっているが、そこにはスウェーデンの最高峰「ケブネカイセ山」の等高線と座標が描かれているのも変わりなし。19インチのマットブラック塗装の専用ホイールには外径が大きい235/50R19サイズのタイヤを装着している。

    フロントとリアのバンパー下部はヴェイパーグレーとなる

    クロスカントリー専用のフロントシールドは、スカンジナビア山脈北部にあるスウェーデンの最高峰「ケブネカイセ山」周囲の標高線をトポグラフィーで描くとともに座標（67°54'0"N,18°31'0"E）も刻まれている

    フロントシールドと同じくリアのテールランプの間もブラック仕上げとなる

    新たに「P5 Long Range」のプレートがあしらわれる

    フロンク（フロント＋トランク）を備える

    Cピラーと専用リアバンパーの下部に「CROSS COUNTRY」の文字が配される

    ボディサイズは全長4235mm×全幅1850mm×全高1565mm。地上高を高めたクロスカントリーは全高が1550mmに制限される機械式駐車場には収まらないものの、全幅は1850mmのパレット内にかろうじて収まるため、高さに余裕のある機械式駐車場ならマンション住まいでも現実的な選択肢になりそうだ。

    一方、背が低いタイプのEX30は全高を1550mmに抑えてくれていることで、現時点で日本で販売されているBEVとしては、日本の一般的な機械式駐車場に収まる数少ないモデルの1つといえる。

    クロスカントリー専用の19インチホイール（7.5J）は、5スポークでカラーはマットグラファイト/マットブラック。装着タイヤはグッドイヤーの「エフィシェントグリップ パフォーマンス SUV」でサイズは前後とも235/50R19。また、ダークカラーのホイールアーチ・エクステンションで力強い印象を際立たせている
