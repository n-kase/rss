    AllUnity、欧州規制準拠のドル建てステーブルコイン「USDAU」を発行開始(NADA NEWS)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:00 配信

    AllUnity、欧州規制準拠のドル建てステーブルコイン「USDAU」を発行開始（Image via NADA NEWS.） ドイツのステーブルコイン発行体AllUnity（オールユニティ）は9月30日、米ドル連動型ステーブルコイン「USDAU」の発行を開始した。

    同社が発行する法定通貨裏付け型の銘柄としては、ユーロ連動型の「EURAU」、スイスフラン連動型の「CHFAU」、スウェーデンクローナ連動型の「SEKAU」に次ぐ4種類目となる。

    USDAUは、EU（欧州連合）の暗号資産市場規則（MiCA）に準拠したトークンであり、分別管理された準備金によって1対1で裏付けられ、6つのブロックチェーン上で展開される。

    今回の新規発行は、欧州の政策当局においてドル連動型ステーブルコインの優位性がもたらす影響について議論が交わされるなかで実施された。

    CoinGeckoのデータによると、約2910億ドル（約45兆6870億円、1ドル=157円換算）規模のステーブルコイン市場のうち、99%超をドル連動型が占めている。欧州中央銀行（ECB）も今年6月、ドル建て銘柄の普及がトークン化金融市場におけるユーロの役割を低下させかねないと警告していた。

    こうした見方に対し、AllUnityのアレクサンダー・ヘプトナー（Alexander Höptner）CEOは、「欧州が懸念しているのはドルという通貨そのものではない。監督が及ばず、確実な償還権や準備金の透明性も担保されていないオフショア発行体を通じて、ドルの流動性が流入していることだ」と反論している。そして、USDAUはドルの流動性を欧州の厳格な規制下に置き、域内企業の貿易や国際決済を支援していくと述べた。

    欧州の規制に準拠したドル連動型ステーブルコインは、Tether（テザー）のUSDTやCircle（サークル）のUSDCの有力な代替手段になり得る。ただし現状として、同社が発行するEURAUの時価総額は約40万ドル（約6280万円）にとどまっている。

    なお、日本国内においても今年6月、外国発行の信託型ステーブルコインの流通を解禁する改正内閣府令が施行されるなど、各国の規制整備が進みつつある。

    10月6日のGlamsterdam控え、イーサリアムETF純流入は8.5億ドル規模へ【価格分析】(NADA NEWS)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:31 配信

    10月6日のGlamsterdam控え、イーサリアムETF純流入は8.5億ドル規模へ【価格分析】（Image via NADA NEWS.） デリバティブの活発化がリスク選好の再燃を示唆し、イーサリアムは2,745ドルに上昇

    9月29日火曜日、トレーダーが無期限先物市場全体でエクスポージャーを引き上げたため、イーサリアムは約1%上昇して2,745ドルとなった。

    この動きはイーサリアム先物未決済建玉の約7億ドルの増加と一致しており、ETHが直近の調整からの回復を試みる中で市場参加が広がっていることを示唆している。

    イーサリアムのデリバティブデータは以下の通りである：

    未決済建玉の増加は、イーサリアムが2,745ドルに向けて回復する過程で、より多くの先物契約が決済されずに維持されたことを意味する。

    ただし、ロング/ショート比率は1をわずかに上回る程度にとどまり、デリバティブ市場は比較的均衡を保っていた。

    清算データからも、過去24時間においてショートトレーダーがロングよりもやや多くの損失を被ったことが示された。

    イーサリアムの総清算額は8,317万ドルに達し、そのうちロングポジションが3,816万ドル、ショートポジションが4,501万ドルを占めた。

    この数値は、ETHの価格上昇によってより多くのショートポジションが強制決済されたことを示しているが、大規模なショートスクイズと呼べるほどの開きではない。

    一方、米国のイーサリアム現物ETFも引き続き資金を引き寄せている。

    Farside Investorsのデータによると、イーサリアムETFは9月28日に1,710万ドルの純流入を記録し、連続流入記録を7営業日に更新した。

    この7営業日の連続記録には、9月18日の1億4,370万ドルの流入に加え、その後の各取引セッションにおける2億7,000万ドル、1億6,220万ドル、1億450万ドル、6,610万ドル、8,700万ドル、170万ドルの流入が含まれている。

    これにより累計純流入額は約8億3,500万ドルに達し、8億5,000万ドルの大台到達が視野に入った。

    直近の資金流入の内訳では、ブラックロックのETHAが1,540万ドルを占め、21シェアーズのTETHが170万ドルを追加した。

    デリバティブトレーダーがポジションを再構築する中で、持続的なETF需要は現物市場参加のもう一つの有力な源泉となっている。

    Glamsterdamの10月6日Sepolia稼働に向けてイーサリアムの市場心理が改善

    開発者が次の大型ネットワークアップグレードの準備を進める中、イーサリアムへの市場参加も改善を見せている。

    Glamsterdam（グラムスターダム）は10月6日にSepoliaテストネットで稼働する予定であり、メインネットでの稼働は確定日こそ定まっていないものの2026年第4四半期を目標としている。

    このアップグレードはイーサリアムの実行層および合意形成層に焦点を当てており、スケーリング、ブロック構築、トランザクション処理の向上を目的とした変更が盛り込まれている。

    最も重要な変更点の一つが、プロトコル組み込み型の提案者・作成者分離（ePBS：enshrined proposer-builder separation）である。

    この変更により、専門のブロックビルダーとバリデータ間の受け渡しがイーサリアム自体のプロトコル内へと移行する。

    これにより、外部ミドルウェアへの依存を減らしつつ、ブロック構築のためのより標準化されたメカニズムが構築される。

    また、Glamsterdamではブロックレベルアクセスリスト（BAL：block-level access lists）も導入される。

    これらのリストはブロック内でアクセスされたアカウントやストレージの場所を記録し、トランザクション処理中にイーサリアムのステートのどの部分にアクセスする必要があるかをクライアントが特定するのを支援する。

    さらに、イーサリアム上でのデータ作成およびアクセスのコストをより適切に反映させるため、ガス料金設定の改定も含まれている。

    イーサリアム開発者は、HoodiテストネットやイーサリアムメインネットにおけるGlamsterdamの稼働日をまだ確定していない。

    したがって、10月6日のSepoliaでの稼働はメインネットのアップグレードではなく、テスト段階のマイルストーンを意味する。

    現在の市場反応はメインネットの即座な変更ではなく、イーサリアムの開発ロードマップに対する期待を反映したものであるため、この区別は重要である。

    アルトコインの取引所入金、約1年ぶりの高水準に＝CryptoQuant(NADA NEWS)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:30 配信

    アルトコインの取引所入金、約1年ぶりの高水準に＝CryptoQuant（Image via NADA NEWS.） オンチェーン分析企業CryptoQuant（クリプトクアント）は9月29日付の週次報告で、アルトコインの暗号資産（仮想通貨）取引所への入金が急増していると指摘した。

    7日間合計の入金件数は約7万6000件、入金したアドレス数は約5万1000に達し、いずれも2025年10月17日以来の高水準となった。同日はビットコイン（BTC）が前回の最高値を付けた11日後にあたる。

    これらの数値は9月14日からそれぞれ約160%増、約3倍に膨らんだ計算だ。CryptoQuantは「入金の急増は通常、売り抜けの兆候である」と分析している。

    報告は、ビットコインが約8カ月ぶりの高値となる8万7400ドルを付けた後、上昇の勢いが鈍っているとも指摘した。9月22日には1日として今年最大の2万5700BTCの利益が確定されたという。

    一方、TradingViewのデータでは、ビットコインが暗号資産市場全体の時価総額に占める比率は10月1日朝時点で59.18%だった。5月27日以降は58〜60.4%のレンジで推移している。

    足元の市場では、アルトコインの急騰と利益確定のサイクルが繰り返される傾向が顕著となっている。こうしたボラティリティの高い相場環境のなか、国内では7月に成立した改正金融商品取引法により、暗号資産にもインサイダー取引規制が導入される。市場の健全化に向けて、今後はより一層「公正な価格形成」が問われることになりそうだ。

    米イリノイ州、0.2%暗号資産取引税の規則案を公表──ステーブルコインは課税対象に(NADA NEWS)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:00 配信

    米イリノイ州、0.2%暗号資産取引税の規則案を公表──ステーブルコインは課税対象に（Image via NADA NEWS.） 米イリノイ州の歳入局は9月28日、2027年1月1日に施行するデジタル資産税法の規則案を公表した。10月30日まで意見を募集している。

    同法は、事業者から暗号資産（仮想通貨）の交換・移転・保管サービスを受けた州内の顧客に、資産価値の0.2％を課すものだ。州内に拠点を持つか、州内顧客からの売上が10万ドル（約1550万円、1ドル=155円換算）以上の事業者に徴収と納付を義務付ける。

    規則案はステーブルコインを課税対象と明記し、NFT（非代替性トークン）やトークン化証券は対象外とした。DeFi（分散型金融）取引は原則非課税だが、運営・維持のためのプロトコル手数料を支払う場合は課税となる。

    流動性提供者のみに渡るスワップ手数料やネットワーク手数料は対象外だ。取引所から自己管理型ウォレットへの有料送金や、事業者を介したブリッジも課税対象となる。

    David Harris（デビッド・ハリス）局長は「税の新しさと業界の複雑さを踏まえ、影響を受ける人々に明確な指針を示す規則にしたい」と述べた。

    同州は2025年8月に暗号資産事業者を州の監督下に置く法律を制定し、2026年6月には予算関連法で全米初の州レベルの取引税を成立させた。業界団体のThe Digital Chamber（デジタル商工会）は7月、違憲だとして州を提訴している。

    損益に関係なく取引ごとに課税されるため、売買や送金の多い利用者の負担は重く、事業者の州外流出も懸念される。日本には暗号資産の取引自体に課す税はない。

    HSBC、香港ドル建てステーブルコイン「RedCoin」発行へ(NADA NEWS)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 7:00 配信

    HSBC、香港ドル建てステーブルコイン「RedCoin」発行へ（Image via NADA NEWS.） 英金融大手HSBCは9月30日、香港で発行を予定する香港ドル建てステーブルコインの名称を「HSBC RedCoin（RedCoin）」とすると発表した。

    香港法人の香港上海銀行が発行主体となり、2026年下期の提供開始を計画している。

    香港上海銀行は2026年4月、香港金融管理局（HKMA）からステーブルコイン発行者ライセンスを取得した。RedCoinは同ライセンスの下で発行される予定だが、現時点ではまだ提供されていない。

    サービス開始時は、HSBCの決済アプリ「PayMe」と「HSBC HK Mobile App」を通じて提供する予定。

    当初は個人間（P2P）送金や個人から加盟店への決済（P2M）といった日常的な用途から展開し、その後、法人や機関投資家向けのホールセール用途にも拡大する方針としている。

    HSBCは今回、香港の顧客1060人を対象に実施したステーブルコイン調査の結果も公表した。

    回答者の74％が少なくとも1つの利用用途を認識しており、最も多かったのは暗号資産（仮想通貨）取引・トークン化投資の57％だった。P2P送金が53％、国際送金と加盟店決済がそれぞれ52％で続いた。

    一方、回答者の60％が、ステーブルコインについて法定通貨などの資産に裏付けられ、価値の安定を目指すデジタル資産という基本的な特徴を理解していた。

    利用への信頼を高める要素としては、規制の明確化が62％で最多となり、教育の強化が55％、詐欺対策が53％だった。
