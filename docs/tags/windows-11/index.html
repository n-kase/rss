    マイクロソフト、「Windows 11 26H2」をリリース--新機能や移行は？(ZDNET Japan)

    マイクロソフト、「Windows 11 26H2」をリリース–新機能や移行は？の画像（ZDNET Japan） 「Windows」の新バージョンが登場した。期待された「Windows 12」ではなく、Windows 11の2026年版にあたる「Windows 11 26H2」である。Microsoftは、例年通り年後半の年次更新スケジュールに沿って、この最新版の一般提供を公式に開始した。

    Microsoftは米国時間9月29日に公開したブログで、26H2の提供形態を「イネーブルメントパッケージ」と説明している。これはアップデートが最適化されており、従来の年次更新よりも迅速かつ容易にインストールできることを意味する。ユーザーは更新プログラムを実行してPCを再起動するだけで、すぐに利用できる。

    なお、「Windows 11 26H1」も存在するが、同バージョンは「Snapdragon X2 Arm」プロセッサー搭載PC専用として提供された。現時点では26H1から26H2への直接のアップデートパスは用意されていない。一方「Windows 11 25H2」または「24H2」を実行中の他の全てのPCは、最新バージョンを入手可能となっている。

    対象のPC

    トラブルを回避するため、26H2の展開は段階的に進められている。自身のPCが対象であるか確認するには「設定」から「Windows Update」を開く。対応可能な状態であれば「Windows 11, version 26H2」の利用が可能である旨の通知が表示されるため「ダウンロードとインストール」をクリックして手続きを進める。通知が表示されない場合は「利用可能になったらすぐに最新の更新プログラムを入手する」のスイッチをオンにしてから、再度更新を確認する。

    更新プログラムは、Microsoftのウェブサイトからも入手できる。同サイトでは「インス トールアシスタント」「メディア作成ツール」あるいはISOファイルのダウンロードを通じて26H2を取得可能となっている。ただし、全てのWindows 11搭載PCが適用対象となるわけではないため、Windows Update経由で届くまで待つことが推奨される。

    既知の互換性問題が発生する可能性のあるPCには、更新プログラムが配信されない。この制限は通常、新しいアップデートと互換性のないハードウェアやソフトウェアが存在する場合に適用される。現在までにMicrosoftは26H2に関する重大な互換性問題を検出しておらず、発見されたわずかな不具合も解消済みとなっている。しかし、利用者の増加に伴い新たな問題が浮上する可能性はある。

    Windows 11 26H2の主な新機能：インストールすべきか？

    26H2には、既にリリースされている機能以外に新しい機能は追加されていない。むしろ過去1年間に配信された月ごとの機能更新およびセキュリティ更新を統合したパッケージとなっている。毎月のアップデートを適用していなかったユーザーにとって、PCを最新の状態に更新するために26H2をインストールすべきだろう。

    26H2を適用することで、カスタマイズ性が向上したスタートメニューやタスクバー、シンプルになった「Windows検索」「ウィジェット」アプリの改善、外部指紋リーダーに対する「Windows Hello」のサポート強化といった新機能を利用できるようになる。

    定期的なアップデートを欠かさず適用してきたユーザーにとっては、今回の新バージョンへの移行を急ぐ必要はないかもしれない。しかし、最終的にはアップデートが必要だ。Microsoftは「Windows Pro」および「Windows Home」の年次エディションに対するサポート期間を2年間と定めており「Enterprise」および「Education」エディションには36カ月間のサポートを提供する。

    現在「Windows 11 23H2」のサポートはすでに終了している。24H2のHomeおよびProエディションのサポートは米国時間2026年10月13日に、25H2は2027年10月12日に終了する。最新の26H2へ更新することで、サポート期間を2028年10月10日まで延長できる。

    Windows 11のうっとうしいポップアップ連発を凝縮体験できる「Windows 11½」

    Windows 11のユーザー体験で、改善はされたもののそれでもうっとうしいポップアップをこれでもかと体験させてくれる、「 Windows 11½ 」という誰が喜ぶのかわからないサイトが公開されています。

    Definitely Not Windows — Windows 11½

    https://definitelynotwindows.com/

    サイトにアクセスするとこんな感じでロゴマークが中央に表示され、読み込みが進みます。

    やがてデスクトップが表示されました。すると、画面左下にアシスタントのClippyが登場して説明を開始。一方、画面右下にはWindows 11½やMicrosoftアカウントのポップアップが次々と表示され始めました。

    ポップアップが止まりません。

    ポップアップは✕印をクリックすると消えるほか、しばらく待つと自動で消えます。Clippyもすべての説明を閉じると消えますが、すぐに次の発言を開始するので、ほぼ常時表示状態です。

    Edgeを開くと、Google Chromeのページを開こうとした状態になっていて、Edgeが「Microsoft EdgeはChromeと同じ技術を使用しています、ただし、すでにここに存在して削除は困難です」というメッセージを表示していました。

    OneDriveではデスクトップやマイドキュメント、マイピクチャなど、最大容量の5GBを超えるファイルをバックアップ済み。

    Microsoft Storeを開くと、中央に「それまで知らなかったけれど必要としているアプリ」のバナーが表示されています。

    WordやExcelもありますが、使用を続けたければアクティベートやサブスクリプションが必要だとのこと。

    Clippyの背後には「Definity Not Windows - Unofficial parody」との表記があります。クリックすると「Windows 11½」の説明が開き、非公式のパロディ企画であること、架空のOS体験であることなどが記されています。

    なお、Hacker Newsでは「 コンテキストメニューやスタートメニューが2秒以内に開くから偽物だとわかります 」「 ✕を押した後の反応がキビキビとして応答性が良好 」など、本物のWindows 11はもっとひどいというユーザーの声が多数寄せられていました。

    2024年6月に登場した「Copilot+ PC」では、40TOPS以上の処理能力を有する高性能なローカルAI処理用チップ「NPU」を活かして、様々なAI関連機能をオフライン環境でも動作させることができます。

    ・・・が、Windows 11 2024 Update（Version 24H2）向けに配信された更新プログラム「KB5055523」の適用後、なぜかNPUを搭載していないPCでも、ローカルAIを処理するサービスが常時バックグラウンドで動作する状態が既定となり、無駄にRAMを消費しています。

    そこでこの記事では、ローカルAI関連のサービスを停止する手順を紹介いたします。

    まずは注意点をチェック

    以前も記事で取り上げましたが、“基本的には”Windowsで動作しているサービスは意味があって動いているため、むやみに停止するのは推奨しません。

    特にCopilot+ PCでこの記事で紹介する手順を実行した場合、以下の機能が使えなくなるので、使っている方はサービスを停止すべきではありません。

    エクスプローラー・タスクバーの検索バーでのセマンティック検索機能

    回帰（Recall）機能

    メモ帳でのオフライン文章校正機能

    ペイントでのオフラインイラスト生成（Cocreator）、背景オブジェクト削除機能

    Click to Do（クリックして実行）

    Windows Studio Effects（WEBカメラで利用できるNPUを活用した各種エフェクト機能）

    画像識別機能

    また、NPU搭載PCでもCopilot+ PCでのみ利用できるローカルAI関連の機能を全く使っていない場合、バックグラウンドで「WorkloadsSessionHost.exe」が複数立ち上がり、環境によっては5GB以上のRAMを消費するケースも確認されています。

    今後上記の機能を一切使う予定がないのであれば、サービスを無効にすればRAMの消費を抑えられます。

    現在では実質WEBアプリとなってしまった「Microsoft Copilot」や、Microsoft 365 Personal/Familyのサブスクリプション契約ユーザー向けに提供されているOfficeのCopilot機能など、クラウドベースの生成AI機能については、本サービスを無効にした状態でも引き続き利用できます。

    一方、NPU非搭載PCの場合は、そもそも使えない機能のためのサービスが無意味に起動しているだけなので、停止しても特に影響はありません。

    ▼Copilot+ PCのシステム要件を満たしていないNPUを搭載するPCや、そもそもNPUを搭載していないPCでも、なぜかローカルAIを処理するためのサービスが立ち上がっている。↓

    Windows 11世代のPCではOSを軽量化するためにサービスやレジストリ設定を変更する必要は無い

    実際の操作手順について

    非Copilot+ PCやNPU非搭載PCの環境で無駄に起動しているWindows 11のローカルAIサービスは「Windows AI コンポーネントホスト」という名称で登録されていて、既定では自動的に起動するよう設定されています。

    ▼ タスクバーの「検索」ボックス、または「Windowsキー + Rキー」で開く「ファイル名を指定して実行」に「Services.msc」と入力すると「サービス」が起動するので、「Windows AI コンポーネントホスト」を選択します。↓

    ▼次に「スタートアップの種類」を「自動」から「無効」に切り替えて「停止」ボタンを押し、最後に「適用」ボタンを押します。↓

    ▼この状態で再起動すると、「Copilot+ PC」対応PCではローカルAI関連の機能がすべて無効化され、関連サービスも停止されます。再起動後も「Windows AI コンポーネントホスト」サービスが停止した状態になっていればOK。↓
