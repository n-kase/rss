    天の川銀河で「マイクロブレーザー」の有力候補を発見 超高エネルギー宇宙線の発生源の可能性も？(sorae 宇宙へのポータルサイト)

    2026年9月28日 カテゴリー ニュース

    本文

    9/28(月) 6:01 配信

    今回の研究をもとに作成されたマイクロブレーザー候補「IRAS 18293-0941」の想像図。画像の左側には地球に向かうジェットが、右側には反対側のジェットによって生じたとみられるホットスポットが描かれている（（Credit: B. Marcote (JIVE/ASTRON)）） 遠方の宇宙で知られる「ブレーザー」の小型版が、天の川銀河にも存在するかもしれません。ハエン大学のJosep Martí氏を筆頭とする研究チームは、地球に対してジェットをほぼ真っ直ぐ向けているとみられる連星系「IRAS 18293-0941」について、「マイクロブレーザー」の有力な候補として報告しました。研究チームの成果をまとめた論文は学術誌「Astronomy & Astrophysics」への掲載が受理されており、プレプリントが公開されています。

    長さ180万光年の“弓” 市民科学者が発見した弓矢形の巨大な電波銀河「RAD-BAARG」

    正面から見たジェットは明るく見える

    ブレーザーとは、銀河中心の超大質量（超巨大）ブラックホールのジェットを正面から見ている天体のことです。光速に近い速度で近づくジェットの放射が強められて明るく見えるのが特徴で、遠ざかる側は反対に暗く見えます。

    マイクロブレーザーは、「マイクロ」が示すようにブレーザーの小型版と言える天体で、ブラックホールや中性子星といったコンパクト天体を含む連星が作るジェットを正面から見ているものです。SARAO（南アフリカ電波天文台）によれば、その存在は1990年代から予測されてきたものの、継続的なジェットの確実な例はこれまで見つかっていませんでした。

    ジェットの推定角度が電波と可視光線で一致

    研究チームによると、電波望遠鏡による観測の結果、IRAS 18293-0941では片側だけに伸びる電波ジェットが確認され、反対側は検出されませんでした。反対側との明るさの比（26倍を超える）をもとに、検出されたジェットの向きは視線から47.8度以内と算出されています。

    各地の電波望遠鏡を結ぶ観測手法であるVLBI（超長基線電波干渉計）で測定した位置は、ESA（ヨーロッパ宇宙機関）が運用していた「Gaia（ガイア）」宇宙望遠鏡衛星で測定した恒星の位置と誤差内で一致したことから、ジェットが遠方の銀河ではなくIRAS 18293-0941に由来することが確かめられたといいます。

    また、明るさの周期的な変化をもとに、IRAS 18293-0941の公転周期は約11.38日と見積もられています。明るさの変化が小さいことから、公転軌道の真上から30度以下の角度で観測している可能性が高いといいます。ジェットが軌道面に対して垂直に放出されていると仮定すれば、その角度は視線から30度以下となりますから、前述の電波観測で割り出された角度とも矛盾しません。
