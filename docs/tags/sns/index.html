    ラーメン店に謎の“手紙”、大量ペットボトル…ネットあ然 “ありがた迷惑”な差し入れに店側困惑(ENCOUNT)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:40 配信

    「『差し入れではない』と思いました」

    ラーメン店の前に置かれた大量の1.5リッターペットボトル【写真：投稿者提供】（ENCOUNT） 熱烈なファンによるものか、それとも、クレーマーによるものか……。ある日突然、ラーメン店の裏手に大量の1.5リットルのペットボトルが置かれ、店のドアには“お節介“とも取れるアドバイスが延々と書かれた手紙が挟まれていた。SNSで明かしたラーメン店の投稿には多くの反響が寄せられていたが、一体何があったのか。店主に詳細を聞いた。

    【写真】いったい誰が？ネットも首をかしげる…ラーメン店に挟まれていた実際の手紙

    「店の裏にお茶置いたり、店の裏のドアに手紙挟んだりするのは辞めてください。これ以上続くようでしたら警察に相談します。防犯カメラも設置します」

    9月23日にSNSに投稿したのは、千葉・木更津市で開店4年目を迎えたラーメン店「麺やギブタンクス」のアカウントだ。投稿には、路上に置かれたペットボトルの数々の画像と、「飲食経営しているギブタンクスファンより」から始まる“店へのアドバイス”を延々と書き連ねた手紙の画像が添えられていた。

    大量のペットボトルが事の発端だ。「最初に発見した時は、正直かなり驚きました。おそらく、深夜から明け方にかけて置かれたと考えています。従業員が作業していたので店の明かりはついていたはずで、直接渡せばいいのにやらなかったということは『差し入れではない』と思いました」と、店主は振り返る。

    ペットボトルは「いっさい飲まずに処分しました。量が多く捨てるのが大変で、正直、気持ち悪かったです」と明かすが、その1週間?2週間後には、店のドアに手紙が挟まれていた。かなりの文量が書き込まれており、「顧客満足度の向上」と題した項目では「食券をせめて受け取るようにしたほうが良い。その時に確実に挨拶できます」、「値段設定を大幅に変えたくなければ、ノーマルの値段で大盛まで無料にする」など、事細かな文言が続いている。

    投稿への反応では「良いこと書いてもらってるじゃないですか」「手紙の意見参考にして改善したほうがいい」と“手紙の主”に理解を示す声もあったが、店主は「内容については改善すべき点もあります。ただ、明らかに事実と異なる点があり、アンチ的要素が強いと感じました」との受け止めを伝える。実際、投稿に対して「言いたいことはわかるけどこれを実践し始めてデカい顔する常連さんがいると思うとやりづらいね」と、店側を気遣う反応もあった。

    今回の投稿をした理由は「匿名で無断で飲み物を置いたり、手紙を挟んだりするのは、従業員並びに建物にお住まいの方にも迷惑がかかるのでやめていただきたいと思ったからです」と店主。たとえ店への思いやりであったとしても、振る舞いによっては“ありがた迷惑”になりうることを、客側も肝に銘じておくべきだ。

    【写真を見る】「何度もして覚えていない」同年代を装い10代少女にわいせつ動画を撮影送信させた疑いで37歳男逮捕 余罪多数か 北海道北見市

    ■SNSで少女を装い動画を送信させる

    SNSを介して自分自身を同年代の少女であると信じ込ませたうえで、面識のない10代の少女にわいせつな動画を撮影させ、送信させたとして、北海道警察は9月30日、北見市の37歳の会社員の男を逮捕しました。

    不同意わいせつ、児童買春・児童ポルノ禁止法違反の疑いで逮捕されたのは、北見市とん田西町に住む会社員、水野利信容疑者（37）です。

    水野容疑者は2026年1月7日ごろと、11日ごろ、SNSアプリで知り合った大分県に住む面識のない10代後半の少女に対して、自身が同年代の少女であると装い、信じ込ませたうえ、メッセージアプリへ誘導しました。

    その後も連絡を取り続けて、少女に対しわいせつな動画を撮影するよう要求し、その動画を送信させた疑いが持たれています。

    ■アカウント解析から男の関与が浮上

    少女の親族が、少女がわいせつな動画の撮影をしていることに気付き、不審に思った親族が少女と話し合い、警察に相談しました。

    相談を受けた大分県警が、SNSアカウントを解析するなどの捜査を行った結果、水野容疑者の関与が浮上し、道警が逮捕しました。

    警察の調べに対し、水野容疑者は「私がやったことではありますが、これまで同じようなことを何度もしてきたので、正直覚えていないというのが本音です」と容疑を一部否認しています。

    警察によりますと、押収した水野容疑者のスマートフォンなどから同様のわいせつな姿態が写った動画などが多数見つかったことから、警察は余罪は多数あるとみて捜査を続けています。

    熊本弁は〝愛〟言葉 「熊本のオッサン」動画でフォロワー急増 甲佐町のインフルエンサーの素顔 連載「これが私の生きる道」＃8 jj.outdoorさん(熊本日日新聞)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:05 配信

    インスタグラムやティックトックで熊本弁動画を配信するjj.outdoorさん。素顔は甲佐町に住む会社員だ＝7月中旬、甲佐町の乙女河原（熊本日日新聞） 親戚や近所にいそうな熊本弁のおじさんにふんした動画で人気のインフルエンサーがいる。「jj.outdoor」として活動する甲佐町の45歳の男性会社員だ。方言を使った面白動画にあふれる郷土愛に、じわじわと共感が広がっている。（熊日ベータ版編集部）

    コテコテの熊本弁をしゃべる「オッサン」と「爺（じい）さん」の動画「熊本弁理解度検定」を、交流サイト（SNS）のインスタグラムで毎日のように投稿している。投稿を始めた6月は2500人ほどだったフォロワーは、8月には２万人に急増した。

    「始めてすぐブワッと跳ねて、1週間に千人単位で増えていきました。県外にいる熊本出身の方から『じいちゃんのしゃべり方にそっくり』『懐かしくて涙が出た』といったコメントを多くもらいます」

    地元の危機を救うため

    素顔は「銀座に本社がある会社の営業マン」。動画には顔や声を加工して登場する。携帯電話で誰かと会話している設定だ。「仏（ほとき）さん」「こる豆」「鉢盛り」など、年配者にありがちな言葉遣いが、熊本人に刺さっている。

    動画に登場する「熊本のオッサン」。顔と声を加工している。いつでもどこでも撮影できるよう、どの動画も車内で誰かと携帯電話で話しているスタイルだ（熊本日日新聞） 「地元の先輩やじいちゃん、ばあちゃんとの雑談とか、身近な『熊本あるある』がネタです。あんな人たち、本当にいるでしょ？ それまでアウトドア系の内容ばかり投稿してましたが、多くの人が喜ぶコンテンツを上げてみようと思って。それが熊本弁でした」

    子どもの頃からキャンプが好きで、自宅近くの乙女河原（津志田河川自然公園）や緑川で遊んで育った。野外での救急法に関する資格を持ち、自然ガイドをしたり、キャンプの知識を生かして防災イベントの講師を務めたりしている。

    熊本弁動画は、乙女河原を守り、維持する取り組みの一つだ。公園は甲佐町が管理し、申請すれば無料で利用できるため人気だが、マナー違反が問題になっていたという。

    「一般的なキャンプ場と違って、24時間出入り自由です。県外からも人が来て、わいわい騒いで花火を派手に打ち上げる。地面で火をたいて、ごみも捨てていく。若い頃、バイクやヒッチハイクで全国をキャンプしながら旅してましたが、キャンプやバーベキュー禁止の場所が多いんですね。原因は利用者のマナー違反なんです。乙女河原も常態化すれば閉鎖の可能性がありました」
