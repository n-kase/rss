    熊襲撃備える防護服 メーカー開発 爪や牙から身守る 防刃素材で負傷減(日本農業新聞)

    熊対策防護服「SSPベア・アーマー」のマスクとベスト、アーム（神戸市で）（日本農業新聞） 防刃装備品を展開する「SYCO（サイコウ）」（神戸市中央区）は、熊対策の防護服「SSPベア・アーマー」を製造販売する。爪や牙による攻撃に対し、防刃素材で負傷を最小限に抑える。

    熊より〝一枚〟上手の防護服

    胴体や腕、肩など体の部位ごとに装着する。熊の攻撃が集中する顔と首を守るため、鼻から首までを包むマスクが特徴。刃物で突き刺しても貫通しない炭素繊維強化プラスチックで覆ってある。

    マスク、ベスト、アームの3点購入多く

    熊対策防護服「SSPベア・アーマー」で防御姿勢をとった場合（神戸市で）（日本農業新聞） 同社が製造してきた防刃防護服が、熊にも有効か問い合わせがあったことから、笹田直輝社長が開発し、4月に一般販売した。マスクとベスト、アームの3点での購入が多く、自治体などへ約80セットを販売。価格は3点で17万8200円。

    （鴻田寛之）
