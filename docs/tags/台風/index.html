    ▶▶▶▶【巨大な渦…雨風シミュレーションはここから】【台風情報】本州をめがけ北上する台風27号

    中心気圧は998ヘクトパスカル、中心付近の最大風速は18メートル、最大瞬間風速は25メートルとなっています。中心から全域 220 キロ以内は風速15m/s以上の強風域となっています。

    台風は4日午前3時ごろにかけて強い勢力に発達する見込みです。

    ■本州をめがけて北上の見込み

    台風27号は、このあと西に進んだあと北上を続け、発達しながら4日午前3時ごろには南鳥島近海へ達する見込みです。その後は北北東に進み、5日ごろにかけて小笠原近海へ進むでしょう。

    来週、本州付近の天気に影響を与えるおそれがあり、注意が必要です。

    最新のシミュレーションでは、台風27号は今後北上し、週明け「巨大な渦」が本州の東海上を北上する予測が示されています。

    【写真4枚】台風27号の6日午前3時の勢力詳細

    台風26号はきょう1日午前6時時点で八丈島の南東約50キロメートルの海上を北東に進み、中心気圧は1002ヘクトパスカル、最大瞬間風速25メートル。午後6時ごろまでに銚子市の東約280キロメートルへ移動する予想。2日午前6時までに温帯低気圧となるとされる。

    新たな台風27号は、1日午前3時ごろにマリアナ諸島で発生。4日午前3時ごろまでに「強い台風」に発達し南鳥島近海に移動する予想。6日午前3時には中心気圧960ヘクトパスカル、最大瞬間風速55メートルまで勢力を増し、小笠原近海に達する可能性がある。本州に影響を与える可能性がある。

    台風の進路は著しく変化することもあり、今後も最新の気象情報を確認する必要がある。
