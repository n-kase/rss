    趣味で始めたライブ配信で「投げ銭」が年間30万円ほど集まりました。副業のつもりはありませんでしたが、今年は確定申告が必要でしょうか？（ファイナンシャルフィールド） 最近では、さまざまなSNSサイトやアプリなどを使って、誰でも気軽にお金を稼ぐことができるようになりました。本業とは別に、副業として利益を得ている人もいるでしょう。

    副業で得た利益がある場合、確定申告が必要なケースがあります。今回は、確定申告が必要となる副業についてチェックしていきます。

    ▼会社員で「年収1000万円」以上の割合は？ 大企業ほど高年収を目指せる？

    SNSやアプリでお金を稼げる時代に

    インターネット技術の発達や、ネットビジネスの多様化により、SNSサイトやアプリで、私たちでも気軽にお金を稼ぐことができるようになりました。

    例えば、インターネットサイトを利用して、自分で作ったハンドメイドの物を販売したり、中古品を売買したり、動画を配信したりと、自分の得意分野を生かして、利益を得ている人もいるでしょう。

    また、複数のサイトで副業を行っている人もいるかもしれません。

    このようなSNSサイトやアプリでの収入には、税金がかかるケースがあります。特に、本業として普段は会社員として働き、年末調整で課税関係の精算を終わらせている人（確定申告をしていない人）は、副業収入について注意が必要です。

    副業で確定申告が必要なケース

    では、具体的に、副業収入で確定申告が必要なケースについてチェックしていきましょう。会社員の方で副業収入がある場合、副業の所得が年間20万円を超えると確定申告が必要です。

    複数のサイトを使って副業を行っている人の場合は、すべての副業を合算して計算します。また、この副業所得とは、売り上げそのものではなく、収入から必要経費を引いたものとなります。

    例えば、ハンドメイドの物を販売しており、収入があったとしても、材料費を差し引いた利益が20万円を超えなければ、確定申告の必要はありません。

    なお、副業の所得が20万円以下であっても、医療費控除やふるさと納税などのために確定申告をする場合は、副業所得についても一緒に申告をする必要があります。

    また、副業の所得が20万円以下の場合、確定申告は不要となりますが、住民税の申告をする必要があります。副業の所得は、本業の所得などと合算されて住民税が計算されることになっています。
