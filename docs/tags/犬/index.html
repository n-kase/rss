    【田んぼの脇に捨てられていた犬】ひどい状態での放置

    海外のSNSで話題になっているのは、田んぼの脇に捨てられていた犬「キッキ」の姿です。

    保護当時のキッキは、左目が白く濁り、全身は泥や汚れに覆われていました。毛は長く伸び、皮膚の状態も良いとはいえず、厳しい環境で過ごしてきたことが伝わってきます。

    動画には、キッキの体を洗うとスタッフの手に汚れがびっしり付着する様子も映し出されていました。

    スタッフは、その状態を「本当にひどい」と表現。ネグレクトや遺棄を経験したキッキが、過酷な日々を送ってきたことがうかがえる場面です。

    【タオルに包まれたキッキ】スタッフに保護され、動物病院へ

    田んぼの脇で見つかったキッキは、駆け付けたスタッフによって優しくタオルに包まれました。安心させるように抱きかかえられたキッキは、そのまま車で動物病院へ搬送されます。

    病院では体の状態を確認したあと、シャンプーや毛のカットなどのケアが始まりました。

    動画には、シャンプーで洗い流された泥や汚れがスタッフの手に付着する様子も。キッキは過酷な環境で、不安の中過ごしていたことでしょう。

    保護から1週間が経つと、キッキには少しずつ変化が見られるようになりました。

    毛並みは徐々にきれいになり、ご飯もしっかり食べられるように。さらに、周囲を歩き回ったり、他の犬に興味を示したりするなど、行動にも変化が現れました。

    スタッフは、キッキが初めて吠える姿も見ることができたと報告。まだ回復の途中ではあるものの、心と体の両方が少しずつ元気を取り戻している様子が伝わってきます。

    散歩中に「何アレ可愛い」と言われた愛犬の姿は……（写真：ねとらぼ） 散歩中、女子小学生に「かわいい」と言われた愛犬の姿は……。見て納得の写真がThreadsに投稿され「目の保養」「え！可愛いw」といった声が寄せられています。

    【画像】納得の格好

    画像を投稿したのは、シベリアンハスキーの「O次郎（オウジロウ）」くんと暮らす飼い主さん。今回話題になったのは、散歩中に声をかけられたときのエピソードです。

    晴れた穏やかな日に散歩をしていたら、小学生の女の子に「何アレ ハスキー可愛い」と言われました。一体どんな姿だったのかと見てみると、そこには頭や耳まですっぽりとウエアで包まれたO次郎くんの姿がありました！

    それは頭部から首元をやさしく包むライトグレーのスヌードと、白地に薄いグレーの水玉模様が入ったベストというコーディネート。O次郎くんの黒と白の毛並みに、淡いモノトーンのファブリックが美しく調和しています。都会的で洗練されたこちらのファッション、とてもすてきではありますが一見するとシベリアンハスキーかは迷うところ。

    ハスキーと瞬時に見抜きリアクションした女の子に、飼い主さんは「この姿を見てすぐハスキーってわかるのスゴイ」とつづっています。なお、こちらのウエアは、濡らして着ると気化熱効果で涼しくなる機能性があるもの。O次郎くんは上半分が黒い毛並みなので遮熱効果も発揮するんだそうです。

    この投稿には「かんわぃい！！」「目の保養です」「お家でもハスキーかっているのかもしれない」「その子はワンちゃん好きなんですね」「え！可愛いwwwww」といった声が寄せられています。

    快適なお散歩タイムを満喫しているO次郎くんの楽しそうな表情も合わせて「かわいい」と思わず声に出てしまう姿ですね。
