    鈴木京香ら笑顔でクランクアップ、いきものがかりの名曲から誕生した物語『キリコのタクト～YELL～』(オリコン)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:19 配信

    クランクアップ時の鈴木京香＝映画『キリコのタクト～YELL～』（10月2日公開） （C）映画「キリコのタクト〜YELL〜」製作委員会（オリコン） 俳優の鈴木京香が伝説の音楽教師を演じる映画『キリコのタクト～YELL～』（10月2日公開）から、合唱シーンなどの場面写真や、メイキング、クランクアップの写真計8点が公開された。

    【画像】この記事に関するそのほかの写真

    本作は、いきものがかりの楽曲「YELL」に着想を得たヒューマンドラマ。同曲は、「第76回NHK全国学校音楽コンクール」中学校の部の課題曲として制作された。“魔法のタクト”を持つと語り継がれる音楽教師・原田貴理子（鈴木）と、彼女に人生を導かれた教え子たちの絆を描く。

    音楽と笑顔で生徒たちを指導していた、通称“キリコ”。しかし、卒業式の日を境に突然姿を消してしまう。音楽雑誌記者となった元教え子の北村翔（藤原大祐）は、高校時代の合唱部仲間たちとともに恩師の行方を追い、記憶をたどりながら、キリコの知られざる真実に迫っていく。

    このたび、2025年夏の撮影現場から、合唱部のメンバーが集まったオフショットや、キャストとスタッフが笑顔を見せるクランクアップの写真が公開された。

    場面写真は、キリコによる猛特訓の成果を披露する合唱コンクールでの「YELL」の合唱シーンから2点、挿入歌「白鳥」を手がけた藤原が歌う場面、キリコが合唱部を担う4人をスカウトする、物語の始まりとなる場面が切り取られ、音楽を軸にした作品の舞台裏を伝えている。

    第20回田辺・弁慶映画祭プログラム決定！ 第10回記念作「ポエトリーエンジェル」や「孤狼の血」「銀河鉄道の父」「金髪」を招待上映(映画.com)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:00 配信

    第10回記念映画「ポエトリーエンジェル」（(C)田辺・弁慶映画祭 第10回記念映画プロジェクト） 11月13日から15日までの3日間、和歌山県立情報交流センターBig・U（和歌山県田辺市）で開催される、第20回田辺・弁慶映画祭の上映プログラムが決定した。

    田辺・弁慶映画祭は、2007年から開催し、今年で20回目の節目を迎える。映画産業を担う「次世代監督」や「映像作家」の作品、地元に関係した映画または映像作品の上映等をはじめ、映画祭を切り口とした様々な活動を通じ、市民・映画関係者・田辺市への来訪者との交流推進、連携の創出、また映画文化の振興を図るとともに、地域の活性化に寄与することを目的としている。

    今年は4月17日から7月17日まで若手映画監督によるコンペティション部門の募集を行い、応募総数183作品（前回182作品）の中から予備審査を経て、季子汀監督「霧しぐれ」、林真子監督「パズル残念ながら１ピース」、藤井柚衣監督「露骨な花」、岡本祐一郎監督「自由研究『マイファミリー』」、百武大輔監督「聞こえるかこの雄叫びが」、入江祐斗監督「台風なんだって、明日」、嶋田萌花監督「憂い夏、錆びて」、そして山中太郎監督「愛の手掴み」の8作品が入選した。

    13日と14日の2日間に同センター多目的ホールで上映され、15日の表彰式で「弁慶グランプリ」および役者個人に贈られる「俳優賞」などが発表される。今年のコンペ部門のゲスト特別審査員は白石和彌監督と俳優の坂井真紀が務め、特別審査員長で本映画祭のプログラムディレクターである掛尾良夫、松崎健夫（映画評論家）、沢村敏（東京テアトル）の各氏とともに審査を行う。

    そして、招待作品と上映スケジュールも決定。13日には、田辺・弁慶映画祭の第10回開催を記念して製作された長編映画「ポエトリーエンジェル」（2017）を上映する。「チキンズダイナマイト」「独裁者、古賀。」「踊ってミタ」など個性的なオリジナル作品を発表し続けている飯塚俊光監督が脚本も手掛け、今や映画・ドラマなどで大活躍する岡山天音と武田玲奈がダブル主演した青春エンタテインメント。国民的人気グループとなったMrs. GREEN APPLEが主題歌に「soFt-dRink」を提供した。

    さらに、14日には白石監督の舞台挨拶付きで「孤狼の血」、15日に坂井の舞台挨拶付きで「銀河鉄道の父」と、「金髪」（岩田剛典主演・坂下雄一郎監督）を上映する。コンペ入選作品の鑑賞は無料で、招待作品は有料。

    田辺市の真砂充敏市長は「これまで、本映画祭から多くの若手監督が羽ばたき、映画界の第一線で活躍されていることは、田辺市にとって大きな誇りであります。この記念すべき節目を新たな出発点として、映画を通じた人と人との出会いや地域とのつながりがさらに広がり、田辺の地から新たな才能と感動が生まれることを大いに期待しております。本市といたしましても、引き続き映画文化の振興と次代を担う若い才能の支援に取り組んでまいります」（一部抜粋）とコメント。

    本映画祭実行委員会の中田吉昭実行委員長は「『映画で町おこし』の活動は、2005年に田辺市を舞台に１本の映画制作から始まりました。2007年には第1回田辺・弁慶映画祭を開催して以来、今回で第20回の節目を迎えることができました。これまで弁慶映画祭に対しまして、多くの映画ファンや映画関係者の皆様からの応援と、地元の市民・協賛企業・協力団体の皆様からは多大なるご支援により、育てていただきましたことに心から感謝申し上げます」（一部抜粋）とコメントを寄せている。

    なお現在、第20回と節目の年を迎える中、会場変更等により事業費拡大を受け、クラウドファンディング（https://motion-gallery.net/projects/tbff20th）を実施し、10月5日まで支援を募集している。また、市民の多くの人々と共に映画祭を作っていくことを目的に「市民応援団」の募集を10月30日まで行っている。
