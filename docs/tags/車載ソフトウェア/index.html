    【テスラ】サマーアップデート「2026.26.6.1」が配信開始〜点数付きカラオケ・Grok拡張ほか

    2026/09/14

    Teslaのソフトウェアアップデート「 2026.26.6.1 」の配信が、日本国内で始まりました。

    国内の現行バージョンは「 2026.20.6.1 」で、海外で7月下旬に配信が始まった「 2026 Summer Release ( 2026.26.6 )」を含んでおり、国内では今回が事実上のサマーアップデートにあたります。

    アップデートの内容

    車内のリリースノートに記載されているのは、以下の項目です:

    Grokコマンド … 電話の発信、音楽の再生、空調の調整、コントロールパネルの検索に対応。Teslaや最新のアップデート内容についての質問も可能。「Grok」＞「設定」で「Hey Grok」と位置情報に基づくリマインダーを切り替えられます。プレミアムコネクティビティ、または有効なWiFi接続が必要

    スコア機能付きCaraoke … パーキング中の歌唱を採点。「マイ カラオケ」タブで星を獲得し、ハイスコアを記録できます。リアディスプレイのキューボタンでQRコードを表示すれば、同乗者がスマホから曲を追加可能。プレミアムコネクティビティが必要

    ウェルカム アニメーション … 起動時にアニメーションを表示

    カスタムラップ … スマホの画像からラップデザインをアップロードし、車両に直接送信。モバイルアプリの「クリエーション」＞「ラップ」＞「アップロード」から操作し、バージョン「4.59.0」以降が必要。車内では「アプリランチャー」＞「おもちゃ箱」＞「ペイントショップ」

    オートナビゲーション … 自宅・勤務先・カレンダーの予定に加えて、通勤途中の学校への送りなど、定期的に訪れる場所を提案してルート案内。「目的地の提案」が有効な場合に動作します

    カメラ プレビュー … パーキングに入っていなくても、いつでも表示可能に。「コントロール」＞「サービス」＞「カメラ プレビュー」でカメラを個別表示、グリッドボタンで全カメラ表示に戻ります

    Apple Music … 検索結果やアーティストページから、キューに直接曲を追加。長押しか3点リーダーメニューで、次に再生・キューに追加・ライブラリに保存・お気に入りを選べます

    ドライビング ビジュアライゼーション … ドライブアシストのズーム設定をカスタマイズ。ピンチ操作か、「コントロール」＞「ドライブアシスト」＞「ビジュアライゼーション カメラのズーム」でプリセットを選択

    リアディスプレイ … リアタッチスクリーンの操作を無効化できます。「アプリランチャー」＞「リア」＞「リアスクリーンをロック」。センターディスプレイで選んだコンテンツは、後部で再生が続きます

    ウェブブラウザ … インテリアカメラと車内マイクをブラウザで使用可能に。カメラが使えるのはパーキング中のみ

    トラクションコントロール モード … 通常の「自動」、凍結・濡れた路面向けの「滑りやすい路面」、雪や泥にはまったときの「立ち往生アシスト」の3種類。走行のたびに「自動」へリセットされます

    推定航続距離 … バッテリーの経時劣化に関連する特性が、航続距離の見積もりに反映されるようになりました

    スーパーチャージャー(SC)検索 … 目的地の検索時に、SCを名前で探せるようになりました

    セキュリティの改善 … 重要なセキュリティ修正と改善を含みます
