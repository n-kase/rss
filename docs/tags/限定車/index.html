    ニュース アルファロメオ ジュニア トナーレ 特別限定車 ステランティス イベント

    2026年9月24日、ステランティス ジャパンは同社がプロデュースする「アルファロメオ」ブランドのジュニアとトナーレに設定された特別限定車の発表を記念して、東京・渋谷で一夜限りのカルチャー＆ナイトパーティ「アルファロメオ ウナ ノッテ スペチアーレ」を開催した。
