    長野県松本･里山辺の落石 風化･浸食が原因 県が報告書まとめる 対策で防護柵設置へ(市民タイムスWEB)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:35 配信

    落石現場を調査する県職員ら（県森林づくり推進課提供）（株式会社市民タイムス） 県は30日、長野県松本市里山辺で5月に発生した、巨石の落石災害の報告書をまとめた。現場は松くい虫被害などで岩肌がむき出しになった場所で、落石の原因は長年の風雨で軟らかい泥岩が風化・浸食され、残った硬い岩が浮き石化したことだと結論付けた。県は令和6年度に枯損木を整理する治山事業を行っていたが、落石を誘発した作業は確認されなかったとした。

    落石は5月7日に発生し、最大約11トンの巨石3個が斜面を転がり落ち、民家の車庫や市道に被害が出た。県は8月から斜面にある不安定な岩を固定する対策を進めている。

    恒久対策として来年度以降、防護柵の設置も計画する。松枯れ被害に対しては、植樹を行わず自然に広葉樹などが生えて回復する「天然更新」で森林を再生したい考えだ。

    今回の落石を受け、県は森林整備などの治山事業を行う際、計画段階で落石のリスクを確認する仕組みを、来年度事業分から導入する。周辺に人家や道路がある場合、落石の危険性と対策の実施可能性を確認し、事業を行うかどうか判断する。

    県森林づくり推進課は「県内ではこれまで治山事業の現場での落石事例があまりなかった。今回を契機に、そのリスクを計画段階から認識して対策していきたい」としている。

    株式会社市民タイムス

    発掘中の長野県松本・安塚古墳群 10日に初の現地説明会(市民タイムスWEB)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:30 配信

    今年見つかった第17号古墳の石室（株式会社市民タイムス） 長野県松本市和田の中部縦貫自動車道・松本波田道路の建設に伴う「安塚古墳群」の発掘調査現場で10日、県埋蔵文化財センター（長野市）による現地説明会が開かれる。今年の調査で新たに2基の古墳が見つかり、古墳群の広がりが明らかになってきたほか、これまで不明だった上部構造を考える上で参考になる発見もあった。

    令和4年度の発掘調査開始以来、広く一般市民を対象にした現地説明会は初めて。

    安塚古墳群は国道158号新村交差点の南西側に広がり、7世紀末～8世紀初頭の「古墳時代終末期」の古墳が見つかっている。半地下式または地下式の石室が特徴で、後の時代の水田開削で盛り土が削られて上部構造が謎になっている。

    今年の調査で見つかった第17号古墳は石室の長さが約6メートル、幅が約1.5メートルで、安塚古墳群の中でも「大きい部類」だという。

    もう一つの第18号古墳は調査範囲の境界にあるため石室の長さは不明だが、幅が2.3メートルで、隣接する古墳群を含めて最大の可能性がある。調査範囲の境界に位置するため石室を横切る発掘断面が残り、当時の地表面である黒色土を切り込んで石室を造ったことが分かった。盛り土らしき層も確認された。

    調査研究員の水科汐華さんは「水田の開発によって人々が生活してきた下に、古墳時代の人々が生きた証しがある。今ここで生活を営んでいることも歴史なのだということを伝えたい」と語る。

    現地説明会は午前10時半からと午後1時半からの計2回。発掘現場を巡回しながら古墳を紹介するほか、現場プレハブ内で主な出土遺物を解説する。雨天の場合は発掘現場は公開せず、プレハブ内での遺物解説のみ。

    株式会社市民タイムス

    葉物野菜が高騰 恨めし9月の長雨 長野県中信地域(市民タイムスWEB)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:26 配信

    レタスやキャベツなどの葉物野菜が並ぶ売り場（ラ・ムー流通団地店）（株式会社市民タイムス） レタスやハクサイなど葉物野菜の価格が高騰している。9月の長雨による日照不足や低温による成育の遅れで関東地方や県内の主産地で出荷量が減っており、卸売価格でレタスは平年比2・3倍、ハクサイやキャベツ、ホウレンソウは同2～6割高い。消費者は店頭価格に驚き、購入を控えたり使う量を減らしたりと日々の献立に知恵を絞っている。

    中信地域の小売価格は、いずれも税込みでレタスが1玉380円前後、キャベツが同260円前後、ホウレンソウは1袋280円前後、ハクサイが2分の1サイズで350円前後とみられる。

    長野県松本市内の食品スーパーに3日分の食材を買いに訪れた同市笹賀の女性（76）は「久しぶりに見たら値段にびっくりした」と、レタスの売り場を見て衝撃を受けていた。野菜炒めはキャベツを減らしてモヤシを増やすなど工夫しており、「大根やニンジンといった根物を中心に献立を考えたい」と語った。

    サンドイッチにレタスを使っている松本市内のあるパン店は、少しでも安い店で購入するようにしている。経営者は「すごく高いのを実感しているが、ないと困る。使うのをやめるとか量を減らすとかではなく、クオリティー（品質）を維持しつつ工夫しながらやっている」とした。

    松本市小屋南2の食品スーパー「ラ・ムー流通団地店」。葉物野菜は2週間ほど前から値上がり傾向で購入の動きが鈍るが、タマネギやニンジン、キノコ類の動きが良くなってきているという。竹内渓人副店長は「何店舗も回って少しでも安く買いたいという人もいると思う。高騰の中でもなるべく安く提供できるように工夫している」と説明する。

    農林水産省園芸作物課によると、葉物野菜は夏の産地から冬の産地に切り替わるタイミングだが、例えば次のレタス産地の茨城県でも長雨が続いていて見通しは明るくない。この高騰はいつまで続くのか。同課は「天候次第」としている。

    株式会社市民タイムス
