    ウーバーイーツ配達でシルバーウイークチャレンジ。今年はどれくらい稼げたのか？【チャリンコ爆走配達日誌】(週プレNEWS)

    本文

    10/1(木) 7:04 配信

    シルバーウイーク中にウーバーイーツ配達をやってみました（週プレNews） 連載【ギグワーカーライター兼ウーバーイーツ組合委員長のチャリンコ爆走配達日誌】第170回

    ウーバーイーツの日本上陸直後から配達員としても活動するライター・渡辺雅史が、チャリンコを漕ぎまくって足で稼いだ、配達にまつわるリアルな体験談を綴ります！

    ＊ ＊ ＊

    9月23日の秋分の日が水曜日だったことから、月曜日の敬老の日（21日）と秋分の日にはさまれた22日火曜日が国民の休日となり、今年のシルバーウイークは5連休となりました。

    東京都内でウーバーイーツ配達員をやっている私の肌感では、お盆休みから1ヵ月ほどしか経っていないシルバーウイークは、海外に行くより近場へ出かける人が多いです。

    私がよく配達するエリアでいうと、浅草や築地、東京タワーなど観光名所の人出は普段の休日程度ですが、江東区の「ららぽーと豊洲」「アリオ北砂」といった大型ショッピングモールが普段以上に混雑する感じです。こういった日帰りできる近場へ出かける人が多く、夜は家で過ごす人が多いからなのでしょう。シルバーウイークに配達をしていると、けっこうな数の依頼が舞い込みます。

    そこでシルバーウイーク中にどこまで稼げるか試してみました。

    私は仕事のため土曜日は18時以降、日曜日は19時以降と夜しか稼働できませんが、月曜日、火曜日、水曜日は特に仕事もなく丸々稼働できます。これまでの経験から、土日はそれぞれ5000円、月曜日以降は1日平均1万5000円で5万5000円ほど稼げそうです。

    そんな皮算用をしつつ迎えたシルバーウイーク初日(19日)の天候は雨。「雨クエ」と呼ばれる特別報酬が付く状況でしたが、雨の降る夜の自転車での配達は危険。ずぶ濡れになり体調を崩すリスクもあるので、この日は配達をせず。

    翌20日も雨、21日も台風による大雨で配達できず、1円も稼ぐことができないままシルバーウイークは終盤へ。

    台風が通り過ぎ、日差しの出た22日、向かったのは東京都江東区にある都営地下鉄新宿線の西大島駅。駅周辺の大通りにはファミレスがたくさんあり、先ほど紹介したアリオ北砂も近く、モール内にたくさんの飲食店があります。また、昭和の時代に建てられた団地もたくさんあります。
