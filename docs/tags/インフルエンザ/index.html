    インフル、能登中部８倍増 患者数・前週比 金沢市は３割減(北國新聞社)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:48 配信

    北國新聞 県全域では拡大、対策呼び掛け 石川県は30日、第39週（9月21〜27日）に県内47定点医療機関から報告された季節性インフルエンザの患者数が前週比11人増の277人となったと発表した。保健所管内別では金沢市が3割減となった一方、能登中部（七尾、羽咋、志賀、中能登、宝達志水）が8倍増と急拡大。県は県内全域に感染が広がっているとして対策の徹底を呼び掛けている。

    県によると、県内の1定点医療機関当たりの患者数は5.89人（前週5.66人）で、流行基準の1.0人を4週連続で上回った。注意報を出す基準は定点当たり10.0人。

    保健所管内別では、能登中部が8.17人（1.00人）と最も多く、南加賀6.10人（6.40人）、能登北部5.75人（6.25人）、石川中央5.45人（4.55人）、金沢市5.25人（7.56人）となった。全ての地域で定点当たり5.0人を上回るのは今季初となる。

    第39週の新型コロナ患者数は前週比56人減の43人だった。1定点当たり0.91人（前週2.11人）で、保健所別では能登中部が2.17人（4.00人）で最多。金沢市は0.75人（1.88人）だった。

    ●羽咋小で集団風邪

    県は30日、羽咋市羽咋小でインフルエンザとみられる集団風邪が発生したと発表した。2年生8人が発熱などの症状を訴え、1クラスが1日まで学級閉鎖となった。今季の集団風邪の累計は16校293人。
