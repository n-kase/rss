    テレビユー福島 1日、福島県内では猪苗代町でクマが目撃されました。

    【猪苗代町翁沢字畑田】

    1日午前6時半ごろ、国道49号を車両で走行していた男性が北から南に進むクマ1頭（体長約80センチメートル）を目撃。クマはその後、猪苗代湖方面へ立ち去る。

    これまでに周辺で被害は確認されていません。

    郡山の賃貸住宅に無断で住み込んだ疑い、58歳会社員逮捕(福島民友新聞)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:21 配信

    福島県郡山市（福島民友新聞） 郡山署は30日午後8時20分ごろ、不動産侵奪の疑いで本籍福島県郡山市、住所不定、会社員の男（58）を現行犯逮捕した。逮捕容疑は、7月上旬ごろ～9月30日までの間、契約者ではないのにもかかわらず同市の戸建て賃貸住宅に勝手に住み込んだ疑い。

    同署によると、賃貸住宅は男の勤務先の会社が借り上げていたが、男に住まわせてはいなかった。被害関係者から通報を受けた警察官が現行犯逮捕した。

    福島民友新聞
