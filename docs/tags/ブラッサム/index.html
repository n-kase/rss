    珠（村上蘭）が書いた作文の内容とは？

    宿題だった「父について」の作文をようやく書き上げた珠（村上蘭）。しかし、尋常小学校の先生の提案で、その作文を父親の前で発表することになってしまう。

    珠はリョウ（国仲涼子）に相談したうえで、父・清治（渡部篤郎）に発表のことを伝える。しかし、清治はさほど興味を示さない。

    そして迎えた発表の日。まばらに父親たちが参観する教室に、清治の姿はなかった。それでも、いよいよ珠の番が回ってきたその時、清治が教室へと姿を現す。

    珠は作文の中で、父を「放蕩無頼」と表現。しかし、月夜にカナリアを見つめていた清治の表情からは、そんな言葉だけでは言い表せない何かを感じたことをつづっていた。

    作文を聞いた清治は「お前かわっちょるの」と珠の頭をなでると、その作文を周囲にも見せて回り、どこかうれしそうにはしゃぐ姿を見せる。

    それからしばらく、葉野家には穏やかな時間が流れていた。しかし、リョウが清治の大切にしていたカナリアを逃してしまったことで状況は一変する。

    カナリアがいなくなったことに激昂する清治。学校から帰宅した珠は、リョウが家を出ていったことを知る。母に置いていかれた珠は、自らカナリアを探しに向かうのだった。

    第4話では、珠の作文を通して、これまでとは違った清治の一面が描かれた。

    娘の作文をうれしそうに見せて回り、珠の頭をなでる。その姿だけを見れば、これまで描かれてきた厳しい父親とはまるで別人だ。

    しかし、その穏やかな時間は長くは続かない。カナリアをきっかけに清治は激昂し、今度はリョウが家を去ることになってしまう。

    優しいのか、恐ろしいのか。愛情があるのか、身勝手なのか。簡単には一つの言葉に収めることのできない清治という人物を、渡部が圧倒的な存在感で体現している。

    SNSでも「渡部篤郎の芝居が良すぎる…」「クズ親父なのに色っぽくて可哀想でもある…渡部篤郎の説得力」「緊張と緩和がすごい」と、その怪演に注目する声が相次いだ。

    清治の機嫌一つで、穏やかな日常が一瞬にして崩れてしまう葉野家。その中で、大好きな母までいなくなってしまった珠はどうするのか。

    カナリアを探しに飛び出した幼い珠の行く先が気になる。

    （文・野原まりこ）

    左から博多華丸、鈴木奈穂子アナ、博多大吉（Nikkan Sports News.） 石橋静河がヒロインのNHK連続テレビ小説「ブラッサム」（月～金曜）第4話が1日に放送された。

    【写真】「揺さぶられました」と漏らした大友花恋

    ※以下ネタばれを含みます。

    情報番組「あさイチ」MC陣も朝ドラ受けした。

    あらすじは、宿題であった「父について」の作文をようやく書き上げた珠（村上蘭）。しかし、尋常小学校の先生の提案で、その作文を父親の前で発表することになってしまう。珠はリョウ（国仲涼子）に相談し、そのことを清治（渡部篤郎）に伝える。しかし、清治はあまり興味を示さない。発表の日、まばらに参観する父親の中に清治の姿はなかったが、いよいよ珠の発表が回ってきた時、清治が教室にやってきて…。珠の作文に清治も笑顔を見せる。しかしある日、ふとしたことからリョウが清治の飼っていたカナリアを逃がしてしまう。清治は激しく怒り、リョウは姿を消してしまう。

    葉野珠の幼少期を演じる12歳の村上蘭があさイチにVTR出演した。鈴木奈穂子アナウンサーは「華丸さんは村上さんの目の演技がすごいと言いながら見ていましたけれど」と言うと、華丸は「もうでも、（村上の出演が今週で）終わり？ くぎ付けですよ」と語った。

    ゲストの川村エミコは「（珠が）来週女学生になって、カナリアはどうなるんでしょうか」と心配した。大吉が「（リョウは）出ていったんですかね」と話すと、川村は「戻ってきて欲しいですね」と漏らした。大友花恋は「おととさまに書いた作文が認められて良かったね～、とほっこりしていたら…この15分の中で気持ちが上がったり下がったり…揺さぶられました」と振り返った。

    「ブラッサム」は朝ドラ第115作目で、同作は明治、大正、昭和を駆け抜け、自由を求め続けた山口県出身の作家・宇野千代をモデルに、主人公・葉野珠（はの・たま）の波瀾（はらん）万丈の人生を描くオリジナル作品。石橋静河が珠を演じ、珠の高齢期を加賀まりこが演じる。

    主題歌は、YOASOBIの「咲き誇れ」。語りは三條雅幸アナウンサーが務める。
