    「元AKBで1番の勝ち組」東海オンエア・てつや＆峯岸みなみの“大豪邸”にネット衝撃「レベル違いすぎる」「想像をはるか超えてとんでもない」 ヤフーニュース

    人気YouTuberグループ「東海オンエア」のてつやが28日、YouTubeの個人チャンネル「べりたんで検索お願いします」を更新。妻で元AKB48の峯岸みなみと協議を重ね、 構想5年をかけた新居を大公開して、大きな話題となっている 。

    新居は外観から、 “てつやらしさ”が全開 。イメージカラーであるオレンジ色をモチーフとしたデザインについて、 家が特定される危険性を考慮して迷ったもののやっぱりオレンジにしようと夫婦で意見が一致 。静脈認証など 最新のセキュリティー設備を万全に整える ことで採択に至ったという。

    とにかく広い玄関や家事動線を意識したランドリールームとクローゼットの配置、フランスから取り寄せたタイルなど、動画では 新居の魅力をたっぷり1時間にわたって紹介している 。
