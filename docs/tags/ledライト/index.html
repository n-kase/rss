    ジュースでもお茶でもOK。水分さえあれば2秒後に光るLEDライト

    三浦一紀 ( GIZMODOライター )

    Image: Amazon

    完璧な防災ソリューション。

    水でもジュースでもお茶でもオシッコでも、 水分さえあれば光るLEDライト「アクモキャンドルスーパー」 。防災グッズとしてかなり頼りになる存在ですが、なんと スイッチとホイッスルが付いてパワーアップ しました。

    Advertisement

    現在12％オフの1,547円とお買い得になっています。

    スイッチが付いてさらに使いやすく

    Image: Amazon

    以前のモデルは、水に漬ければ 連続168時間点灯 するというシンプルなものでしたが、新モデルでは キャップがスイッチ になっています。ということは、明るいときは消灯しておき、暗いときだけ点灯することが可能になりました。これで、ライトの寿命を長持ちさせることができます。

    ホイッスルが付いて安心

    Image: Amazon しかも、本体下部が ホイッスル になっています。災害時に自分の居場所を知らせたいときなどに役立ちます。これ1台で、ライトもホイッスルもまかなえちゃうのは、何気にすごい。

    ライトは拡散タイプとなっており、周囲を明るく照らしてくれます。 未使用の状態で10年以上持つ ということなので、電池式や充電式の懐中電灯よりも安心かもしれませんね。
