    日本の食卓インフレは遅れてやってくる。欧州熱波、同時多発的不作がもたらす2027年の値上げ、欠品リスク(BUSINESS INSIDER JAPAN)

    10/1(木) 7:00 配信

    5 コメント 5 件

    フランス・パリの運河で遊泳するパリ市民たち。この夏、ヨーロッパは記録的な熱波に襲われていた。2026年6月17日に撮影。（Le Pictorium via Reuters Connect / Reuters） 2026年夏、ヨーロッパは40℃を超える熱波に何度も見舞われ、西欧では観測史上最も暑い6月となった。国際研究ネットワーク「World Weather Attribution（WWA）」は、この記録的熱波について人為的な気候変動の影響が極めて強いと分析している。

    【全画像をみる】日本の食卓インフレは遅れてやってくる。欧州熱波、同時多発的不作がもたらす2027年の値上げ、欠品リスク

    遠く離れたヨーロッパでの異常気象だが、筆者の推計ではその影響は2027年、値上げや欠品という形で日本の「家計」「食卓」を直撃する可能性がある。

    欧州で「歴史的不作」の農産物

    気候変動が農業に打撃を与えることはよく知られている。だが今ヨーロッパで起きている変化は、単なる農業問題から、生産、加工、物流、小売、生活者の食生活までを含む「食のサプライチェーン全体」の問題へと姿を変えている。

    今回の熱波で深刻なのは高温そのものより水不足だ。土壌から水を奪う力が桁違いに強まり、雨の量以上に畑が乾く。開花や結実という農作物にとって決定的な時期に高温と乾燥が重なれば、収穫量にも負の影響が現れる。

    被害は品目を選ばない。

    イギリスのガーディアン

    （The Guardian）によると、フランスでは野菜の収量が3割から7割落ち込み、ほぼ収穫できない農場も出たという。ワインの原料であるブドウは収穫が大幅な前倒しとなり、生産量の低下が見込まれる。

    スペインやイタリアのオリーブは高温による落果に加え、山火事による園地の焼失も重なった。トウモロコシもフランスの生産量が前年比3割以上減り、1980年以来の低水準に落ち込む見通しだ。

    畜産への波及も大きい。牧草地の乾燥で飼料の収量が落ち、生乳生産の減少、チーズやバターの生産減、食肉のコスト上昇へとつながる。冬に蓄えるはずの飼料を夏に取り崩す農家も多く、影響は翌年へ持ち越される。

    最も深刻なのは、これらが「どこか一カ所の不作」ではない点だ。フランスの生産者団体からは「通常はどこかの産地が持ちこたえて補ってくれる。だが今年は主要産地すべてが同時にやられた」という声が上がった。産地分散でリスクを吸収できるという前提が崩れつつある。

    問題は食品にとどまらない。欧州物流の大動脈ライン川では渇水による輸送制約が繰り返し発生し、川船の貨物が鉄道やトラックへ流れれば物流全体が逼迫する。生産・加工・物流が同時に圧迫される。これが気候変動時代の供給ショックだ。
