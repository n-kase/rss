    芸能界「再出発」の秋 移籍や独立続々 竜星涼がオフィスにの、藤あや子も37年所属バーニング退所

    10/1(木) 9:03 配信

    （左上から時計回りに）岩田剛典、藤あや子、竜星涼、永瀬莉子（スポーツニッポン新聞社） 2026年度の上半期が終了した9月30日から10月1日にかけ、芸能界では事務所移籍や新会社設立など、新たなスタートを切る「ご報告」が相次いだ。節目のタイミングで、それぞれが新たな道へ踏み出した。

    俳優の竜星涼は1日、二宮和也の個人事務所「オフィスにの」に所属すると発表した。

    竜星は8月31日に、芸能事務所「研音」からの退所を発表していた。新たな所属先が決まり「このたび、オフィスにのに所属することとなりました」と報告。二宮について「自分の信じた道を自分の足で歩き続ける表現者」と表現し「新しい挑戦をご一緒できることを嬉しく思います」と喜びを語った。

    演歌歌手の藤あや子は、37年間所属していた「バーニングプロダクション」とのマネジメント契約を9月いっぱいで終了し、退所していたことを1日、自身のインスタグラムで発表した。

    三代目 J SOUL BROTHERSの岩田剛典は9月30日、新会社を設立したことが所属する「LDH」の公式サイトで発表された。自身の個人プロジェクト「Be My Guest」をさらに発展させ、事業を拡大していくための設立という。

    女優・モデルの永瀬莉子も「ソニー・ミュージック・アーティスツ」を退所したと発表。永瀬は、2018年8月に「ミスセブンティーン2018」に選出され、モデル活動をスタート。19年1月放送のフジテレビ系「ココア」でテレビドラマ初出演を果たし、24年10月放送のTBS系「その着せ替え人形は恋をする」で俳優・野村康太とダブル主演を務めるなど、最も勢いのある若手女優の一人として活躍を続けている。

    俳優・歌手・声優として活躍する馬越琢己はソニー・ミュージックエンタテインメントを退所。声優の小林秀行も「ブライト イデア」を退所、声優の木村千咲もREBOOTを退所した。
