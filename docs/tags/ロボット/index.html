    歩行中でも目の前の人に気づくとすぐにピタッと止まり、道を譲れる人型ロボットが話題だ。

    米オレゴン州拠点のロボット企業、Agility Robotics（アジリティ・ロボティクス）が、人型ロボットの最新モデル「Digit 5」を発表した。

    Digit 5は、人を検知すると、とっさに自ら回避したり、立ち止まったり、しゃがみ込んだりできる。

    これまで工場や倉庫内の作業において、安全柵が必要だった人型ロボット（ヒューマノイド）だが、人間のそばで働く時代がついにやってくる。

    歩いてるときに物陰から出て来た人に気づいたとたん、すぐ止まる。

    向かい側から歩いてきた人に対し、その場ですぐにしゃがみ込むこともできる。

    この画像を大きなサイズで見る image credit:youtube

    人の存在を認識し、自ら判断して行動を変えるDigit 5。安全のための臨機応変な動きが可能になったのだ。
