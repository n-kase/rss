    ホテル滞在中、タオルでへびを作って外出→部屋に戻ったら……「めっちゃ面白いｗ」 驚きの光景に「最高のバトル」【海外】(ねとらぼ)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:30 配信

    画像はInstagramアカウント「Olya iten（@olyaodi_dii）」から引用（写真：ねとらぼ） ホテルの一室を舞台に、宿泊客と清掃スタッフの思わぬ“作品交換”が始まりました。きっかけは、宿泊客が残した1つのタオルアート。部屋に戻るたびに予想外のお返しが待っており、気付けばどんどん豪華な展開に。Instagramに投稿された動画は、記事執筆時点で50万回以上再生され、3万件の「いいね」を集めています。

    【画像】驚きの光景

    スイスに住むオーリャ（Olya）さんは、Instagramアカウント「Olya iten（@olyaodi_dii）」で旅先での出来事や自身のライフスタイルなどを紹介しています。

    今回の舞台は、滞在していたトルコのホテル。オーリャさんは以前にも清掃スタッフとのタオルアートのやりとりを投稿しており、今回はその第2弾です。

    まずオーリャさんが作ったのは、タオルを細長く巻いたへび。そこにスタッフへのチップを添え、花びらや葉っぱも飾って部屋を後にしました。

    すると、清掃後の部屋にはハート形のタオルアートが。清掃スタッフから“お返し”を受けたことで、再び宿泊客とスタッフの遊び心あふれるやりとりが始まります。

    次にオーリャさんが動物をかたどった作品を残すと、清掃スタッフは鳥をモチーフにしたタオルアートで応戦。その翌日には、オーリャさんが人形を作り、スタッフ側からはハートや白鳥を組み合わせた作品が返ってきました。

    回を重ねるほど、ベッドの上は花や葉っぱを使った華やかな空間に。もはや客室清掃のちょっとしたサービスというより、“次は何を作る？”と競い合っているような展開です。

    なお、動画に映る200トルコリラ紙幣は、現在の為替レートで1枚あたり約640円。オーリャさんのコメント返信によると、スタッフには1日あたり約6400円相当のチップを渡していたとのこと。最後にはカエルの手にナプキンを持たせ、そこにトルコ語で「ÇAY VAR（お茶あります）」とメッセージを残しました。

    作品だけで交流していた2人ですが、動画の最後にはついに清掃スタッフ本人と対面。笑顔で近づき、そのままハグを交わしました。

    コメント欄には、「ラストにハグし合うなんて素敵！」「めっちゃ面白い！」「最後の映像で、清掃スタッフも楽しんでいたことが分かってよかった」「2人とも勝負をつけられないぐらい最高だったよ」「最高のバトルだね」「私もやってみたい」と、心あたたまる結末を喜ぶ声が寄せられています。

    また、手の込んだタオルアートを作るスタッフについて、「いつもの掃除より手間がかかっただろうし、それだけオーリャさんからチップをもらう価値があったのかもね」「チップをたくさんもらえてよかった」など、スタッフを気遣う声もありました。

    タオルアートから始まった、宿泊客と清掃スタッフのユニークな交流。作品は回を重ねるごとに豪華になり、最後は2人が笑顔でハグを交わして締めくくられたのでした。※タオルアートを含む客室清掃時の対応は、ホテルや施設によって異なります。
