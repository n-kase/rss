    民間企業で働く会社員らの去年の平均給与は過去最高のおよそ487万円で5年連続で増加しました。

    国税庁によりますと、会社員やパート従業員らの去年1年間の平均給与は前の年よりも9万1000円増え、486万6000円（前年比1.9％増）で、5年連続の増加となりました。

    調査開始以降、最も高くなり、賃上げの影響があるとみられています。
