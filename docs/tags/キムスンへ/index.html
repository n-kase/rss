    39歳キム・スンへが母親に…自然分娩で女児出産(朝鮮日報日本語版)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:05 配信

    (写真：朝鮮日報日本語版)（朝鮮日報日本語版） 【NEWSIS】女性お笑いタレントのキム・スンへ（39）が母親になった。

    キム・スンへは29日、ソーシャル・ネットワーキング・サービス（SNS）に「きょう午前にうちの『ドゥンイ（胎児名）』が生まれた。自然分娩に成功した」と書き込み、娘を出産したことを伝えた。

    【写真】 キム・ヘジュン＆キム・スンへ、甘い眼差しのロマンチックなウエディング写真

    さらに「わたしたちが親になるなんて感激だ。愛情を持ってしっかり育てたい」とコメントした。あわせて公開された写真を見ると、生まれたばかりの娘を抱いたキム・スンへと、そばに寄り添っているお笑いタレントの夫キム・ヘジュン（39）の姿が収められている。

    仲間たちからの祝福メッセージも相次いだ。お笑いタレントのカン・ジェジュン、女性お笑いタレントのシム・ジンフ、モデルのソン・ヘナらがお祝いのコメントを書き込んでいる。

    キム・スンへはおよそ1年の交際を経て、2024年10月にキム・ヘジュンと結婚した。そして、結婚から2年で第一子となる女の子が誕生した。胎児名の『トゥンイ』については、以前「夫の愛称である『トゥンイ』から取ったもので、クィヨムドゥンイ（かわいい子の意）、サランドゥンイ（愛しい子の意）という意味」と打ち明けた。
