    Amazon「プライム感謝祭」の注目キャンペーン｜ふるさと納税は訪問するだけで最大12,000ポイントの抽選、Amazonフレッシュは対象商品50%OFF

    Amazonが、2026年10月16日から始まる「 プライム感謝祭 」に合わせて実施する、ふるさと納税、ネットスーパー、ビューティー、クッキングの4つのキャンペーンを発表しました。

    ふるさと納税は抽選で最大12,000ポイント、Amazonフレッシュは対象商品50%OFF

    ・ ふるさと納税イベント

    2026年9月24日から10月19日までの4週間です。地域ごとの特集が週替わりで組まれ、9月30日までは中国・四国・九州・沖縄、10月1日から6日は北海道・東北・関東、10月7日から12日は中部・関西、10月13日から19日は各地の人気返礼品が対象です。イベントページや地域応援特集を訪問するだけで抽選に参加でき、当選者は5,000名で、最高は12,000ポイント（5名）です。プライム会員は当選確率が4倍になります。

    ・ Amazonネットスーパー（Amazonフレッシュ）

    Amazonネットスーパーは、2026年10月13日から19日までセールを実施します。Amazonフレッシュでは、対象商品が50%OFFになる特選セールがあります。ほかにもライフ、成城石井などのネットスーパーが対象です。

    そのほか、2026年10月13日0時から19日23時59分までは、次の2つの特集も行われます。

    ・ 秋のBeauty Festival

    KANEBOやラ ロッシュ ポゼなどのホリデーキット（クリスマスコフレ）の先行予約や、対象のコスメ・ビューティー商品を買うとポイントがもらえるキャンペーンがあります。

    ・ 秋のクッキング祭り

    調理家電・調理器具・食料品が特別価格になり、新米・ごはん、コーヒー・ティー、本格調理・時短がテーマです。

    【91%OFF】Audibleの聴き放題が最初の4か月「月額99円」〜プライム会員の新規入会限定

    2026/09/19

    Amazonのオーディオブックサービス「 Audible 」が、聴き放題の「 Audibleプレミアムプラン 」を最初の4か月間 月額99円で使えるキャンペーンを、10月19日(月)まで実施しています。

    【リンク】 Audibleプレミアムプラン 最初の4か月 月額99円 (10/19まで)

    4か月の支払いは合計396円

    プレミアムプランは通常、初回30日間の無料体験のあと月額 1,500円 (税込)。今回は入会月を含む最初の4か月が月額 99円 となり、支払いは4か月で合計 396円 です。

    通常の無料体験から入会して4か月使うと、支払いは 4,500円 (30日無料＋月額1,500円×3か月)。差額は 4,104円(91%OFF) になる計算です。

    7月のプライムデー前に実施された「3か月無料」は、4か月目に1,500円がかかる設定でした。同じ4か月で比べると、無料の月がない今回のほうが支払いは少なくなります。

    対象はプライム会員の新規入会

    対象は、Amazonプライム会員がキャンペーン情報の表示された申込画面から新規入会した場合のみ。受付期間は 9月18日(金)10:00〜10月19日(月)23:59 で、入会前に申込画面の「月額99円」の表示を確認しておくと確実です。

    5か月目からは通常の月額1,500円で自動更新。退会はいつでもできるため、続けるか迷う場合は4か月後の更新日をカレンダーに入れておくと慌てずに済みます。

    聴き放題は数十万作品

    聴き放題の対象は、オーディオブックやポッドキャスト、Audibleオリジナル作品など数十万以上。発表で紹介された作品には、次のようなものがあります。

    Andy Weir(アンディ・ウィアー)『プロジェクト・ヘイル・メアリー』：Audible版ナレーターの井上悟が、映画の日本語吹替版にも参加

    朝井リョウ『イン・ザ・メガチャーチ』：2026年本屋大賞受賞作

    凪良ゆう『汝、星のごとく(特別版)』：10月9日公開の映画の原作。Audible向けに書き下ろしたスピンオフを収録

    湊かなえ『暁星』：音声で聴くことを前提に書き下ろしたAudibleオリジナル作品

    4か月あれば、上下巻の長編を聴き切るにも十分な長さで、通勤や運転、家事の時間がそのまま読書の時間として使えそうです。

    【45%OFF】日本限定カラー「Jackery ポータブル電源 1500 New パールホワイト」が公式サイトで予約セール中〜9月30日まで

    2026/09/17

    Jackery Japanが公式サイトで、10月中旬から順次発送となる「 ポータブル電源 1500 New 」パールホワイトの予約を、 45%OFF で受け付けています。

    パールホワイト限定の割引

    セール期間は8月12日(水)11:00から9月30日(水)23:59まで。同じ商品ページのブラックとサンドゴールドは9月17日時点で通常価格のままで、45%OFFの対象は予約販売のパールホワイトに限られます。

    パールホワイトは、Amazonの販売ページで「日本限定モデル」と銘打たれたカラー。いま注文すると支払いはセール価格で、手元に届くのは10月中旬以降です。

    ソーラーパネルとのセット「 Solar Generator 1500 New 」もパールホワイトが対象。200Wパネルとの組み合わせは48%OFFです。

    構成(パールホワイト) 通常価格 セール価格 割引率

    本体のみ 149,800円 82,390円 45%OFF

    本体＋ソーラーパネル100W 184,600円 101,530円 45%OFF

    価格は2026年9月17日時点のJackery公式サイトの表示にもとづく(税込)

    1536Whのリン酸鉄モデル

    容量は 1536Wh 、定格出力は 2000W (瞬間最大4000W)。家庭のコンセント(1500W)を上回る出力で、電子レンジや電気ストーブも動かせます。

    バッテリーはリン酸鉄リチウムイオン(LFP)で、6,000回の充放電後も容量70%を維持する設計。ACコンセントからは約1時間で80%、約1.5時間で満充電になります。

    停電時に0.01秒以内で本体からの給電へ切り替わるUPS機能も搭載。ただしJackeryは、無停電が必須のサーバーなどには接続しないよう注意書きしています。

    本体は同社の旧モデル「 ポータブル電源 1500 Pro 」と比べて、サイズが約44%小さく、重量は約15%軽量です。

    公式サイト購入は5年保証

    公式サイトで購入すると、3年保証に2年の延長保証が自動で付き、合計5年。保証登録の手続きは不要です。

    送料は全国無料。使い終えたポータブル電源の無料回収にも対応しています。
