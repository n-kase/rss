    円山応挙の国宝《雪松図屏風》が公開。三井記念美術館で「国宝 雪松図と四季」が開催(美術手帖)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 8:08 配信

    東京・日本橋の三井記念美術館で、展覧会「国宝 雪松図と四季」が開催される。会期は12月12日〜2027年1月30日。

    同館で年末年始の恒例となっている、国宝の円山応挙

    （1733〜95）《雪松図屏風》公開。本展では、この《雪松図屏風》をはじめ同館が所蔵する書画・工芸品を中心に、移りゆく四季や気象を表す技法、見立てなどに着目した展示が展開される。

    全5章で紐解く「四季」の表現

    本展は全5章で構成される。「茶道具にみる四季」では、うつわに描かれた草花や焼き物の景色・かたちに季節を見出し、銘によって象徴させた茶道具が取り上げられる。《唐物丸壺茶入

    銘淡雪》（12〜13世紀）や《瀬戸橋姫手水指 銘有明》（16〜17世紀）、応挙の下絵による蒔絵が施された《桜木地茶箱》（18世紀）などが並ぶ。

    「四季と気象を描く」では、画家や作品による気象表現の違いに焦点を当てる。国宝である応挙の《雪松図屏風》（18世紀）をはじめ、白い絵具の塗り重ねや銀砂子で応挙の《雪松図屏風》と対照的な表現を見せる山口素絢の《雪中松に鹿図屏風》（18〜19世紀）、木目を強風に見立てた酒井抱一の《秋草に兎図襖》（19世紀）、湿気を帯びた夏の夜を描いた川端玉章の「京都名所十二ヶ月」より《六月

    四条納涼》（1898）などが紹介される。また、円山派のレパートリーを示す作品として「四季海辺図屏風」4点が初展示される。

    「四季を詠む」では、古来より人々に感興をもたらしてきた詩歌を収めた書を展示。古筆のなかでも「三色紙」として尊ばれる《伝小野道風

    継色紙》（10〜11世紀）、《伝紀貫之 寸松庵色紙》（11世紀）、《伝藤原行成

    升色紙》（11世紀）の3点が同館として約6年ぶりに同時公開されるほか、古典文学にゆかりの深い蒔絵調度も紹介される。

    「四季と暮らし」では、明治の浮世絵師・水野年方による連作「三井好 都のにしき」から、雪景色のなかを出かける女性を描いた《朝の雪》（1904）などが展示される。本連作は、三井呉服店の商品広告も兼ねていたとされ、画中の女性の着用アイテムには当時の流行を見ることができる。

    「四季を束ねる」では、ひとつの画面や1組の作品に春夏秋冬をあしらった作品に着目する。春から秋、昼から夜へのときの流れを金地や金属板で収めた重要文化財《日月松鶴図屏風》（16世紀）のほか、大小の花々を描き込んだ川端玉章の《草花図額》（19〜20世紀）、中国絵画の図像を再構成した狩野栄信の《四季山水図》（19世紀）、異界としての「四方四季の庭」を描いた亀岡規礼の《酒呑童子絵巻》（19世紀）などが一堂に会する。
