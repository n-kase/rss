    Windows 11のうっとうしいポップアップ連発を凝縮体験できる「Windows 11½」

    Windows 11のユーザー体験で、改善はされたもののそれでもうっとうしいポップアップをこれでもかと体験させてくれる、「 Windows 11½ 」という誰が喜ぶのかわからないサイトが公開されています。

    Definitely Not Windows — Windows 11½

    https://definitelynotwindows.com/

    サイトにアクセスするとこんな感じでロゴマークが中央に表示され、読み込みが進みます。

    やがてデスクトップが表示されました。すると、画面左下にアシスタントのClippyが登場して説明を開始。一方、画面右下にはWindows 11½やMicrosoftアカウントのポップアップが次々と表示され始めました。

    ポップアップが止まりません。

    ポップアップは✕印をクリックすると消えるほか、しばらく待つと自動で消えます。Clippyもすべての説明を閉じると消えますが、すぐに次の発言を開始するので、ほぼ常時表示状態です。

    Edgeを開くと、Google Chromeのページを開こうとした状態になっていて、Edgeが「Microsoft EdgeはChromeと同じ技術を使用しています、ただし、すでにここに存在して削除は困難です」というメッセージを表示していました。

    OneDriveではデスクトップやマイドキュメント、マイピクチャなど、最大容量の5GBを超えるファイルをバックアップ済み。

    Microsoft Storeを開くと、中央に「それまで知らなかったけれど必要としているアプリ」のバナーが表示されています。

    WordやExcelもありますが、使用を続けたければアクティベートやサブスクリプションが必要だとのこと。

    Clippyの背後には「Definity Not Windows - Unofficial parody」との表記があります。クリックすると「Windows 11½」の説明が開き、非公式のパロディ企画であること、架空のOS体験であることなどが記されています。

    なお、Hacker Newsでは「 コンテキストメニューやスタートメニューが2秒以内に開くから偽物だとわかります 」「 ✕を押した後の反応がキビキビとして応答性が良好 」など、本物のWindows 11はもっとひどいというユーザーの声が多数寄せられていました。
