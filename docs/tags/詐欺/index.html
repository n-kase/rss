    架空の株式投資で現金だまし取ろうとしたか 中国籍の男含む3人を通報で警戒中の警察官が逮捕=静岡市葵区(静岡放送（SBS）)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:33 配信

    3 コメント 3 件

    静岡放送 9月30日、静岡市葵区で70代の無職の女性から架空の株式投資の運用資金名目で現金をだまし取ろうとした疑いで、埼玉県の男と中国籍の2人の男が現行犯逮捕されました。

    詐欺未遂の疑いで現行犯逮捕されたのは、埼玉県川越市に住む無職の61歳の男と、いずれも中国籍の40歳と35歳の男の合わせて3人です。

    警察によりますと、男らは30日、ほかの人物と共謀し、架空の株式投資の運用資金を名目に静岡市葵区に住む70代の女性に携帯電話のメッセージアプリで複数回にわたってうそのメッセージを送信し現金をだまし取ろうとした疑いが持たれています。

    投資運用会社の関係者になりすました埼玉県の男が、女性の自宅を訪問し現金を受け取ろうとしましたが、現場周辺で警戒していた警察官によって逮捕されたということです。また、警察は現場周辺で見張り役とされる中国籍の男2人を逮捕しました。

    警察によりますと、被害に遭った女性はメッセージアプリのやり取りの中で不審に思い、自ら警察署に通報し、現場で警戒していた警察官が男らを逮捕し被害を未然に防いだということです。

    警察の調べに対し、男らは容疑を否認しているということです。警察は指示役がいるとみて、引き続き捜査を進めています。

    （※写真はイメージです／PIXTA）（ゴールドオンライン） 「息子さんがトラブルを起こして、今日中に150万円必要です」そんな電話が突然かかってきたら、冷静でいられるでしょうか。「家族を名乗る電話を信じてしまい、高額なお金を振り込んでしまった」というケースがあります。一方で、電話口のちょっとした違和感をきっかけに、詐欺に気づいて被害を免れるケースもあります。今回はトータルマネーコンサルタント・CFPの新井智美氏が、思わず笑ってしまうような「犯人の演技力」がきっかけとなり、約150万円の被害を防げた事例を紹介し、電話詐欺から身を守るためのポイントを解説します。※プライバシーに配慮するため、登場人物の情報に一部変更を加えています。

    【早見表】年金に頼らず「1人で120歳まで生きる」ための貯蓄額

    息子にしては、演技が大げさすぎる

    大阪府に住む山田一郎さん（仮名・68歳）は、妻に先立たれ、現在は一人暮らしです。年金は月20万円。現役時代から少しずつ貯めてきた預貯金は約1,200万円あり、住宅ローンもすでに完済しています。

    ある平日の午前11時ごろ、自宅の固定電話が鳴りました。

    「お父さん、僕だけど……」

    電話の相手は「僕」とだけ名乗り、立て続けに話し出しました。

    「どうしよう……痴漢の疑いをかけられて、相手への示談金として150万円を払わないといけないんだ。今日中に全額払わないと警察に突き出すって言われてるんだけど、まとまったお金がなくて」

    激しく動揺している「息子らしき相手」の話を聞いているうちに、一郎さんの中にある違和感が出てきました。

    「声は似ているけど、妙に芝居がかっている……」

    「お前、なんかちょっといつもと違うな」と一郎さんがたずねると、相手は「動揺してていつも通りの話し方なんてできないよ。本当に緊急事態なんだよ」と大げさにため息をつきます。一郎さんは心の中で「いやいや、うちの息子、こんなに演技派だったかな」と思ったそうです。

    「じゃあ、警察に相談してみようか?」

    相手の言動に違和感を覚えた一郎さんでしたが、その場で相手を問い詰めるのではなく、まずは話を聞きながら息子本人なのかどうかを確かめようとしました。

    痴漢の疑いをかけられていることが本当なら、むしろ警察に相談したほうがいいんじゃないかと一郎さんが助言すると、「警察に行っても疑いが晴れるわけじゃない」「会社に知られたくないから警察には行きたくない」と答えます。

    「じゃあ、俺が今からそっちに行くから、場所を教えてくれないか」

    一郎さんがそう言うと、これまでスラスラと話していた電話口の相手が急に口ごもりました。演技ではなく、今度は明らかに動揺していたのです。

    「お前が本当に困っているなら、今から会いに行くから居場所を教えてくれ。それができないなら、自分でどうにかするしかないぞ」

    すると相手は、何も言わずに電話を切りました。

    【写真を見る】「支払いは会社に」虚偽の電話 実在の取引先を装いガソリン詐取した疑いで26歳男逮捕 余罪も捜査 北海道名寄市

    ■自動車販売店員を装う偽の電話でガソリン詐取

    9月30日、北海道名寄市のガソリンスタンドで、自動車販売店の従業員と名乗りレギュラーガソリンをだまし取ったとして、26歳の会社員の男が逮捕されました。

    詐欺の疑いで逮捕されたのは、自称・北海道旭川市に住む会社員、高坂聖也容疑者（26）です。

    高坂容疑者は、8月11日、名寄市内のガソリンスタンドに対して、ガソリンスタンドと取り引きのあった実在の自動車販売店の従業員を名乗り、「お客さんが給油しに行くので、支払いは会社に付けるように」などと虚偽の電話をかけたうえ、自身がその客であると装ってガソリンスタンドに赴き、レギュラーガソリン36.9リットル（税込販売価格6291円）をだまし取った疑いが持たれています。

    名寄市内では、同じ手口でガソリンをだまし取られる犯行が相次いでいて、そのことを知っていたガソリンスタンドの従業員が不審に思い、8月13日に警察に相談したことで事件が発覚しました。

    ■再び来店したところを通報され逃走するも逮捕

    その後、警察が捜査を進めていたところ、9月30日に高坂容疑者が再びガソリンスタンドに訪れたため、従業員が警察に通報しました。

    高坂容疑者は、従業員の通報中に、ガソリンを給油することなく、その場から走り去りました。

    付近の防犯カメラの映像などから高坂容疑者の関与が浮上し、事情を聴くなどしたところ、容疑が固まったとして逮捕しました。

    調べに対し高坂容疑者は「間違いありません」と容疑を認めているということです。

    警察は、名寄市内で多発していた同じ犯行にも高坂容疑者が関与しているとみて、さらに捜査を進めています。

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:51 配信

    静岡放送 9月下旬、静岡県湖西市に住む50代の女性が、著名ミュージシャンをかたるSNSアカウントでファンカード取得の手続きを進めたところ、現金110万円をだまし取られる特殊詐欺事件がありました。

    被害に遭ったのは、湖西市に住む50代の清掃員の女性です。

    警察によりますと、女性は9月下旬、著名ミュージシャンをかたるSNSアカウントから送られてきたファンカード取得の手続きを進めたところ、チケット代、保証金、会場代などを要求され、10万円、30万円、70万円と3回にわたって、合わせて現金110万円を指定された銀行口座に振り込み、だまし取られたということです。

    女性が新たに銀行口座に振り込もうとした際、銀行員が「詐欺ではないか」と不審に思い、女性に声をかけて警察に通報しました。

    警察は、「SNS上で現金の要求があったら詐欺」と注意を呼び掛けています。
