    東京湾アクアライン 大型ダンプカー4台絡む事故 1人重体(テレビ朝日系（ANN）)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:40 配信

    東京湾アクアラインで大型ダンプカー4台が絡む事故がありました。1人が意識不明の重体です。

    1日午前7時ごろ、東京湾アクアライン上り線川崎方面から2キロほどの地点で「車両複数台の事故」と110番通報がありました。

    警察などによりますと、大型ダンプカー4台が絡む玉突き事故があり、そのうちの1台に乗っていた1人が心肺停止の状態だということです。

    現在も救助活動が続いていて、警察が事故当時の詳しい状況を調べています。

    日本道路交通情報センターによりますと、午前8時15分からアクアライン連絡道木更津ジャンクションと東京湾アクアラインの川崎浮島ジャンクションの間の上り線が通行止めになっていて、解除の見通しは立っていないということです。

    テレビ朝日
