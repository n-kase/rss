    Appleのソフトウェアプラットフォームのメジャーアップデートが利用可能に

    Siri AI、次世代のApple Intelligence、パワフルなペアレンタルコントロール、そして広範なソフトウェアの機能強化が、本日よりiOS 27、iPadOS 27、macOS 27をはじめとするAppleプラットフォームで順次提供開始されます

    本日から提供されるAppleの最新のソフトウェアアップデートでは、Siri AIを導入し、ユーザーが毎日使うアプリをさらに賢く便利にするApple Intelligenceの新機能を提供します。

    Appleの最新のソフトウェアアップデートでは、より一層賢く、豊富な知識を持ち、有能なSiriあるSiri AIを導入することで、ユーザーが毎日使うアプリをさらに賢く、便利にするApple Intelligenceの新機能を提供します。このアップデートでは、保護者が子どものデジタル体験をより安全で豊かなものにするために役立つパワフルで直感的な新機能も導入します。また、これらによりApple製品の利便性を一段と高め、より楽しく、簡単に使えるようにするための幅広い機能強化も加わっています。

    Apple製品がかつてないほどパーソナルで便利に

    Siri AIは、次世代のApple Intelligenceを利用し、iPhone、iPad、Mac、Apple Watch、Apple Vision Proに深く組み込まれた、まったく新しいバージョンのSiriです。パーソナルコンテクストの理解、幅広い知識、オンスクリーン認識を備え、システム全体で使えるアプリ内でのアクションが充実しています。より有能かつ自然な会話ができるアシスタントであるSiri AIは、現在、ベータ版として英語で提供されており、10月には日本語、フランス語、韓国語、ポルトガル語、スペイン語にも対応します。

    Siri AIは、パーソナルコンテクストの理解、幅広い知識、オンスクリーン認識、さらにシステム全体で使えるアプリ内でのアクションの充実を実現した、より有能でより自然な会話ができるアシスタントです。

    Siri AIはメッセージ、Eメール、写真などからパーソナルコンテクストを理解して、ユーザーがその時に必要なものを見つけられるよう手助けをします。また、ユーザーの画面上のコンテンツに関する質問に答えたり、最新の情報をウェブから検索し、役立つ回答を生成することもできます。Siriは、iPhoneのカメラアプリのSiriモードに組み込まれているので、ユーザーの目の前にあるものの情報を取得し、それに対するアクションを実行できます。例えば、Apple Cashで会計を割り勘にして友人に代金を送金したり 1 、カスタムパスをウォレットに追加したりといった操作を実行できます。ビジュアルインテリジェンスにより、iPhone、iPad、Macのユーザーは、画面上で見ているものについてSiriに質問することができ、Vision Proのユーザーは、周囲を見てSiriに質問するだけで、検索したり、質問したり、アクションを実行したりできます。
