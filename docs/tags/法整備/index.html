    スパイ行為阻止へ法整備方針…刑事罰含む「外国干渉防止法」念頭、ロビー活動の登録義務化を検討

    2026/09/29 07:25

    政府は、２８日に初会合を開いたインテリジェンス（情報活動）機能の強化に関する有識者会議で、外国によるスパイ行為を阻止するための法整備を進める方針を明らかにした。

    刑事罰を含む「外国干渉防止法」（仮称）の制定が念頭にある。有識者からは国民の理解や透明性確保が不可欠との指摘が出ており、慎重に制度設計を進める。

    初会合では、当面の論点として政府が策定する「国家情報戦略」と、「外国からの不当な干渉の防止策」を重点的に議論していく方針を確認した。
