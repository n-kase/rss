    「何度もして覚えていない」同年代を装い10代少女にわいせつ動画を撮影送信させた疑いで37歳男逮捕 余罪多数か 北海道北見市(HBCニュース北海道)

    北海道放送 SNSで同年代の少女を装い、面識のない10代の少女にわいせつな動画を送信させたとして、北海道北見市の37歳の男が逮捕されました。男のスマートフォンからは多数の同様の動画が見つかっており、警察が余罪を調べています。

    【写真を見る】「何度もして覚えていない」同年代を装い10代少女にわいせつ動画を撮影送信させた疑いで37歳男逮捕 余罪多数か 北海道北見市

    ■SNSで少女を装い動画を送信させる

    SNSを介して自分自身を同年代の少女であると信じ込ませたうえで、面識のない10代の少女にわいせつな動画を撮影させ、送信させたとして、北海道警察は9月30日、北見市の37歳の会社員の男を逮捕しました。

    不同意わいせつ、児童買春・児童ポルノ禁止法違反の疑いで逮捕されたのは、北見市とん田西町に住む会社員、水野利信容疑者（37）です。

    水野容疑者は2026年1月7日ごろと、11日ごろ、SNSアプリで知り合った大分県に住む面識のない10代後半の少女に対して、自身が同年代の少女であると装い、信じ込ませたうえ、メッセージアプリへ誘導しました。

    その後も連絡を取り続けて、少女に対しわいせつな動画を撮影するよう要求し、その動画を送信させた疑いが持たれています。

    ■アカウント解析から男の関与が浮上

    少女の親族が、少女がわいせつな動画の撮影をしていることに気付き、不審に思った親族が少女と話し合い、警察に相談しました。

    相談を受けた大分県警が、SNSアカウントを解析するなどの捜査を行った結果、水野容疑者の関与が浮上し、道警が逮捕しました。

    警察の調べに対し、水野容疑者は「私がやったことではありますが、これまで同じようなことを何度もしてきたので、正直覚えていないというのが本音です」と容疑を一部否認しています。

    警察によりますと、押収した水野容疑者のスマートフォンなどから同様のわいせつな姿態が写った動画などが多数見つかったことから、警察は余罪は多数あるとみて捜査を続けています。
