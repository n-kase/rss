    コーヒーで旅する日本／四国編｜沈下橋の架かるのどかな風景に惹かれて。清流の畔にひっそりと開いた新しい憩いの場。「ミギキシコーヒー」(ウォーカープラス)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:00 配信

    古民家の一角を改装したテイクアウトカウンター（KADOKAWA） 全国的に盛り上がりを見せるコーヒーシーン。飲食店という枠を超え、さまざまなライフスタイルやカルチャーと溶け合っている。4つの県が独自のカラーを競う四国は、県ごとの喫茶文化にも個性を発揮。気鋭のロースターやバリスタが、各地で新たなコーヒーカルチャーを生み出している。そんな四国で注目のショップを紹介する当連載。店主や店長たちが推す店へと数珠つなぎで回を重ねていく。

    【写真】店への道すがら清流・仁淀川が眼下に。観光名所の浅尾沈下橋からもほど近い

    四国編の第49回は、高知県越知町の「ミギキシコーヒー」。清流として知られる仁淀川の畔、小さな集落にポツンと一軒、1年前にできたばかりのニューフェイスだ。店主の右田さんが、この地に縁を得たのも、緑深い山々と清流が織りなす風景がきっかけ。この地に移り、地域おこしに携わりつつ一念発起。以前から興味を抱いていたコーヒーで、新たな道を歩み出した。新天地で一から作り上げた店は、今も試行錯誤を続けながら、界隈の新たな憩いの場を目指している。

    Profile｜右田智貴(みぎたともき)

    1989年(平成元年)、鹿児島県生まれ。大学卒業後、土木設計会社に就職し、大阪、京都、名古屋などで勤務。2018年に四国旅行で仁淀川を訪れたのが縁で、コロナ禍の2022年に地域おこし協力隊として高知県越知町に家族で移住。協力隊の仕事の傍ら、学生時代から好きだったコーヒーを仕事にすべく自家焙煎に着手。イベント出店や豆の委託販売を経て。2025年に「ミギキシコーヒー」をオープン。

    ■高知との縁をつないだ“沈下橋のある風景”

    高知屈指の港町・須崎から海を背にして、北へ車で小一時間。道を進むほどに、切り立つ山々の緑と清流・仁淀川が織りなす、里山の風情が色濃くなる。仁淀川の名所の一つ、浅尾沈下橋にほど近い小さな集落に、ひっそりと店を構えるのが「ミギキシコーヒー」だ。山腹の斜面に立つ店の立地は複雑で、通りからは屋根しか見えない。細い道に見える看板だけが頼りだ。

    「階段を下りて、店のカウンターで目が合ったお客さんに、“本当に店があった！”と驚かれたこともあります(笑)」。そう話す、店主の右田さんが、この地と縁を得たのは2018年。まだ土木建設会社に勤務していた頃、夫婦で旅した際に訪れたのがきっかけだった。「沈下橋のある風景がずっと記憶に残っていて。あの雰囲気はよかったねと、夫婦ともに好感を持ったんです」と振り返る。その2年後、コロナ禍に入るとともに子どもも生まれ、あらためて、先々の生き方を考えたときに思い出したのが、このときに見た里山の光景だった。

    これを機に、右田さんは一念発起、2022年に移住を決め、地域おこし協力隊として3年間、観光振興でSNSやイベント開催などの活動に携わった。「実際、住んでみたらいい場所で。こっちに来てよかった。子育てにしても周りの助けてくれる人がいっぱいいて、車もほとんどこないから安心。大都市に居続けたら疲弊していたかもしれません」と振り返る。

    学生時代から好きで、移住の前からコーヒーで何かできないかという思いはあったという右田さん。とはいえ、会社員時代は、コ－ヒーそのものよりも、趣向を凝らした空間で楽しめる純喫茶に行くことが多かった。そこへ転機をもたらしたのは、大阪のスペシャルティコーヒー専門店を訪ねたときのこと。「そこでエチオピアのコーヒーを飲んだときに、こんなコーヒーがあるんだ!?と驚きました。コーヒーじゃないみたいだと。当時、漠然とコーヒーを仕事にしたいと考え始めていたので、自分が店をするならこういう味を出したいと思いました」。

    ■コーヒーを飲むシーンを靴でイメージ

    実はこの頃、右田さんは「モノを大事にする仕事がしたい」と、京都の靴修理店に転身。その傍ら、方々のコーヒー店を回る中でコーヒーを仕事にするイメージを膨らませた。「実は当時は、ロースターという仕事があるのを知らなくて(笑)。テレビや動画で見て、個人でも焙煎ができるとわかったことで、より具体的になりました」と、まずは手鍋焙煎から始めた。移住をはさんで2年ほど続けていたところ、折よく、当時訪ねた店のうちの一軒・おうちでコーヒーるるるで話を聞かせてもらったのが縁で、焙煎機を譲ってもらうことになった。
