    10/1(木) 7:14 配信

    気象庁＝東京都港区（KYODONEWS） 台風26号は1日、東京・伊豆諸島付近を北寄りに進んだ。大気の状態が非常に不安定になるとして、気象庁は落雷や竜巻などの激しい突風に注意を呼びかけた。今後、台風は日本の東に離れていき、温帯低気圧へ変わるとみられる。

    台風は1日午前6時現在、八丈島の南東約50キロを時速15キロで北東に進んだ。中心気圧は1002ヘクトパスカルで、中心付近の最大風速は18メートル、最大瞬間風速は25メートルとなっている。

    また、台風27号が太平洋のマリアナ諸島周辺で発生した。西寄りに進む見通し。
