    図鑑完成は「妻のハッパ」のおかげ 5年目になってできてないなんてありえないでしょ？ 話の肖像画 福井県立恐竜博物館副館長・寺田和雄＜27＞(産経新聞)

    家族で白山登山＝平成29年（株式会社 産経デジタル） 《妻の靖子さんは8つ年下。熊本県出身で大阪教育大学に進んだ。もともとは天文学を学びたかったという》

    実は、大学で「天文」を専門に勉強できるところはほとんどありません。主たる所は東京大学や京都大学くらいでしょうか。そこ以外なら、各地の教育大学が、理科教育の中で「天文」を学ぶことができる。大阪教育大学もそのひとつでした。

    ところが、いざ進学してみれば、天文をやりたい学生が多くて、抽選かなにかで彼女は落とされた。結局、天文に少しでも関係がありそうな「地学」を選んだらしいのです。実はそれまで地学は、大嫌いだったそうですけどね（苦笑）。

    それでも、彼女は一生懸命やって、長崎県の地質の調査をずっと続けたりして、なかなか優れた卒論を書いています。

    就職する際には、教員採用試験は受けずに、（地元の）熊本博物館の学芸員に採用されました。分野は「植物」。大学では、理科教育と地学の勉強しかしてなかったので、彼女は地域の植物の研究会に入ったりしながら、自分で植物について勉強したそうです。

    《靖子さんは、熊本大学の大学院の修士課程に通い、現生のシダの染色体を研究することに。平成14年、京都大学で研究発表を行う学会があり、「化石」の発表をした寺田さんと懇親会の2次会で出会う》

    2次会で、たまたま前の席に彼女が座った。「学生さん？」と聞くと、「いえ、熊本の博物館で働いています」という。ならばウチ（恐竜博物館）と標本の貸し借りができるかな、と思って、僕が名刺を渡したのがなれそめですかねぇ。

    その後、彼女が博物館の企画展のパンフレットを送ってくれたり、僕がやった国際シンポジウムの苦労話をメールで報告したり、福井まで来てくれた彼女に僕がつくった料理でもてなしたりして…まぁ、いろんなことがありましたよ。

    《2人は寺田さんが36歳のときに結婚した》

    （恐竜博物館に）就職したとき、僕はすでに30歳。両親を安心させないといけないし、上司や先輩の先生方が何回も女性を紹介してくださったのですが、どこかピンとこない。

    初めて「この人となら幸せになれる」と感じたのが、彼女だったというわけですね。

    本文

    9/28(月) 12:00 配信

    「日本産ジュラ紀の植物化石図鑑」の表紙（株式会社 産経デジタル） 《「日本産ジュラ紀の植物化石図鑑」の刊行（平成29年）は、財政的に厳しい地方の博物館の「生き残り方法」を模索する試みでもあった》

    【写真】標本を集めた木村達明先生

    地方の博物館が生き残ってゆくためには、所蔵している資料の存在価値を知り、普及に努めることが必要でしょう。さらには、地域ごとの特性を生かすことや人材を活用すること。

    そして、地元の人に対してもその存在意義をアピールしていかねばなりません。

    というのも、地元の人たちが博物館が所蔵している資料の価値をよく知らないことが多々あるからです。

    「ジュラ紀の植物化石図鑑」のもとになった標本を所蔵していたのは、石川県の小松市立博物館です。前にも少し触れましたが、標本を集めた木村達明先生は、一緒に研究をしていた、関戸信次先生がこの博物館の専門委員をされていた関係でここに寄贈された。でも、地元で「貴重な資料」と認識されていた人は、おそらくほとんどいなかったでしょうね。

    木村先生は、恐竜がいた時代の中生代の植物化石を調べられた著名な学者です。東京学芸大学を退官された後は、東京の大久保に研究所をつくり、研究を続けられました。

    平成13年に亡くなられましたが、集めた標本はすべて小松の博物館に寄贈したと聞いていたし、関戸先生も「全部ウチ（小松の博物館）に来ているはずだ」と話されていた。

    ところが、木村先生の論文と突き合わせてみたら標本が足りない。その後、何個かは研究所で見つかったのですが、研究者が亡くなったり、資料の価値が認識されなかったりすれば、研究者の業績も忘れられてしまうし、貴重な資料が散逸してしまいかねなかった例でしょう。

    僕はできるだけ、その地で発掘された化石などは、その地元の博物館で保存すべきだ、と思っています。「地域の特色」を打ち出すことが、地方の博物館が生き残る道の一つだ、と考えているからです。

    《地方の博物館では人件費の問題で「学芸員が1人」しかいないケースも》

    地方の博物館というのは、いわゆる「箱もの行政」で各地にたくさんできましたが、財政的には本当に厳しいところが多い。学芸員がいない博物館もいっぱいありますし、いても、1人だけという博物館もごく普通です。
