    Core Ultra 5 322搭載のミニPC「Cubi NUC AI+ 3MG-033JP」がMSIから(AKIBA PC Hotline!)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 7:30 配信

    写真：AKIBA PC Hotline!（株式会社インプレス） USBキーボード・マウスが付属するW119.6×D115.2×H37.5mmのCopilot+ PC「Cubi NUC AI+ 3MG-033JP」がMSIから登場した。

    【この記事に関する別の画像を見る】

    Amazon.co.jpなどの価格は263,800円。

    ■ Core Ultra 5 322やメモリ32GBなどを搭載したミニPC

    Cubi NUC AI+ 3MG-033JPは本体サイズがW119.6×D115.2×H37.5mmのPC。Intel Core Ultra 5 322、32GB（16GB×2）のDDR5メモリ、512GBのM.2 NVMe SSD、Windows 11 Proを搭載するCopilot+ PCで、キーボードにCopilotボタンを備えAIアシスタントを手軽に活用できるとしている。

    Thunderbolt 4×2、HDMI 2.1×2を使用し最大4画面の映像出力に対応するほか、2.5G LAN×2、Wi-Fi 7（320MHz帯には非対応）、Bluetooth 5.3を搭載。また、指紋認証、TPM 2.0、ケンジントンロックなどビジネス用途に必要な高いセキュリティ機能を搭載したとしている。

    MSI Power Link機能により対応MSI製モニターの電源ボタンとの連動が可能。また、付属のマウントブラケットを使用して対応モニターの背面に設置でき、電源スイッチ延長ケーブルによりモニター背面設置時でも利便性を確保するとしている。

    フロントI/OポートはUSB 3.2 Gen2 Type-C×1、USB 3.2 Gen2 Type-A×1、USB 2.0 Type-A×1、電源ボタン一体型指紋センサー×1。リアI/OポートはThunderbolt 4×2、有線LAN×2、HDMI 2.1×2。

    付属品はUSBキーボード・マウス×1、電源スイッチ延長ケーブル×1、電源ケーブル×1、ACアダプタ×1、VESAマウントブラケット（75/100対応）×1、VESAマウントブラケット取付ネジ×4、ケーブル脱落防止クリップ×1、クイックスタートガイド×1。
