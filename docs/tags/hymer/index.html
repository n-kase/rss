    トイファクトリー、キャンピングカーの名門ドイツ「HYMER」のB-MCシリーズ2台限定発売 価格3493万6000円から

    編集部：塩谷公邦

    2026年9月28日 13:24

    2026年10月3日 発表 B-MC T680：3493万6000円 B-MC I600：3824万7000円

    キャンピングカーの名門ドイツ「HYMER」のフルインテグレーテッドモデル「B-MC I600」

    キャンピングカーを手掛けるトイファクトリーは、10月3日～4日に開催する「EURO-TOY モーターホームコレクション」にて、ドイツのプレミアムブランド「Hymer（ハイマー）」のモーターホーム「B-MC T680」および「B-MC I600」を各1台ずつ限定販売する。価格はB-MC T680が3493万6000円、B-MC I600が3824万7000円。

    B-MCは「B-Class ModernComfort」の意味で、メルセデス・ベンツの「スプリンター417 CDI」をベースに、HYMER独自のSLC（Super Light Chassis）を組み合わせたプレミアムモーターホームシリーズ。軽量化と走行安定性を追求したSLCシャシーに加え、独自の「PUAL構造」による優れた断熱性など、HYMERならではの技術が随所に取り入れられている。

    B-MC T680（5名乗車/4～5名就寝）

    ベース車両がメルセデス・ベンツの「スプリンター（Sprinter）417 CDI」のセミインテグレーテッドモデル「HYMER B-MC T680」は、全長約7.4mのボディサイズを生かしたゆとりあるレイアウトと、独立シャワーを備えた快適な水まわりが魅力の1台。

    HYMER B-MC T680

    居住空間は、木目を生かした上質な家具仕上げと、LED照明、アンビエントライトにより、落ち着きのある快適な空間にまとめているほか、前方のシートエリアはゆったりと設計され、セミインテグレーテッドならではの大きなパノラマルーフベントによる採光、室内空間を両立。

    就寝定員は最大4名で、後方にツインベッド、前方にプルダウンベッドを備え、快適な居住性とプレミアム感を兼ね備えている。夫婦からファミリーまで過ごせる空間で旅を楽しめる。

    居住空間は、木目を生かした上質な家具仕上げと、LED照明、アンビエントライトにより、落ち着きのある快適な空間にまとめられている

    後方ベッドのサイズは2000×840mm（長さ×幅）および1880×840mm

    プルダウンベッドのサイズは1880×1300～1050mm（長さ×幅）

    キッチンは、コンプレッサー式冷蔵庫（150L）、深型シンク、ソフトクローズ機能付きの収納などを備え、使いやすさとデザイン性を両立。サニタリールームはB-MC T680ならではの独立シャワーを備えた構成が大きな特徴。トイレ・洗面スペースとシャワールームを分けることで、長期滞在や複数人での利用時にも快適性を保ちやすいレイアウトとなっている。

    キッチンはコンプレッサー式冷蔵庫（150L）、深型シンク、ソフトクローズ機能付きの収納などを備える

    サニタリールームは独立シャワーを備える

    室内レイアウト

    B-MC I600（5名乗車/4名就寝）

    HYMER B-MC I600（5名乗車/4名就寝）。ボディサイズは7190×2290×2980mm（全長×全幅×全高）。免許は準中型免許（3.5t以上）が必要

    同じくメルセデス・ベンツの「スプリンター（Sprinter）417 CDI」がベース車両の、フルインテグレーテッドモデル「HYMER B-MC I 600」。フロントまで一体設計された伸びやかなボディデザインと、HYMERらしい上質なインテリアが魅力の1台。

    居住空間は、洗練された高級木材とレザーで統一され、LED照明やアンビエントライトによって、上質で心地よい室内空間を演出。L字型のシートラウンジや大きなフロントまわりの開放感も、フルインテグレーテッドモデルならではの魅力を備えている。

    居住空間は高級木材とレザーで統一。LED照明やアンビエントライトで上質で心地よい室内空間に仕上げている

    後方ベッドのサイズは1950×840mm（長さ×幅）または1870×840mm（長さ×幅）

    プルダウンベッドのサイズは1940×1450mm（長さ×幅）

    就寝定員は最大4名。後方にツインベッド、前方にプルダウンベッドを備え、快適な居住性を確保したことで、快適なベッドスペースでゆったりとした眠りを楽しめる。サニタリールームは、トイレとシャワーをひとつの空間にまとめた2Wayで切り替える転換式。必要な機能をコンパクトにまとめながら、快適性にも配慮されたスペースに仕上げている。
