    西武渋谷店 58年の歴史に幕(ABEMA TIMES)

    2026年10月1日 カテゴリー ニュース

    10/1(木) 9:33 配信

    西武渋谷店（ABEMA TIMES） 百貨店の西武渋谷店が9月30日、営業を終了しました。58年の歴史に幕を下ろしました。

    【映像】58年の歴史に幕を下ろした西武渋谷店

    閉店したのは、西武渋谷店の「A館」「B館」と「パーキング館」です。周辺の再開発をめぐり地権者と合意ができず、閉店に至りました。

    西武渋谷店は、1968年4月に開店し、最先端のファッションを紹介するなど文化の発信地としても機能してきました。

    運営するそごう・西武は、社内で配置転換を行い勤務していた社員の雇用は継続するとしています。（ANNニュース）
