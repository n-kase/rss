    英空軍基地のテロ計画、イラン関与の「強い兆候」 英首相が発言(CNN.co.jp)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:21 配信

    3 コメント 3 件

    リバプールで開催された英国労働党の年次党大会で演説するバーナム英首相＝9月30日（Phil Noble/Reuters） ロンドン（CNN） 英国のバーナム首相は30日、米軍が使用する英空軍基地を標的にしたとされる先週末の計画について、イランが関与したことを示す「強い兆候」があると述べた。事件に外国勢力が関与したとする米国の見解を支持した形だ。

    バーナム氏は公共放送BBCに対し、「週末に英空軍フェアフォード基地で起きた出来事にイランが関与したことを示す強い兆候がある。ただし、警察による複雑かつ重大な捜査は現在も続いている」と述べた。

    「いずれ詳細を明らかにするが、イランが関与したと我々が確信していることは明言できる」とした上で、現時点ではこれ以上の詳細は明かさないとした。

    「当然ながら、軽々しく言っているわけではない」とも述べた。

    さらにバーナム氏は、英国が米国側と「緊密に」連携していると説明した。

    米国のルビオ国務長官は29日、トランプ米大統領が容疑者らについてイランと関係している「可能性がある」と発言したことを受け、今回のテロ計画容疑に関し、「明らかに外国勢力が関与していた」と述べていた。

    イランは関与を強く否定している。在ロンドン・イラン大使館も、イラン政府と事件との関連を示唆する報道を批判し、イランの関与をめぐる「根拠のない悪意ある臆測を断固として否定し、強く非難する」と表明した。

    イランのアラグチ外相は30日、英国について「見当違いだ」と述べた。

    今回の事件は現場周辺で大規模な警戒態勢が敷かれ、国際的な警戒も招いた。事件をめぐっては、大西洋の両岸で今もなお多くの疑問が残されたままとなっている。

    バーナム英首相（ABEMA TIMES） イギリスのバーナム首相がEU＝ヨーロッパ連合への再加盟を検討する可能性に含みを持たせる発言をしました。「国民に選択肢を提示していく」としています。

    【映像】バーナム英首相のEU再加盟をめぐる発言

    英バーナム首相「ブレグジット（EU離脱）は利益より害の方が大きかった。世論の約60％がこの見方に同意していると考えます。この事実に正面から向き合い、国民が検討、判断できる具体的な選択肢を提示していきます」

    イギリスのバーナム首相は30日に公開されたBBCのインタビューでEUへの再加盟を望むか問われた際にこのように述べ、再加盟を検討する可能性に含みをもたせました。選択肢としては単一市場や関税同盟への参加もあるとしています。

    イギリスは2016年にキャメロン政権の下で実施した国民投票でEUからの離脱を決めました。

    バーナム首相は再加盟を公約に掲げてはいませんが、長期的には再加盟を支持する発言をしています。

    29日に開催された与党労働党大会の演説では、EUから離脱したことで「移民管理が弱体化し」と主張していました。（ANNニュース）

    50歳からの贅沢なイギリス留学…リビエラ･トーキーで叶える「オトナ留学」の神髄 現地の「豊かな日常」をご紹介(東洋経済オンライン)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:46 配信

    トーキーの美しい街並み （写真：筆者撮影）（東洋経済オンライン） 人生の後半に差し掛かり、新たな学びや挑戦を求めて海外へ旅立つ大人の留学。円安や情勢の変化など海外渡航へのハードルが意識される時代ですが、大人世代が求める留学の価値は、単なる英語能力の向上にとどまらないものへと進化しています。

    【写真を見る】世界中から愛される港町・トーキー

    若者と同じように文法や試験のスコアを競うのではなく、これまでの人生で培ってきた豊富な経験や価値観を持ち寄り、異国の地で深く分かち合うこと。それこそが、大人ならではの留学生活を真に豊かなものにしてくれます。

    今回筆者が訪れたのは、イギリス南西部デヴォン州に位置し、イングリッシュ・リビエラ(English Riviera)の愛称で世界中から愛される港町・トーキー(Torquay)です。温暖な気候、ヤシの木が揺れる美しい海岸線、そしてゆったりとした時間の流れ。この魅惑的なリゾート地で展開されている「50+(フィフティープラス)」プログラムの実態と、現地で体感したオトナ留学の醍醐味をお届けします。

    ■英国リゾートの朝、海辺の風に溶け込む日常の豊かさ

    ロンドンでの会議を前に、筆者は英国南西部のトーキーへ渡りました。現地に到着して迎えた最初の朝、海外出張時の恒例にしている早朝のランニングへ繰り出しました。

    イングリッシュ・リビエラと呼ばれるトーキーの海沿い約10キロを走ります。目の前に広がるのは、青く輝く海と白いヨットハーバー、そして特徴的な赤い崖の海岸線。この街で生まれ育ったミステリーの女王アガサ・クリスティの像が海を見守るように佇んでいます。

    走りながら特に印象的だったのは、海辺の美しい風景とアート、そして地元の人々の暮らしがごく自然に結びついていることでした。コースの途中には、ルノワールなどの名画を紹介する屋外展示パネルが点在しており、画家たちが描いたキャンバスの風景と、いま目の前にある実際の景色を重ね合わせて楽しむことができます。

    犬の散歩や朝のランニングを楽しむ地元の人々と、アイコンタクトと笑顔で挨拶を交わしながら進むうちに、単なる観光旅行では見えてこない、この街の日常のグラデーションが少しずつ見えてきました。
