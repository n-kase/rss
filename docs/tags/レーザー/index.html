    高さ8mからレーザー照射 鳥獣追い払う「たおれん棒」ドローン技術応用(日本農業新聞)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:30 配信

    たおれん棒（NTTイードローン提供）（日本農業新聞） NTTイードローン（埼玉県朝霞市）は、鳥が嫌がるレーザー光を最大高さ8メートルから照射する、手持ち式の追い払い資材「たおれん棒（鳥獣害対策タイプ）」を発売。同社のドローン技術を応用し、伸縮性の棒を高く伸ばしても安定して保持できるようにした。

    動画：畜産現場では「カラス撃退レーザー」が効果を発揮

    棒の上端には、赤緑2色の忌避レーザーを照射する装置が付いている。作業者はこの棒を高く掲げて、施設の屋根周辺や樹木といった、鳥類のすみかに照射して追い払う。高所に集まる鳥を地上から機動的に追い払うことができるとしている。

    手持ちでも安定させるために、複数のプロペラの回転を制御して、棒が直立するように補助する機能を備えている。1人でも簡単に扱えるとする。

    価格は99万円（税別）。問い合わせは同社サービス推進部、agri＠nttedt．co．jp。
