    東京圏でPixel 10aが4週ぶりに首位 Androidスマホ人気ランキングTOP10 2026/10/1(BCN)

    2026年10月1日 カテゴリー 未分類

    Pixel 10a 128GB(au)（株式会社BCN） 「BCNランキング」2026年9月21日～27日の日次集計データ・東京圏（東京都・神奈川県・千葉県・埼玉県）によると、Androidスマートフォン（スマホ）機種別の実売台数ランキングは以下の通りとなった。

    【写真ギャラリー】

    1位 Pixel 10a 128GB(au)（Google）

    2位 Galaxy S26 256GB(SoftBank)（SAMSUNG）

    3位 arrows We3 F-52G（FCNT）

    4位 moto g06（Motorola Mobility）

    5位 A5 5G(au)（OPPO）

    6位 Galaxy A25 5G SC-53F（SAMSUNG）

    7位 Pixel 10a 128GB(NTT docomo)（Google）

    8位 AQUOS sense10 SH-M33 6GB+128GB（シャープ）

    9位 Pixel 11 256GB(NTT docomo)（Google）

    10位 Galaxy S26 SC-51G 256GB（SAMSUNG）
