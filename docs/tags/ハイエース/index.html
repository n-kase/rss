    犬や猫との車中泊、暑さと傷はどうする？ 家庭用エアコンと引っかきに強いシートを標準装備したキャンピングカー(MotorFan)

    写真：Motor-Fan（山崎 友貴） レクビィが手がける「ソラン」。今回紹介するのは、ハイエースのワイドボディ・ミドルルーフ仕様であるワゴンGLをベースとするバンコンだ。家庭用エアコンやFFヒーター、リチウムイオンバッテリーを標準で備え、シート生地には引っかきに強い素材を使う。ペットとの車中泊を想定した1台である。

    【写真】犬や猫との車中泊、暑さと傷はどうする？ 家庭用エアコンと引っかきに強いシートを標準装備したキャンピングカー

    バンコンなのにゆとりの北欧風空間｜レクビィ・ソラン

    ワゴンGLがベースのソランは、全長4840×全幅1925×全高2115mmというサイズ。（山崎 友貴）

    北欧調のインテリアが居心地の良さを演出する。（山崎 友貴）

    天板下に49Lの電気冷蔵庫を内蔵。カセットガス式コンロも標準で付く。（山崎 友貴）

    右側に横向き２人掛けソファベッド、左側に１人掛けREVOシートを配置する。（山崎 友貴）

    出窓部分に収まる家庭用エアコン。室外機は床下に設置されている。（山崎 友貴）

    ペットベッドをオプションで用意。（山崎 友貴）

    シートの生地は引っかきに強く、防汚・防水性も高い。オプションで生地の変更も可能だ。（山崎 友貴）

    天井の木目パネルにLEDを配置。（山崎 友貴） バンコンのベース車両でベーシックなトヨタ・ハイエースの生産量が伸び悩んでいるため、キャンピングカー市場は現在、製造に苦労している。そんなハイエースの中でも、比較的納車期間が短いということで、昨今増えているのがワイドボディ車ベースのモデルだ。

    レクビィの「SOLAN（ソラン）」には、ハイエースの標準ボディ（標準ルーフ/ハイルーフ）、ワイドボディ・ミドルルーフ、スーパーロングをベースとする4タイプがある。今回取り上げたワイドミドルは、ハイエース・ワゴンGLがベースだ。もともと多人数乗車を身上としているワゴンは、車内スペースにゆとりがあるのが美点だ。その居住スペースを、余すところなく車中泊用に使っている。

    まず、ソランで紹介しておきたいのが、その可愛らしいエクステリアカラー。取材車両はミントグリーンとホワイトのツートーンに塗られており、ボディに合わせてホワイトのスチール調クラシカルアルミホイールとホワイトレタータイヤが奢られている。女性やファミリーにもフレンドリーな外観だ。

    車内は、北欧調のインテリアで統一されている。家具や飾り板に使われているのは、ホワイトウッド調の合板。見た目の風合いが柔らかく、心地よく優しいインテリアとなっている。

    サイドドアから入ると、まずシンクが備わっている。洗いものをするには小振りだが、歯磨きや給水なら実用的に使えそうだ。逆サイドには調理テーブルが。トップには洒落たタイルが張られ、作業スペースは十分に広い。これなら、コンロを置いたとしても調理スペースは残る。

    後部はカギ形にシートが配置され、さらにテーブルを囲むようにセカンドシート1脚がインストールされている。セカンドシートは前向きにするとリクライニングシートになるため、ゆったりと昼寝をしたり読書をするといった使い方ができるのがうれしい。

    後部のシートはマットを並べることで、縦183（最大210）cm、横165cmのベッドに変身。大人2名がゆったりと休むことができる就寝スペースだ。

    車内での快適性をサポートしてくれるのが、標準装備のエアコンだ。後部窓を出窓に改造することで、家庭用の100Vエアコンが装備されている。サブのリチウムイオンバッテリーは300Ah。1日中の使用とはいかなくても、就寝時から明け方までは涼しく寝られそうである。冬もエアコンが活躍してくれるが、FFヒーターも装備されているので、寒冷地はこちらの方が暖かい。

    なお、このソランはペットとの車中泊を考慮したモデルとなっている。シート生地に傷や汚れに強いものを使い、ペットを安心して同乗できる。また運転席と助手席の間に付けるペットベッドをオプションで用意。いつも愛犬と一緒にいたいという飼い主の気持ちに、見事に応えたモデルなのだ。

    それに内外観とも、雰囲気が非常にいい。北欧風のコーディネイトは四季を問わず気持ちが落ち着くし、同時に高級感も備えている。飽きがこないというのも、長く乗りたい人には魅力となるだろう。
