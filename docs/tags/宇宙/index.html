    ボーイングの新型宇宙船「スターライナー」早ければ2026年12月にもISSへの無人ミッション実施へ(sorae 宇宙へのポータルサイト)

    2026年9月30日 カテゴリー ニュース

    本文

    9/30(水) 11:33 配信

    2024年9月、CFTミッションの帰還に向けて無人の状態でISS（国際宇宙ステーション）を離脱するBoeing（ボーイング）の有人宇宙船「Starliner（スターライナー）」（Credit: NASA） NASA（アメリカ航空宇宙局）と航空機大手Boeing（ボーイング）は2026年9月28日付で、Boeingの新型宇宙船「Starliner（スターライナー）」に関する今後の計画を発表しました。有人飛行試験におけるトラブルが“重大事故”に認定されたStarlinerは、改良の効果をISS（国際宇宙ステーション）への無人飛行ミッションで確かめたうえで、本格的な有人飛行ミッションの開始を目指します。

    NASAがスターライナーの有人飛行試験を“最も重大な事故”に認定 調査報告書を公表

    Starlinerは2024年6月の有人飛行試験「CFT（Crew Flight Test）」でISSに到着したものの、接近中に推進システムの不具合が相次ぎ、機体は無人で帰還しました。搭乗していた2名の宇宙飛行士は、2025年3月にSpaceX（スペースX）の「Crew Dragon（クルードラゴン）」宇宙船で地球へ帰還しています。

    NASAが2026年2月に公表した調査報告書によると、帰還前に切り離される「サービスモジュール」の姿勢制御用スラスターが認定された条件を逸脱して作動したことが、機体の制御を一時的に失う原因となりました。NASAとBoeingは地上での試験や解析を通じて、このスラスターの性能低下が熱環境や設計に内在する特徴を含む複数の要因によって生じていたことを突き止めています。

    無人ミッション「Starliner-1」で改良を検証

    スラスターを噴射しつつISS（国際宇宙ステーション）から離れていくStarliner（スターライナー）宇宙船（Credit: NASA+） Boeingはすでにサービスモジュールの熱対策を施しており、NASAはStarlinerによる次のミッション「Starliner-1」でその効果を評価します。ISSへ物資を運ぶStarliner-1は無人のミッションで、2026年12月～2027年1月に打ち上げられる可能性があります。

    一方、サービスモジュールの推進システムで使用されているバルブの弁（ポペット）のシールが変形して押し出される問題に対処するため、Starliner-1の後にはバルブの設計変更も完了する予定です。
