    東京湾アクアラインで大型ダンプカー4台が絡む事故がありました。1人が意識不明の重体です。

    1日午前7時ごろ、東京湾アクアライン上り線川崎方面から2キロほどの地点で「車両複数台の事故」と110番通報がありました。

    現場は森岳小学校近くの住宅地を通る町道の交差点です。
