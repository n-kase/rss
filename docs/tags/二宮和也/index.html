    「オフィスにの」に所属

    二宮和也（右）と「オフィスにの」に所属した竜星涼（ENCOUNT） 俳優の竜星涼が1日、二宮和也の個人事務所「オフィスにの」に所属することを発表した。

    【写真】竜星涼が公開した10年ぶりの“再会”2ショット「眼福」「懐かしいですね！」

    今年8月、デビューから16年間所属した芸能事務所・研音を退所したことを報告した竜星。新たな所属先に選んだのは、TBS系連続ドラマ『VIVANT』（日曜午後9時）で共演する先輩・二宮の個人事務所だった。

    竜星は「二宮和也さんという、自分の信じた道を自分の足で歩き続ける表現者と、新しい挑戦をご一緒できることを嬉しく思います」とコメント。「リスペクトを胸に、僕は僕らしく。まだ見たことのない景色へ、臆することなく挑んでいきたいと思います」と意気込んだ。

    また、今回の選択について「守るためではなく、攻めるための新しいスタートです」と説明している。

    オフィスにのも、「これからさまざまなことに挑戦しながら、面白いことを。皆様とともに、歩んでいければと思います。竜星涼、そしてオフィスにのをこれからも何卒よろしくお願い申し上げます」とメッセージを送っている。
