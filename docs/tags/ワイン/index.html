    仏ソムリエらが選ぶ「日本のお酒」 山梨の日本酒が「最高賞」 富山ワインや熊本焼酎も(テレビ朝日系（ANN）)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:39 配信

    “仏ソムリエらが選ぶ「日本のお酒」 山梨の日本酒が「最高賞」 富山ワインや熊本焼酎も”（All Nippon NewsNetwork(ANN)） フランス・パリで一流のソムリエらが「日本のお酒」の最高峰を選ぶコンクールの授賞式が行われ、山梨県の日本酒が最高賞に選ばれました。

    「Kura Master 2026」は、フランス・パリで一流のソムリエらが日本酒やワインなど日本のお酒の最高峰を選ぶコンクールで、今年で10回目の開催となります。

    今年は1252もの銘柄から応募があり、5つ星ホテルやミシュラン星付きのレストランのトップソムリエなど125人が審査を担当しました。

    日本酒部門で最高賞となる「プレジデント賞」に選ばれたのは、山梨県の蔵元、山梨銘醸の「七賢スパークリング星ノ輝」です。

    伝統を継承しながらも、未来や新しい流行に目を向けて挑戦する酒造りが評価されました。

    このほか、ワイン部門では富山県の「R359」が、焼酎部門では熊本県の「麦汁」、リキュール部門では鳥取県の「Chiyomusubi ULTRA YUZU」がそれぞれ「プレジデント賞」に選ばれました。
