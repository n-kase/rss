    「千鳥」大悟プロデュース「THE ONE SHOT」早くもシーズン2決定！「次はどんな芸人が出てくるのか」(映画.com)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:00 配信

    1 コメント 1 件

    シーズン2決定（(c)FANY Studio） お笑いコンビ「千鳥」大悟がエグゼクティブプロデューサーを務める日本のディズニープラス初となるオリジナルバラエティ番組「THE ONE SHOT」（読み：ザ・ワンショット）が2026年、ディズニープラスで配信された日本発のバラエティ作品の中で、世界・アジア・日本のすべての地域で視聴数No.1（※配信開始後14日間の視聴実績に基づく）を記録する好スタートを切ったことがわかった。

    この驚異的な記録の達成と、大きな反響を受けて、早くもシーズン2の始動が決定。大悟からのコメント映像（https://youtu.be/KyBKI3NGW6o）が到着した。

    大悟がディズニープラスとタッグを組み、エグゼクティブプロデューサーとして世界へ仕掛ける本番組。大悟自らが選び抜いた、M-1グランプリやキングオブコントなどの賞レースをはじめ、お笑い界の第一線で活躍する8人の芸人が、自ら脚本・監督を務め、3カ月という期間の中で本気でショートフィルム制作に挑む。

    課せられたルールは「作品の中に1つだけボケを入れろ」――たったそれだけ。大悟の号令で集まった“ボケの精鋭”たちが、ストーリー構成、演出力、そして笑いのセンスを総動員し、渾身のボケを際立たせるため「いかに最高のフリを作れるか？」という、究極のお笑いプロデュースバトルを繰り広げる。

    現在配信中のシーズン1では、「ネプチューン」堀内健、「ロバート」秋山竜次、「ピース」又吉直樹、「ジャルジャル」後藤淳平、「かまいたち」山内健司、天竺川原、「シソンヌ」じろう、「ランジャタイ」国崎和也が、初代王者の称号“GOLDEN ONE SHOT”をかけてしのぎを削った。

    SNS上では「本当に面白い。これは革命」「芸人さんたちのクセが光る作品ばかり」「俳優さんたちもさすがだし、芸人たちの脚本が素晴らしくて、ショートフィルム普通に見入っちゃう」と、そのクオリティの高さと渾身のボケの破壊力が熱い反響を呼び、大盛り上がりを見せている。

    果たして、シーズン2ではどんな挑戦者たちによる「ONE SHOT」を見ることができるのだろうか？ 芸人以外の参戦にも期待が膨らむ。

    「THE ONE SHOT」シーズン1（全8話）はディズニープラスで配信中。以下、大悟から届いたコメント全文。

    ▼エグゼクティブプロデューサー 大悟（千鳥）コメント

    「THE ONE SHOT」エグゼクティブプロデューサーの千鳥・大悟です。なんと、もうシーズン2をやることになりました。私が一番驚いています。

    世界でも、アジアでも、日本でも、ディズニープラスのバラエティ作品としてたくさんの方に観ていただいているそうで、本当にありがとうございます！

    まさかこんなに早くシーズン2をやることになるとは思っていませんでした。次はどんな芸人が出てくるのか。そのへんは相変わらずまだ何も決まっていません。

    でも、だからこそ楽しみにしてもらえたらうれしいです。もし「我こそは！」という方がおったら、ぜひ私まで連絡ください。

    そして、まだ「THE ONE SHOT」を観たことがないという方も、シーズン2が始まるまでにまだ時間があります。ぜひディズニープラスでシーズン1をお楽しみください。芸人のみなさん、新しい挑戦待ってます！

    千鳥・大悟×ディズニープラス『THE ONE SHOT』シーズン2決定「私が一番驚いています」 挑戦者を募集(オリコン)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:00 配信

    千鳥・大悟×ディズニープラス『THE ONE SHOT』シーズン2決定（C）FANY Studio（オリコン） ディズニー公式動画配信サービス「Disney+ （ディズニープラス）」のスターにて配信中のオリジナルバラエティ番組『THE ONE SHOT』（ザ・ワンショット）。お笑いコンビ・千鳥の大悟が企画・プロデュースし、エグゼクティブプロデューサーを務める同番組のシーズン2制作が決定した。大悟は「なんと、もうシーズン2をやることになりました。私が一番驚いています」とコメントを寄せた。

    【動画】『THE ONE SHOT』シーズン2決定、千鳥・大悟コメント映像

    日本のディズニープラス初のオリジナルバラエティ番組となる本作は、「映画」と「お笑い」を掛け合わせた新たな笑いの大会。芸人たちが自ら脚本・監督を務めてショートフィルムを制作し、「作品の中に“1つ”だけボケを入れろ」というルールのもと、考え抜いたフリと一つのボケで競い合う。

    ディズニーによると、2026年にディズニープラスで配信された日本発のバラエティ作品の中で、配信開始後14日間の視聴実績に基づき、世界・アジア・日本のすべてで視聴数1位を記録。この反響を受け、早くも続編の制作が決まった。

    全話独占配信中のシーズン1には、大悟が選んだ堀内健（ネプチューン）、秋山竜次（ロバート）、又吉直樹（ピース）、後藤淳平（ジャルジャル）、山内健司（かまいたち）、天竺川原、じろう（シソンヌ）、国崎和也（ランジャタイ）の8人が参加。3か月をかけて作品を制作し、初代王者の称号「GOLDEN ONE SHOT」を目指して戦った。

    シーズン2の出演者や配信時期など、詳細は未定。大悟は「次はどんな芸人が出てくるのか。そのへんは相変わらずまだ何も決まっていません。でも、だからこそ楽しみにしてもらえたらうれしいです」と語り、「もし『我こそは！』という方がおったら、ぜひ私まで連絡ください」と呼びかけている。

    また、視聴者に向けて「まだ『THE ONE SHOT』を観たことがないという方も、シーズン2が始まるまでにまだ時間があります。ぜひディズニープラスでシーズン1をお楽しみください」とメッセージを送り、「芸人のみなさん、新しい挑戦待ってます！」と呼びかけている。

    【動画】「まさかこんなに早くやることになるとは」とシーズン2決定について語る千鳥・大悟

    千鳥・大悟がエグゼクティブプロデューサーとして世界へ仕掛ける本番組は、「映画」と「お笑い」を掛け合わせた、まったく新しいお笑いプロデュースバトル。

    大悟自らが選び抜いた芸人“8人”が、3ヵ月という期間の中で自ら脚本・監督を務めたショートフィルムを本気で制作。課せられたルールは、【作品の中に“1つ”だけボケを入れろ】――たったそれだけ。考え抜かれたフリと、たった１つのボケで競い合う、芸人たちの“真の力”が試される前代未聞の新たな大会となっている。

    シーズン1では、堀内健（ネプチューン）、秋山竜次（ロバート）、又吉直樹（ピース）、後藤淳平（ジャルジャル）、山内健司（かまいたち）、天竺川原、じろう（シソンヌ）、国崎和也（ランジャタイ）という、ボケの精鋭8人が、初代THE ONE SHOT王者の称号“GOLDEN ONE SHOT”の座をかけて熱い戦いを繰り広げた。
