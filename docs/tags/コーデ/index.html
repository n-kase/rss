    今時期にめっちゃ使えるTシャツがこれ！ 【着こなし編】(Web LEON)

    いくら残暑だからって、もう9月だというのにボーダーTシャツ？ いえいえ、実は今時期こそがボーダーTの使いドコロなんです！ 初秋のハンパなシーズンのお洒落に、めっちゃ使えますよ！

    キモが作りづらい残暑コーデのお助け役！

    ▲ キモが作りづらい残暑コーデのお助け役！（LEON.JP） もちろん真夏の太陽がお似合いでもあるんですが、ボーダーTシャツは夏が終わってからも活躍してくれる柄なんです。というのも、9月の秋口は、まだ暑さが残っているといってもいかにも夏っぽいコーデは季節外れ感があるし、一方で重ね着して秋を先取りしすぎても汗ダクになってしまう……。つまり、まだアイテム数が少ないなかでお洒落を演出しなければいけないシーズンなのです。

    そこで、柄物であるボーダーTの出番。夏の余韻を残しつつ、ニットの肩掛けやジャケットオンにより、秋の訪れも匂わせられるってヤリクチです。とはいえ、夏のイメージが強烈なボーダーなので、マリンのイメージが強い青白じゃなく黒白をチョイスするってのが正解。このさわやかすぎないってのが重要なんです。

    今回は、白黒ボーダーTを取り入れた、今時期にオススメのコーデを3選ご紹介します！

    ◆ オススメスタイル その1／想定するのは海じゃなく街です！

    ▲ 想定するのは海じゃなく街です！（LEON.JP） 今時期に着るなら、こんな感じで。ボーダーTと白パンツとの組み合わせは夏っぽくあるんですが、ショーツやアイスブルーデニムじゃなくスラックスを選ぶことで、さわやかさをほどよく抑制。モノトーンでまとめているのもポイントです。ただし、モノトーンでまとめすぎるとちょっと華やかさに欠けるので、暖色でもある赤ニットで差し色を。

    ◆ オススメスタイル その2／ダブルジャケットとモノトーンでシックに

    ▲ ダブルジャケットとモノトーンでシックに（LEON.JP） 暑さが和らいできたら、インディゴブルーのジャケットをオン。白パンツとでさわやかなマリンカラーですが、ボーダーがモノトーンであること、さらにジャケットにダブルを選ぶことで夏感をほどよくトーンダウンできます。これが白無地Tだとさわやかすぎるし、黒無地Tだとちょっと重たい感じになっちゃいますからね。
