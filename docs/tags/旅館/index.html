    水素エネルギー普及への挑戦 災害経験し導入の旅館、環境への思い 物流にも革新（テレビ朝日） 今、次世代のエネルギーとして注目をされているのが水素です。地球温暖化対策としても期待されています。高市総理も普及に向けた取り組みを進めています。

    【画像】排出ガスを“ゼロ”に抑える水素エンジン

    水素コンロ 食材も美味に

    こんがりと焼き目のついた近江牛のステーキ。

    円かの杜 総料理長

    柴尾良太さん

    「肉の表面をこんがり焼いてから串を打って、これを焼きます」

    ステーキを焼きあげる、このコンロ。実は、燃料はガスでも炭でもなく「水素」です。

    神奈川県箱根町の温泉旅館「円かの杜」。厨房などには合わせて8台の水素コンロが備えられています。特徴は、その“圧倒的な火力”です。

    「燃焼温度のほうなんですけど、（ガスに比べて）こちらはプラス1000℃、2500℃くらいまでいくと」

    この高い火力が、ステーキの仕上がりに違いを生むといいます。

    「火に乗っけている時間が、かなり短くなってくるので、この肉の持っている水分とかが抜ける時間が少ない。いつもお客さんに焼いてすぐ出すので、一番いい状態で出せるかな」

    そのステーキを味わった宿泊客は、次のように話します。

    アメリカからの宿泊客

    「すごくおいしい」

    「かむと肉汁があふれ出すんです。はしで少し押すだけでも、肉汁が出てきます」

    CO2ゼロで注目

    水素コンロの強みは、これだけではありません。

    柴尾さん

    「ガス（コンロ）は二酸化炭素が出るのに対して、こちら（水素コンロ）は二酸化炭素が全く出ない代わりに、水蒸気が出ている状態ですね」

    水素は燃えるときに酸素と結びつき、出るのは「水蒸気」、つまり水だけ。二酸化炭素を排出しない、地球に優しいクリーンなエネルギーです。

    さらに、コンロから出る水蒸気は、料理にも生かされているといいます。

    「野菜のまわりでも、肉のまわりでも、水蒸気が巻きながら、蒸し焼きというのは、そこなんですよね。お客さんから『みずみずしい』とは、よく言ってもらえます」

    導入のきっかけは

    料理の味を引き立て、環境にも優しい水素コンロ。しかし導入台数は、まだ少ないのが実情です。その理由が…。

    円かの杜 女将

    松坂美智子さん

    「今はまだ（水素の価格が）高くて、プロパンガスと比べると3倍くらいでございます」

    水素の燃料費が高いといいます。ではなぜ、水素コンロを使い続けるのでしょうか。

    「2019年に台風の影響で、箱根が3日間で1000ミリという雨量を観測しまして」

    7年前の台風19号。観測史上最大の雨が箱根を襲い、箱根登山鉄道の陸橋が崩れるなど甚大な被害をもたらしました。

    その爪痕は、宿泊施設にも…。

    「3軒あった旅館のうちの1軒は災害に遭いまして、ちょうど裏山だったんですけれど、裏山がダーッと崩れてしまったんですね」

    「円かの杜」の姉妹館で大正時代から続く老舗旅館「早雲閣」が土砂崩れの被害に。

    「1階部分はもう天井につくぐらいまで土砂が入り込んでしまって、水を含んだ土砂が2階部分にも露天風呂とかも全部まみれて、使えない状態になってしまったんです」

    壊滅的な被害で閉館に追い込まれた「早雲閣」。身をもって地球温暖化の脅威を感じたといいます。

    「気候変動って言われますけれども、それまではそんなに、自分にはそんなに関係ないって思っていたんですが、自分事として捉えるようになりまして」

    そして、この経験が環境に優しい水素コンロを導入するきっかけになりました。

    「コストの面とか、費用面を考えると、誰も選択する時期じゃないという判断が大方だと思うんですね。私もそれは思ったんですけれども、誰かがやらないと、こういうのは広がっていかないんじゃないかな」
