    「食べログ 居酒屋 百名店 2026」発表

    「食べログ 百名店」はジャンルごとに高い評価を集めた100店を発表するグルメアワードです。「居酒屋 百名店」は今回で5回目の発表となります。EAST・WESTの2エリアに分けて、各100店が選ばれています。

    2026年8月12日における、以下条件に該当する店舗から、各エリアの総合点上位100店が選出されています。

    ・選出基準日時点で、第一ジャンルが「居酒屋」となっている

    エリア別に選出店の多かった都道府県を見ると、「EAST」は東京都が39店と約4割を占め、次いで愛知県が15店、北海道が10店となりました。「WEST」は福岡県が29店で最多、京都府が18店、大阪府が11店と続いています。
