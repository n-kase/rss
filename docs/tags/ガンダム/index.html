    「METAL ROBOT魂 ガンダムヴィダール」が彩色新たに復活！金属感が映える［Re:Coordinate］として再商品化(インサイド)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:15 配信

    （写真：インサイド）（インサイド） プレミアムバンダイは、「METAL ROBOT魂 ＜SIDE MS＞ ガンダムヴィダール [Re:Coordinate]」の予約受付を10月2日16時より実施します。

    【画像】金属感が映える！彩色新たに復活する「METAL ROBOT魂 ガンダムヴィダール」

    ◆「ガンダムヴィダール」が彩色新たにMETAL ROBOT魂化！

    「機動戦士ガンダム 鉄血のオルフェンズ」より、「METAL ROBOT魂 ＜SIDE MS＞ ガンダムヴィダール」が彩色の色調とマーキングを刷新した［Re:Coordinate］として再商品化。金属色を多く使用した、METAL ROBOT魂ならではの重量感ある仕上がりとなっています。

    マーキングも一部新規デザインとなり、兵器としてのリアリティを追求。眼光エフェクトパーツには粒子入りの成型色を採用することで、より輝きを放つ鋭い眼光を表現しています。武装には足部ハンターエッジ、バーストサーベル、ハンドガン、ライフルが用意されています。

    ■商品スペック

    商品サイズ：全高約150mm

    主な商品素材：ABS、ダイキャスト、PVC製

    主な商品内容：本体、交換用手首パーツ左右各4種、110mmヴィダール用ライフル、バーストサーベル柄、バーストサーベル用刃（長）、バーストサーベル用刃（短）×6、ヴィダール用ハンドガン×2、台座用ジョイントパーツ2種、眼光エフェクトパーツA・B・C、専用台座一式

    「METAL ROBOT魂 ＜SIDE MS＞ ガンダムヴィダール [Re:Coordinate]」の価格は19,800円（税込）。2027年3月発送予定。プレミアムバンダイにて10月2日16時より予約受付を開始します。
