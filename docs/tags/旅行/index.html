    「お金持ってる？」スウェーデンの入国審査で聞かれた日本人旅行者、その一言の意味を物価が教えてくれた(マネーの達人)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:00 配信

    27 コメント 27 件

    （写真：manetatsu.com）（manetatsu.com） 入国審査に限らず、どんなシーンであっても、目の前の人から突然お金の話をされたら戸惑うかと思います。Xユーザーのゆかてふ（@yukatehu13）さんが、スウェーデンでの入国審査の際に、審査官から「日本人？お金持ってる？」と問われたという投稿は530万回表示を超えました。円安の影響で水を購入したら500円だった実態を編集部が取材しました。実は「お金持ってる？」の一言には制度上の理由がありました。

    【画像】「お金持ってる？」スウェーデンの入国審査で聞かれた日本人旅行者、その一言の意味を物価が教えてくれた

    審査官の「お金持ってる？」に、その場では意味がわからなかった

    ゆかてふさんがスウェーデンを訪れたのは、主催するイベントで紹介するための伝統楽器“ニッケルハルパ”の取材のためでした。入国審査は、はじめは行き先や宿泊先を尋ねる一般的なものでしたが、スペインやフランスに入ったときと比べて、やけに長かったといいます。パスポートを確認されながら仕事や国籍を聞かれ、その流れで突然「Do you have money?」と投げかけられました。

    予想もしない質問に、うまく言葉が出てこなかったそうです。

    「Y、Yes. I have…」

    そのときの率直な戸惑いを、ゆかてふさんはこう話します。

    「なぜ急にお金の話？」

    最初は聞き間違いかと思ったほどで、ほかの国の審査では一度もなかった問いに、意図がつかめなかったといいます。ところが現地に入ってすぐ、その理由を痛いほど実感することになりました。きっかけは、スウェーデンの物の価格でした。ちょっとしたカフェでのランチや、短い距離のタクシーが、日本の感覚をはるかに超えていたのです。

    「ちょっとランチをしようと思って、その辺にあるカフェのようなカジュアルなお店に入っただけでも、普通に5,000円くらいになりました。」

    30分ほど乗ったタクシーは約12,000円。投稿に書いた水の500円も含め、支払いのたびに驚いたと教えてくれました。「えっ、こんなに!?」と、思わず声が出たそうです。

    水の500円やランチの約5,000円、タクシーの約12,000円は、ゆかてふさんが挙げた金額です。

    投稿には、共感や現地の知恵を寄せる声も並びました。「お水は観光地価格でちょっと高めだよね スーパーで買うといいかも」といった声も上がり、のちの滞在中の節約の工夫に役立ったそうです。

    スウェーデンの物価は、EUの中でも指折りの高さ

    ゆかてふさんが感じた物価の高さは、公的な統計とも重なります。EUの統計局ユーロスタットによると、2025年の家計最終消費支出でみた同国の物価水準指数（暫定値）は、EU平均（EU27＝100）を21％上回る121でした。平均的なEU諸国より物価が高い国、という位置づけです。

    ユーロスタットによれば、家計消費の物価が最も高かったのはデンマークで、EU平均の140％。次いでアイルランドが136％、ルクセンブルクが132％でした。北欧を含むこれらの国々は、旅行者にとって出費がかさみやすい地域だといえます。

    そこへ円安が重なれば、日本から訪れる旅行者の負担感はさらに大きくなります。水一本、ランチ一回の値段が日本の感覚と離れて見えるのは、こうした背景があるからです。

    「お金持ってる？」の一言には、制度上の裏づけがある

    審査官の質問は、思いつきや失礼な詮索ではありません。スウェーデン移民庁（Migrationsverket）は、同国を訪れる人に対し、『滞在中にかかる費用を自分でまかなえるだけのお金を持っていること』を確認するよう求めています。在スウェーデン日本国大使館の公式サイトでは2025年7月15日の時点で、『スウェーデン滞在には1日あたり450スウェーデンクローナ（SEK）が必要だ』としていますが、昨今の円安の状況下では、実際には日本円にして1日あたり1万円前後（約700SEK程度）の負担がかかる可能性があります。

    こうした滞在資金の確認は、シェンゲン圏の入国管理で広く行われている仕組みです。ゆかてふさんが受けた「お金持ってる？」という問いは、この要件を確かめる審査の一場面だったと考えられます。物価の高い国だからこそ、旅行者が現地で立ち行かなくならないかを、入り口で確かめているという見方もできます。

    金額の水準そのものよりも、入国時に生活資金の証明を求められることがある、という事実を知っておくことが、これから旅行する人には役立ちます。為替のレートは日々動くため、必要額を日本円に換算しても多め…

    50歳からの贅沢なイギリス留学…リビエラ･トーキーで叶える「オトナ留学」の神髄 現地の「豊かな日常」をご紹介(東洋経済オンライン)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 8:46 配信

    トーキーの美しい街並み （写真：筆者撮影）（東洋経済オンライン） 人生の後半に差し掛かり、新たな学びや挑戦を求めて海外へ旅立つ大人の留学。円安や情勢の変化など海外渡航へのハードルが意識される時代ですが、大人世代が求める留学の価値は、単なる英語能力の向上にとどまらないものへと進化しています。

    【写真を見る】世界中から愛される港町・トーキー

    若者と同じように文法や試験のスコアを競うのではなく、これまでの人生で培ってきた豊富な経験や価値観を持ち寄り、異国の地で深く分かち合うこと。それこそが、大人ならではの留学生活を真に豊かなものにしてくれます。

    今回筆者が訪れたのは、イギリス南西部デヴォン州に位置し、イングリッシュ・リビエラ(English Riviera)の愛称で世界中から愛される港町・トーキー(Torquay)です。温暖な気候、ヤシの木が揺れる美しい海岸線、そしてゆったりとした時間の流れ。この魅惑的なリゾート地で展開されている「50+(フィフティープラス)」プログラムの実態と、現地で体感したオトナ留学の醍醐味をお届けします。

    ■英国リゾートの朝、海辺の風に溶け込む日常の豊かさ

    ロンドンでの会議を前に、筆者は英国南西部のトーキーへ渡りました。現地に到着して迎えた最初の朝、海外出張時の恒例にしている早朝のランニングへ繰り出しました。

    イングリッシュ・リビエラと呼ばれるトーキーの海沿い約10キロを走ります。目の前に広がるのは、青く輝く海と白いヨットハーバー、そして特徴的な赤い崖の海岸線。この街で生まれ育ったミステリーの女王アガサ・クリスティの像が海を見守るように佇んでいます。

    走りながら特に印象的だったのは、海辺の美しい風景とアート、そして地元の人々の暮らしがごく自然に結びついていることでした。コースの途中には、ルノワールなどの名画を紹介する屋外展示パネルが点在しており、画家たちが描いたキャンバスの風景と、いま目の前にある実際の景色を重ね合わせて楽しむことができます。

    犬の散歩や朝のランニングを楽しむ地元の人々と、アイコンタクトと笑顔で挨拶を交わしながら進むうちに、単なる観光旅行では見えてこない、この街の日常のグラデーションが少しずつ見えてきました。

    旅先の「ちょい寝」は、これひとつ。アイマスクと耳栓が手のひらサイズにまとまった

    2026年9月30日 カテゴリー 未分類

    本文

    Sep 30,2026 18:30

    Yuhei Tokimatsu ( GIZMODOライター )

    25 BRAVO!!!

    Photo: Yuhei Tokimatsu

    移動中や旅先では、環境の変化で寝付けなかったり、隙間時間で寝ておきたいことがある。寝る時間はあるのに、環境のせいで眠れない。そんなときのために、光と音を遮る道具をまとめて持っておけばいい。

    寝たいときは、これを取り出すだけ

    Photo: Yuhei Tokimatsu Matador （マタドール）の「 スリープマスク+イヤープラグス 」（税込3,520円）は、アイマスクと耳栓をひとまとめにしたトラベルアイテムだ。

    使わないときは、アイマスク自体を 内蔵ポケットへ折りたたんでコンパクトに収納 できる。広げれば普通のアイマスクなのに、畳むと手のひらサイズ。これなら旅の荷物にも入れやすい。

    そして、 耳栓用の専用ポケット まで用意されている。

    Photo: Yuhei Tokimatsu 自分の場合、耳栓は必要なときに限って見つからないことがある。バッグのポケットやポーチに入れたはずなのに、いざ寝ようとすると行方不明になっていることがある。

    でも、アイマスクのなかが定位置なら探す必要はない。基本的にセットで使用するから、 寝たくなったら、これひとつ手に取ればいい。

    アイマスクと耳栓を別々に持つのではなく、 「寝るためのセット」としてひとつにまとめられる のがこのアイテムのキモ。

    Advertisement

    ふかふかなのに、さらっとした着け心地

    Photo: Yuhei Tokimatsu コンパクトに収納できるだけでなく、アイマスクとしての着け心地もよかった。肌に触れる面には、 竹由来のライナー を採用。ふっくらと厚みがあり、目元をやわらかく覆ってくれる。

    目元に当たる面積は広めだが、通気性のある素材なので、見た目ほど暑苦しくない。 肌に触れたときのさらっとした感触 も心地よかった。

    Photo: Yuhei Tokimatsu 装着は 面ファスナー式 。ゴムの伸縮だけに頼らず、頭まわりに合わせて締め付け具合を調整できる。

    強く締め付けなくても顔に沿わせやすく、昼間の室内で装着しても視界はかなり暗くなる。

    Photo: Yuhei Tokimatsu 窓から入ってくる光が気になるソファでの昼寝も、目を閉じるだけとはだいぶ違った。

    さらにセットになっているのが、アメリカの耳栓ブランド Mack’s（マックス）のイヤープラグス 。

    Photo: Yuhei Tokimatsu 発泡ウレタン素材 で、耳の形に合わせて膨らんでフィットする。もちろん、周囲の音が完全に消えるわけではないが、耳栓を入れてアイマスクを着けると、周囲の光と音が気になりにくくなり、寝ることに集中しやすかった。

    移動中だけじゃない。キャンプでも使える

    Photo: Yuhei Tokimatsu 飛行機や新幹線だけが、このセットの出番ではない。たとえばキャンプ。テントは日の出とともに容赦なく明るくなるので、少しゆっくり寝られる朝でも、明るさで目が覚めてしまうことがある。そんなときも、 アイマスクと耳栓があれば、気になる光と音を抑えられる 。
