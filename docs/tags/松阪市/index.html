    リカレント教育の役割考えるセミナー 三重・松阪市(三重テレビ放送)

    2026年10月1日 カテゴリー 未分類

    本文

    10/1(木) 9:40 配信

    リカレント教育の役割考えるセミナー=松阪市（三重テレビ放送） 医療や福祉、公共サービスなどに携わるエッセンシャルワーカーが活躍する社会を目指し社会人の学び直しがどのような役割を果たせるかを考えるセミナーが9月30日、三重県松阪市で開かれました。

    【動画を見る】リカレント教育の役割考えるセミナー

    三重県内の高等教育機関を中心に社会人の学び直しを推進する「リカレント教育プラットフォームみえ」が開いたもので、はじめに鈴鹿医療科学大学の豊田長康学長が、リカレント教育の必要性やこれまでの取り組みなどについて説明しました。

    セミナーでは、行政や放送、教育など様々な分野から自身の体験を通した学び直しについて講話が行われました。

    このうち松阪市の竹上真人市長は、市長としてのまちづくりや自身の学び直しについて話しました。

    この中で竹上市長は、県庁職員から三重県議会議員を経て松阪市長選挙に出馬したものの落選した経緯を話し「この時が自身の学び直しの原点だった」と振り返りました。

    その後、市長に就任し、市のトップとしての人材育成について「もっとも大切なのは挑戦すること。失敗は人を育てる。成功するには失敗しても挑戦すること。それが一番人を成長させる」と自身の考えを語りました。
