    ノーベル賞化学者の定義には「決定的な欠陥」があった…「酸と塩基」の概念を覆した「陽子」の能力とは？(ダイヤモンド・オンライン)

    1903年にノーベル賞を受賞したアレニウスが定めた「酸と塩基」の定義は、化学の歴史を大きく前進させた。しかし、実は水酸化物イオンを持たないアンモニアがなぜ塩基として機能するのか説明できないという、決定的な限界を抱えていたのだ。この科学界の矛盾を打破したのが「ブレンステッド＝ローリーの定義」である。常識はいかにして塗り替えられたのか、『アメリカの中学生が学んでいる 14歳からの化学』から科学者たちの知的探究を紐解く。

    ● 酸か塩基か

    酸と塩基を初めて区別したのは、スウェーデンの化学者スバンテ・アレニウスである。アレニウスは水溶液のさまざまな性質を調べて、以下のように定めた。 酸は、水の中で電離して水素イオン（H+）を生成する物質である。

    塩基は、水の中で電離して水酸化物イオン（OH-）を生成する物質である。

    スバンテ・アレニウス（1859〜1927）は1903年にノーベル化学賞を受賞した。

    酸と塩基を混ぜると、水素イオンと水酸化物イオンが結合して水分子になり、中和が起こる。酸の陰イオンと塩基の陽イオンは組み合わさって塩（えん）を作る。

    ● ブレンステッド＝ローリーの酸と塩基

    アレニウスによる酸と塩基の定義では、実際にH+やOH-を含む酸・塩基しか説明できなかった。アンモニアなどを含め、水に溶けるすべての物質を説明できず、限界があった。 そこで、デンマークの化学者ヨハンス・ブレンステッドとイギリスの物理化学者トマス・マーティン・ローリーが、アレニウスの定義の欠陥を埋める方法を思いついた。

    2人が考案したブレンステッド＝ローリーの定義では、陽子を受け取ったり与えたりする能力に基づいて酸・塩基を定義する。

    水素イオン（H+）は陽子とも呼ばれる。水素原子は陽子1個と電子1個のみからできていて、水素イオンはその電子を失っているので、残っているのは陽子だけである。

    ブレンステッド酸は、陽子を与える物質である。酸はH+をブレンステッド塩基に与える。

    ブレンステッド塩基は、陽子を受け取る物質である。塩基はH+をブレンステッド酸から受け取る。

    水はブレンステッド塩基とみなすことができる。塩化水素を水に加えると、という反応が起こる。HCl（塩化水素）が陽子を水に与えて、水がH3O+（オキソニウムイオン）になる。したがって、HClは酸、陽子を受け取る水は塩基である。また、水はブレンステッド酸とみなすこともできる。アンモニアを水に加えると、という反応が起こる。塩基は陽子を受け取り、酸は陽子を与える

    ● 酸と塩基の性質

    酸と塩基を見分ける方法が何通りかある。

    酸の性質

    ・すっぱい味がする。（実験室ではけっして味見をしないこと！）

    ・リトマス紙の色が変わる。

    ・青色リトマス紙が赤色に変わり、赤色リトマス紙は赤色のまま。

    ・一部の金属と反応して水素気体を発生させる。

    ・水溶液は電気を伝える。

    ・炭酸塩や炭酸水素塩と反応して二酸化炭素気体を発生させる。

    塩基の性質

    ・苦い味がする。

    ・リトマス紙の色が変わる。

    ・水溶液は電気を伝える。
