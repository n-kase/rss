    押収品（ABEMA TIMES） 静岡県富士市にあるヤード内のコンテナで、覚醒剤を製造していたとして、イラン国籍の男3人が再逮捕されました。

    【映像】連行される容疑者の様子

    自称・イラン国籍のモハンマディ・アリ容疑者（42）ら3人は、おととし9月から去年10月までの間、静岡県富士市にあるヤード内のコンテナで覚醒剤の錠剤を販売目的で製造した疑いが持たれています。

    警察によりますと、このグループの関係先からは覚醒剤を含む錠剤およそ5万錠や、コカインやアヘンなど大量の薬物が見つかったということです。

    その他にも、錠剤を作る機械「打錠機」なども押収していて、錠剤には高級ブランドのロゴやアニメのキャラクターなどが描かれていました。

    警察はアリ容疑者を頭とするイラン人グループが全国に複数の拠点を持ち、薬物の密輸、製造、密売をしていたとみて調べています。（ANNニュース）

    静岡放送 2026年8月、静岡県島田市で営利目的で覚醒剤や大麻などを所持した疑いで、21歳の男が9月30日に再逮捕されました。

    覚醒剤取締法違反（営利目的所持）などの疑いで再逮捕されたのは、島田市三ッ合町の自称・電気工の男（21）です。警察によりますと、男は8月4日、自宅で覚醒剤約7グラム、大麻約73グラム、コカイン約7グラムを営利目的で所持した疑いが持たれています。

    男は、8月4日に、凶器準備集合と暴力行為法違反の疑いで逮捕されていて、警察が家宅捜索をした結果、男が覚醒剤などを所持していた疑いがあるとわかり、逮捕したということです。

    警察の調べに対し、男は「営利目的では持っていない」と容疑を一部否認しているということです。

    警察は覚醒剤などの入手経路や経緯について詳しく調べています。
