    火事の心配なく30年持つ「水系電池」がいよいよ量産に

    2026年9月30日 カテゴリー ライフスタイル

    本文

    Sep 30,2026 18:45 10,730

    長谷川賢人 ( GIZMODO編集部 )

    image: EnerVenue

    水で、電気をためる。

    ……と聞くと、ちょっと怪しい匂いがしますが、だいじょうぶそう。

    アメリカの電池スタートアップ・ EnerVenue が中国・常州市で「水系電池」の量産ラインを動かし始めたそうです。 火事にならず、3万回の充放電に耐える とうたう蓄電池です。

    「水」なのは、中身の液体のほう

    まず、誤解されそうな名前なので触れておくと、水系電池は水から電気が生まれるわけじゃありません。

    電池の中には、電気の通り道になる液体（電解液）が入っています。スマホのリチウムイオン電池だと、これが燃えやすい有機溶媒。だから壊れたり熱をもったりすると、ボッ！と火が出ることがあるわけです。

    水系電池は、この液体を 水ベースの溶液 に置き換えたもの。つまり、「水で動く電池」じゃなくて「燃える恐れのある液体を水に替えた電池」なんですね。

    電解液が燃えないので、リチウムイオンでいちばん怖い熱暴走火災は起きにくい。ただし中身は水素ガスを密閉した容器なので、「危険がゼロ」ってわけではありません。異常時は安全弁から蒸気を逃がす設計、とEnerVenueは説明しています。

    Advertisement

    ハッブル宇宙望遠鏡の電池も同じ

    中身の化学は、 ニッケル・水素ガス電池（Ni-H2） 。ハッブル宇宙望遠鏡や国際宇宙ステーションで何十年も使われてきた方式だそうです。

    充電すると中で水素ガスが発生して、密閉容器にたまる。放電すると、その水素が水に戻る。これをひたすら繰り返します。

    （ちなみに、充電池などでおなじみの「ニッケル水素電池」とは別モノ。あちらは水素を金属に吸わせますが、こちらは水素を気体のまま容器にためます）

    ところが、この電池、宇宙領域では一度「引退」しているんです。2010年代の後半に、軽くてたくさんためられるリチウムイオンに席をゆずりました。それをEnerVenueが安い材料で作り直し、地上に連れ戻した、というわけ。

    宇宙で負けた理由は「重さ」でしたが、地面に据え置きするなら重さはそこまで問題になりませんからね。

    毎日3回で30年持つ

    image: EnerVenue 同社によると設計上の寿命は 3万サイクル 。1日3回フルに充放電しても、 30年もつ計算 です。

    リチウムイオンの蓄電池は8,000〜1万サイクル、7〜10年ほどで交換や増設が要る、というのが同社の比較。35年ローンの返済期間と、ほぼ同じくらい働き続けるイメージです。

    CEOのヘニング・ラート氏いわく、 「劣化していく資産ではなく、インフラのようにふるまう電池」 とのこと。だからライバルに据えているのも、リチウムではなく揚水発電や圧縮空気蓄電といった"設備"のほうだそうです。

    Advertisement

    デメリットもちゃんとある

    じゃあ完全無欠かというと、そうでもありません。

    まず、弱点でもあった 「重くてかさばる」は変わりませんから、 スマホやEVに載る日は、たぶん来ません。地味なところだと、EnerVenueは使える温度帯を「−10〜45℃」に設定しているので、寒冷地は得意じゃなさそうです。-10℃なんて北海道でも平気でいっちゃいますよね。

    また、リチウムよりロスがやや大きめです。貯めた電気を取り出すときの効率は、条件によって80〜90%。同社が公開している2023年の試算（アメリカのStorlytics社によるもの）では、充放電の効率はリチウムの約96%に対して約90%でした。20年間でロスによる損失額は、リチウムの3〜4倍になる計算です。

    ただし同じ試算の結論は、「交換や増設がいらない分、トータルではEnerVenueのほうが安い」とか。同社が配っている資料で、しかも1世代前の製品での話なので、話半分くらいで聞いておきたいところですが…。

    今回の製品の数値は公表されていませんが、一般的に水系電池は放っておくと少しずつ電気が抜けやすい（自己放電）といわれており、引き続き改善の余地ありでしょうね。

    まずは油田から、というのがシブい！

    image: EnerVenue とはいえ、3万回も30年も、まだ「設計値」。第4世代セルの実運用は2025年11月からで、実績はこれから積むところです。2023年に発表したケンタッキー州の工場計画を「技術が追いついていない」として撤回した過去もあります。

    お値段も非公表なので、導入時はリチウムより高くつく可能性は覚悟しておきたいところ。

    今度、特徴を活かした場所で導入されるそうで、これには納得。最初の大口顧客は、 中国北部の油田 。11MWh分、コンテナ26台が12…

    「飲んで溶ける電池」をMITが発明。医療がもっとパーソナルになる

    2026年9月30日 カテゴリー ライフスタイル

    本文

    Sep 30,2026 14:45

    長谷川賢人 ( GIZMODO編集部 )

    Image: Kent Hasegawa-generated with Flow

    電池を、ごくん。

    ……いや、ダメです。 ボタン電池の誤飲は、食道に穴が開くこともある本気のマジの事故。 お子さんがいる家なら、ヒヤッとした記憶があるかもしれません。

    ところが、MITの研究チームが 「飲み込んだら、お腹の中で溶けて消える電池」 を作っちゃいました。

    論文は9月21日付で「Nature Chemical Engineering」に載ったもの。電池入りのカプセルを豚のお腹に入れて、ちゃんと動くところまで確かめたそうです。

    中身はミネラルと自然素材

    image: nature chemical engineering 気になる電池の中身は、マグネシウムの合金と、モリブデンという金属の酸化物。紙のような電極を重ねて、 蜜ロウと植物由来のロウ でコーティングしてあります。

    ロウがじわじわ剥がれると、中の金属が胃液で少しずつ溶けて消えていく。

    電圧は最大1.84V。単3乾電池1本（1.5V）より、ちょっと上ですね。今の「飲み込む医療機器」向けの電池（1.4〜1.55V）よりも高いそうです。

    溶けて出てくるのはマグネシウムやモリブデンと、どちらも人の体にもともと必要なミネラルです。

    論文の試算では、電池1個から出るマグネシウムは多くて約3.4mg。 1日の推奨量の目安が男性なら320mg〜380mg、女性も260〜290mgなので、 100分の1にも満たないくらい。モリブデンも1日1mg未満の見込みで、こちらは摂取量レベルの半分程度。

    Advertisement

    「薬、飲んだ？」を1.5m先から確認

    image: Giovanni Traverso 実験した電池カプセルは、医療でよく使われる長さ26mmのサイズ。単3電池の半分くらいです。 中の約76%は空いていて、そこに薬を入れる想定 だとか。

    いちばん未来っぽいのが、 服薬チェックへの応用 。

    使うのは「RFID」という技術です。電波や電磁波を使ってICチップ（RFタグ）のデータを、非接触で読み書きできます。カプセルの中に薬や電池類を収めたら、いざ、ごっくん。

    image: Giovanni Traverso カプセル内の電池が電波を後押しするので、空気中なら4m先からでも確認できるそう。ところが体の中は水分が多くて、電波が通りにくい。これがマイナスのように見えて、 電波が弱くなったことを「飲んだ」の合図 として捉える、という逆転の発想で活用します。

    豚を用いた実験では 1.5m離れたアンテナ で、その変化をちゃんと捉えられたとのこと。

    4mm角ほどのRFIDチップと電気刺激用の小さな基板は溶けずに残りますが、これらは自然と体外へ出ていくという設計です。

    （ただし今回は、麻酔をかけた豚の食道に、内視鏡でカプセルを置いた実験。自ら飲んだわけではなく、体の向きや体格の違いへの対策もこれからだそうです）

    手術していた治療が、カプセル1粒に？

    もうひとつの応用は、胃に電気を流す治療。胃の動きが悪くなる病気などに使われる方法です。

    アメリカで承認されているシステムでは、今は お腹を手術して、電極を胃に縫いつける 必要があるそう。これを、飲み込めるカプセルに収めちゃえば手術が不要になる！

    電池1個で3日間、2個つなげば7日間、トントンと小さな電気の合図を送り続けられる。豚の胃で試すと、空腹ホルモンの「グレリン」が 平均で36%ほど増えた とか。

    刺激した場所の組織にも、目立った傷はなかったとのこと。空腹ホルモンを電気で増やす、というSFっぽさもたまりません。

    image: Giovanni Traverso 正直なところ、今はまだ豚での段階。しかも絶食させた豚で、頭数も少なめです。
