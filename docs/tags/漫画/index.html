    「令和の美しさの基準を変えている」少女漫画家・折原みと氏が描く愛子さまの品格と、天皇陛下と雅子さまの強い絆(週刊女性PRIME)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:00 配信

    2024年3月26日、伊勢神宮を参拝された愛子さま（週刊女性） 足を運ぶ先々で大きな歓声を浴びる令和のプリンセス・愛子さま。2001年12月1日、日本じゅうが祝福に包まれたご誕生から間もなく四半世紀がたとうとしている。『週刊女性』で愛子さまのこれまでの歩みを描く漫画『プリンセス愛子物語』を連載する、折原みとさんに話を聞いた。

    【写真】「できるだけ忠実に描くほうが絶対にきれい」と折原先生が描いた『プリンセス愛子物語』の愛子さまの伊勢神宮での様子

    美智子さま、雅子さまと3代にわたり“プリンセス”を描くことに

    折原さんは、これまでにもお妃候補の雅子さまの存在をいち早くスクープした『週刊女性』で、その半生を描いた『皇后雅子さま―笑顔輝くまで―』（‘20年連載）、上皇后・美智子さまの生き方や温もりあるお言葉に触れる人々を描いた『孤独なあなたの愛し方〜美智子さまが教えてくれた幸せの法則』（‘21年連載）を手がけ、大きな話題を呼んだ。美智子さま、雅子さまに続き、3代にわたって“プリンセス”を描くこととなった折原さんに、連載に向けた思いを聞いた。

    「『雅子さま』を描いていた6年前、漫画の中で愛子さまのご誕生シーンを描いたんです。その時の印象が強く残っていたので、私自身も描きながら成長を見守ってきたような気持ちでいました。その愛子さまが大人になられ、内面からにじみ出るような美しさを持った素敵な女性になられた姿をテレビなどで拝見して……。なんて素敵なお姫様なんだろうと思っていたので、今回また漫画として描けることが本当にうれしいです」（折原さん、以下同）

    愛子さまの歩みを見つめてきたからこその感慨もあるという。

    「小さいころの愛子さまは、雅子さまのご療養やバッシング、ご自身の不登校など、さまざまな試練を経験されましたよね。『雅子さま』の連載でもその様子を描いてきたので、それらを乗り越えて今があるんだと思うと本当に胸がいっぱいになります。勝手に親のような気持ちになってしまうことも（笑）」

    しかし、愛子さまを主人公として実際に描き始めてみると、新たな発見も多かったそうだ。

    なぜ男児は「棒と石」が好きなのか？「うちだけじゃないよね？」棒きれ、石、穴あきズボン…全国のママが共感【作者に聞く】(ウォーカープラス)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:00 配信

    2 コメント 2 件

    どこからか必ず見つけてくる、いい感じの木の枝。（ヨカ(＠yoka9003)） 「うちの子も棒と石を拾ってきます…！」「男子ーず！絶対棒きれ探す高感度アンテナついてますよね」と、読者から共感の声が殺到した“男の子あるある”を描いたのは、7歳差の男の子兄弟を育てるヨカ(＠yoka9003) さん。冬の公園で繰り広げられる男の子たちの行動を描いた漫画には、「うちもズボンは常に穴あけられてます」「公園ですぐ薄着になるのも、ズボンの膝に穴空けるもあるある」と、男の子を育てるママたちから共感が続々と寄せられた。

    【漫画】本編を読む

    ■男子の公園あるある、共感の嵐！

    漫画では、「どこからかよさげな棒を拾ってくる」をはじめ、冬の公園で見られる“男子あるある”を7つ紹介。なかでも特に反響が大きかったのが、やっぱり「棒」。子どもが棒やどんぐりを拾ってくるという声や、「男の子は棒が好きだから“ボウヤ”って言うのよ」と昔言われたというエピソードまで飛び出し、コメント欄は大盛り上がりとなった。「どこも同じだね〜!!」「一人じゃない！と励まされてます」「子どもたちはこの道を通らないと立派な男子になれないという登竜門なのかな」など、全国のママたちから共感が寄せられたという。

    ヨカさん自身も、漫画を描きながら「うちだけじゃないよね？みんなこんな感じだよね？」と少し心配していたそう。しかし、ふたを開けてみれば、まさに“みんなこんな感じ”。特に男の子を育てるママたちから、次々と「わかる！」の声が届いた。

    ■「知らない子」と始まるハードな遊びにドキドキ

    もちろん、漫画に描き切れなかった“男子の公園あるある”もまだまだある。ヨカさんが挙げたのは、「知らない子となかなかハードな遊びを始める」。子ども同士で楽しそうに遊んでいると思ったら、いつの間にか大人からするとちょっとハードな遊びに発展していることも。怪我をさせないか、ヨカさんは「ドキドキハラハラ」しながら見守っているという。

    そして、男の子育児につきものなのが「ズボンの穴」。読者からも悩みの声が寄せられているが、穴が空いた服の活用法について聞くと、ヨカさん自身も「これ、私も知りたいです…(笑)」と苦笑い。古着として売るのはまず難しいという、なんとも切実な“穴あき問題”。元気いっぱい遊んだ証とはいえ、ママとしては悩ましいところだ。

    ■公園への必需品は「絆創膏」と「袋」!?

    そんな男子たちとの公園遊びに、ヨカさんが持っていくと役立つものとして挙げたのは「袋」。拾ったものを入れたり、汚れたものを入れたりと、何かと出番が多いそう。さらに怪我をすることもあるため、絆創膏も必須だという。

    そして、意外にも便利なのが「スマホのアラーム設定」。帰る時間になっても「まだ遊ぶ！」となりがちな子どもたちに、あらかじめ「スマホのアラームが鳴ったら公園を出る」と約束しておくと、比較的スムーズに帰ってくれたそうだ。

    ワーママとして、ほぼワンオペで育児に奮闘するヨカさん。育児の役立つ情報だけでなく、親だって完璧ではないからこその失敗談や、思わず笑ってしまう日常のひとコマも漫画にしている。「これ、うちだけじゃなかった！」と思わず笑ってしまうような“男子育児あるある”。忙しい毎日の隙間時間に、ヨカさんの漫画をのぞいてみてはいかがだろうか。
