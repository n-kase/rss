    ベビーベッドに入る白猫⇨赤ちゃんに毛を握られても…「母の眼差しだねぇ」「温もりと愛情たっぷり」の声(ハフポスト日本版)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 8:30 配信

    しろ☺︎37w→5mさんのXより（@heliotrope787） ベビーベッドで寝ている赤ちゃんと、猫のやり取りがXで話題になっています。

    投稿したのは、「しろ☺︎37w→5m」さん（@heliotrope787）。

    【画像】赤ちゃんのおててを受け止める白猫

    「ついに猫がベビーベッドに入るようになってしまった」というコメントとともに、動画を公開しました。

    そこには、ベビーベッドの中で白猫の「ゆき」が横たわり、隣で寝返りを打とうとする赤ちゃんに触られながら、じっと見守る姿が映っています。

    投稿主に話を聞くと、ゆきは投稿の数分前に初めてベビーベッドに入り、くつろいでいたのだそう。

    普段は離れた場所から子どもを見ていて、近づいて匂いを嗅ぐことはあっても、隣でくつろぐ姿は見たことがなかったといいます。

    生後5カ月の子どもは、猫がいる方向にしか寝返りができず、それ以上まわれずに動いていたのだとか。

    最後は泣きそうになったため、投稿主が仰向けに戻したそうです。

    毛を握られても怒らず少し距離を取るだけで、引っ掻いたり噛みついたりすることはないといいます。

    この投稿には「温もりと愛情たっぷり」「母の眼差しだねぇ」いった声が殺到。

    「少し心を開いてくれたのかなと感じます。よき友になってくれたら嬉しいです」と明かしています。
