    「Firefox 157」正式版リリース、ここ数年で最大規模のデザイン刷新＆画面を広く使える「コンパクトモード」が登場

    ウェブブラウザ「 Firefox 157 」の正式版が公開されました。Firefox 157ではブラウザの外観が大幅に刷新されたほか、新しい組み込みテーマやツールバーなどの間隔を狭くする「コンパクトモード」が登場しています。また、対応端末ではWebRTCビデオ通話でAV1のハードウェアデコードが利用可能になりました。

    Firefox 157.0, See All New Features, Updates and Fixes

    https://www.firefox.com/en-US/firefox/157.0/releasenotes/

    That’s Firefox? See the browser’s surprising new changes - YouTube

    ◆Firefoxのデザインが大規模刷新

    Firefox 157ではFirefoxのデザインシステムが更新され、ツールバーやサイドバー、メニュー、各種機能の見た目が刷新されました。Mozillaは今回の変更を「ここ数年で最大のビジュアル刷新」としています。

    また、今回のデザイン刷新に合わせて新しい組み込みテーマも追加されました。各テーマにはライト版とダーク版が用意されています。

    さらに、ツールバーやタブの間隔を狭くしてウェブページの表示領域を広げる「コンパクトモード」が登場。画面の小さい環境や、複数のウィンドウを並べて利用する場合などに便利です。

    ◆WebRTCビデオ通話でAV1のハードウェアデコードに対応

    Firefox 157では、AV1のハードウェアデコードに対応した端末において、WebRTCを使ったビデオ通話でもハードウェアによるAV1デコードを利用できるようになりました。

    ◆暗号化キーが記録される設定になっていると警告を表示

    HTTPS通信の解析に使える暗号化キーをファイルに記録する設定が有効になっている場合、Firefox 157ではアドレスバーのサイト情報パネルおよび設定画面に警告が表示されるようになりました。暗号化キーを記録すると、PC上の別のソフトウェアから暗号化されたウェブ通信の内容を読み取れる可能性があるため、ユーザーがそうした状態に気付きやすくなります。

    ◆Firefox Suggestの提供地域を拡大

    アドレスバーに入力した内容に応じて候補を表示する「Firefox Suggest」が、オーストリア、ベルギー、チェコ、デンマーク、フィンランド、ハンガリー、アイルランド、ルクセンブルク、オランダ、ノルウェー、ポーランド、ポルトガル、スロバキア、スペイン、スウェーデン、スイスでも利用可能になりました。Firefox Suggestの動作は設定画面から変更できます。

    ◆サイドバーの新デザインが全ユーザーに展開

    新しいサイドバーが全ユーザーで有効になりました。従来のサイドバーを使用していたユーザーについても、パネル切り替えボタンをサイドバー上部に配置した似たレイアウトへ移行します。また、Firefoxの設定画面に存在していた「Show sidebar」の項目は削除されました。

    なお、新デザインの調整が続いている間は、アドレスバーに「about:config」と入力し、「sidebar.revamp」を「false」に変更することで従来版のサイドバーに戻すことも可能。ただし、この設定では縦型タブも無効になります。「sidebar.revamp」は2027年末まで利用できる予定です。

    ◆ウェブページ上のダイアログがページのライト・ダーク配色に追従

    ウェブページから表示される「alert()」「confirm()」「prompt()」のダイアログや、カラーピッカー、日付選択画面、フォームの自動入力ドロ…

    AirPods 5がバラバラに分解されこれまで交換不可能だったバッテリーがついに交換できるようになっていることが明らかに

    Appleが2026年9月10日に 発表 し、18日に 発売 した「 AirPods 5 」を、さまざまなデバイスを分解し修理可用性を評価する iFixit がバラバラに分解しました。これにより、AirPods 5ではこれまで交換不可能だったバッテリーが交換可能になったことが明らかになっています。

    iFixit teardown of the new AirPods 5 reveals first real repairability improvement - 9to5Mac

    https://9to5mac.com/2026/09/29/ifixit-teardown-of-the-new-airpods-5-reveals-first-real-repairability-improvement/

    AppleのワイヤレスイヤホンであるAirPodsは、本体のステム部分にバッテリーを内蔵してきたため、バッテリーを交換するには筐体部分を破壊する必要がありました。そのため、「AirPodsを完全に破壊せずにバッテリーを取り出す方法は存在しない」と評価されてきました。

    なぜAppleのAirPodsは修理できないのか？ - GIGAZINE

    Appleが2016年に初代AirPodsをリリースして以来、iFixitはAirPodsの各モデルの修理可用性を一貫して「0点」と評価してきました。Appleは2021年に発売されたAirPods 3以降、バッテリーの位置をステム部分から移動していますが、それでもバッテリーは筐体に接着されたままで、バッテリーと基板の接続部分ははんだ付けされているため、筐体を破壊せずに分解・組み立てすることは熟練の修理業者以外にはほとんど不可能だったそうです。

    しかし、iFixitが公開したAirPods 5の分解動画では、Appleがついにこの悪名高い構造を変更したことが明らかになっています。

    We’ve Given AirPods 0/10 for 10 Years. Until Now. - YouTube

    AirPodsの左右に搭載されているバッテリーは、極性が逆になっており、接点の位置も微妙に異なるため、左側用のバッテリーは左側でしか動作しないようになっているそうです。それでも家庭にある工具だけで分解し、バッテリーを交換することができるようになっているとiFixitは指摘しています。

    iFixitはAirPods 5を「史上最も修理しやすいAirPods」と評していますが、修理可用性は10点中「2点」の評価です。これはバッテリー以外のパーツは筐体を壊さずに交換することがほとんど不可能であるためです。

    OpenAIが常時稼働型のAIアシスタント「Dots」を公開、GPT‑6 Astra を搭載して専用のクラウドコンピューターで稼働

    OpenAIが、2026年9月30日に開催された年次開発者会議「 OpenAI DevDay 2026 」の基調講演で、常時稼働型のAIアシスタント「 Dots 」を発表しました。DotsはGPT‑6 Astra を搭載し、専用のクラウドコンピューターで稼働するAIエージェントで、4000以上のアプリと連携しながらテキストメッセージやSlack、Teamsから指示を与えることができます。

    dots のご紹介 | OpenAI

    https://openai.com/ja-JP/index/introducing-dots/

    Introducing dots, always-on agents built to handle everything. - YouTube

    OpenAI DevDay 2026の基調講演は以下で視聴可能。サム・アルトマンCEOが冒頭部分でDotsの詳細を解説しています。

    OpenAI DevDay 2026 Keynote (FULL) - YouTube

    Dotsは、質問に答えたり指示された作業をその場で実行したりするだけではなく、ユーザーから任された仕事を継続的に進めることを想定したAIエージェントです。OpenAIのGPT-6 Astraを搭載し、各dotには専用のクラウドコンピューターとブラウザー、アクセス権限を管理するための専用IDが用意されます。必要に応じてコードを書いて実行したり、テストしたりすることもできます。

    各dotはユーザーのPCとは分離された専用クラウド環境で動作し、ユーザーが明示的に接続しない限り、自分のPC内のデータにはアクセスできません。また、ウェブサービスにログインする場合でも、保存されたパスワードそのものをAIモデルに開示せずに利用できる仕組みが用意されているとのこと。

    OpenAIはDotsについて、新入社員に仕事を任せる場合に近い環境を与えられると説明しています。ユーザーが一つ一つの操作を指示しなくても、dotは任されたプロジェクトを進めながら、別の作業にも並行して取り組むことができます。ユーザーはいつでもdotが使用しているクラウドコンピューターを開き、作業状況を確認できます。

    また、DotsはOpenAIのプラグインを通じて4000以上のアプリと接続できます。ChatGPTだけでなく、SlackやMicrosoft Teams、テキストメッセージなどからもdotとやり取りでき、異なるサービスから指示しても、それまでの作業内容や会話の文脈を引き継ぎます。

    Dotsは音声通話にも対応し、ユーザーが口頭で相談したり、作業の方向性を伝えたりすることも可能です。

    さらにOpenAIはDotsと人間が共同で作業するためのワークスペース「ChatGPT Space」も発表しました。Spaceでは、ページやファイル、調査結果、グラフ、プロトタイプなどを1カ所にまとめ、ユーザーやチームメンバー、Dotsが同じ内容を見ながら作業できます。ページ内でdotを呼び出して作業を依頼したり、コメントから特定のdotにタスクを割り当てたりすることも可能です。

    SpaceはDotsが実際にブラウザー操作やコード実行を行う専用クラウドコンピューターとは別のもので、人間とAIが成果物や作業状況を共有するための共同作業環境という位置付け。Space内のページには継続的な指示を設定することもでき、例えば「特定のSlackチャンネルを確認して、毎日ここに調査結果を更新する」といった作業をdotに任せられます。OpenAIは今後、Space内でプレゼンテーションを作成し、人間とDotsが共同で編集できる機能も提供する予定です。

    「GPT-6.1 Sol」「GPT-6 Sol」「GPT-6 Astra」の3種類でコーディング性能ベンチマーク「DeepSWE」のスコアを比較したグラフが以下。GPT-6.1 SolはGPT-6 Astraの5分の1のコストで同等の性能を達成しています。

    以下はPC操作性能を測定する「OSWorld 2.0」の結果です。GPT-6.1 SolはGPT-6 Astraと比べて7分1のコストで差を2.1パーセントポイントに抑えています。

    データ分析や定理証明などの科学ワークフローでの性能を測定する「Terminal-Bench Science 0.1」の結果が以下。GPT-6.1 SolはGPT-6 Solの2倍のスコアを半分以下のコストで達成しました。また、推論レベルを最大にした場合のタスク当たりのコストはGPT-6.1 Solが5.47ドル(約869円)、GPT-6 Astraが23.80ドル(約3736円)、Claude Opus 5.5が23.21ドル(約3643円)でした。スコアはGPT-6 Astraが最も高くなっており、OpenAIは「総合的な能力ではGPT-6 Astraが引き続き当社の最高のフロンティアモデルです」「GPT-6.1 Solは能力とコストの新たなバランスを提供します」と述べ、GPT-6 Astraがフラッグシップモデルであり続けることを明確にしています。

    第三者機関の Artificial Analysis もGPT-6.1 Solをテストしています。複数のテストでAIの総合性能を算出する Artificial Analysis Intelligence Index v4.3.2 のスコアは52で、GPT-6 Solから4ポイント上昇してGPT-6 Astraと1ポイント差に迫りました。
