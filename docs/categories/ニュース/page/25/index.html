    10月の値上げラッシュに「またか」 家計簿つけずに“月3万円”浮かす固定費の見直し術とは【FP解説】(オトナンサー)

    家計簿をつけずに節約するには？（画像はイメージ）（オトナンサー） 近年、飲食料品やガス代、電気代の値上げが続いています。帝国データバンクによると、2026年10月の飲食料品値上げは計3153品目となり、SNS上では「また値上げかよ」「ふざけんな！！」などの声が上がっています。

    【画像】「えっ…！？」 これが家計簿をつけずに節約する“裏技”です！

    節約には家計簿をつけるのがよいといわれていますが、なかなか長続きせずに挫折しやすいのも事実です。今回は家計簿をつけないで固定費を削る方法や、隠れた無駄遣いを見つけ出すコツについて、1級ファイナンシャル・プランニング技能士（FP1級）で元小学校教諭のもっちゃんさんに聞きました。

    家計簿をつけずに固定費を節約するには？

    Q.10月からの飲食料品などの一斉値上げに対して、家計簿をつけずに固定費を削る方法はありますか。

    もっちゃんさん「私の肌感覚ではありますが、実際に家計簿をつけている人はとても少なく、ほとんどの方はアプリで管理しているようです。そこで、家計簿をつけないで固定費を削る方法ですが、私は先取り貯蓄の仕組み化とメガ固定費の削減をおすすめしています。

    メガ固定費とは通信費・保険・住居費といった特に負担の大きい固定費で、まずはこの3つから見直すのが一番インパクトの大きな方法です。先取り貯蓄の仕組み化はやっていない人が多い印象ですが、給与口座から生活費口座と貯蓄口座へ自動で振り分ける仕組みを指します。口座を分けて管理すれば生活費は口座内の残高だけでやり繰りするようになりますし、毎月一定額を自動的に貯蓄することも可能です。普通預金口座は定額自動入金という設定ができるため、この仕組みを活用すると家計簿に1円単位の記録を残す必要もありません。

    その上で、例えばスマホを格安SIMに変更したり、不要な任意保険を見直したりすることで、本当に何も頑張らないで毎月2～3万円の固定費を削減できるご家庭もあるのではないかなと思います」

    隠れた無駄遣いを見つけるコツとは？

    Q.サブスクリプション（サブスク）や携帯の料金プラン、不要な保険の特約など、無意識に毎月引き落とされている「隠れた無駄遣い」を見つけ出すコツについて、教えてください。

    もっちゃんさん「まずは、直近3カ月くらいの通帳とクレジットカードの利用明細を上から順にチェックすることからスタートです。通帳や明細を見るだけで、使っていない動画のサブスクリプションサービスですとか、幽霊会員になっているスポーツジムとか、スマホの契約当初からつけられていた有料オプションなどが浮き彫りになります。利用明細を少し振り返るだけでも、無駄な部分を洗い出すことが可能です。

    見直しで月にどの程度節約できるかはご家庭にもよりますが、目安で言うとサブスクだと月2000円から5000円程度、携帯プランですと月5000円から1万円程度節約できる可能性があります。

    また、見直しによる節約効果が一番大きいのが保険です。保険に入り過ぎてしまっている人も少なくないため、無駄な任意保険を整理することで月5000円から1万5000円くらいは節約できます。以上を合計すると、月1万5000円から3万円程度の固定費を削減することが可能です」

    「イスラエル人乗客の1人と話した。彼によると、機体はきりもみ状態に陥り、急降下し始めた。何とか乗員の1人と一緒に操縦室へ突入し、機体のシステムを破壊しようとしていた操縦士を2人で制圧したという」とネタニヤフ氏は述べた。

    さらに、「機内にいた別の乗務員が操縦室に入り、機体を安定させることができた」と語った。

    襲撃した操縦士は逮捕され、サウジアラビア当局の取り調べを受けているという。

    年内の引き渡しが決定へ

    北極域研究船「みらいII」（画像：JAMSTEC） 海洋研究開発機構（JAMSTEC：ジャムステック）は2026年9月29日、北極域研究船「みらいII」の引き渡し日を発表しました。

    【就役に合わせ模型も登場？】「1/700 北極域研究船 みらいII」（画像）

    引き渡し日は2026年12月18日で、ジャパン マリンユナイテッド横浜事業所磯子工場で式典が実施されます。

    同船は、海洋研究開発機構（JAMSTEC）が北極域の研究のために運用を予定している砕氷船です。世界的にも珍しい、ドップラー効果を利用して対象の相対的な移動速度や変位を観測する「ドップラーレーダー」を搭載しています。

    慣熟航海もすでに決定しており、2026年12月28日から2027年1月6日にかけて、日本近海（相模湾、駿河湾など）で各種機器の作動確認や観測訓練が実施されます。

    続いて、2027年1月10日から2月3日まで、連続採水観測、ドップラー気象レーダー観測、その他の観測訓練が行われます。

    砕氷船として欠かせない砕氷航行試験については、2027年2月11日から3月9日まで、オホーツク海の流氷域で実施されます。

    慣熟航海を終え、正式に引き渡された後は、地球温暖化に伴う海氷減少など、急速に進む環境変化に関する高精度な将来予測に必要な、時空間的な観測データを北極海などで収集する予定です。南極周辺と比べ、北極海は圧倒的に観測データが不足しているといわれており、同船の北極というデータの空白域を埋めるのに欠かせない船となります。

    手作業で織り目を揃えたボディと体格に合わせ作り直したシートが放つ世界1台の造形

    アルファロメオ 33ストラダーレ：バタフライドアを跳ね上げたPerla Neraはブラックホイールと無装飾のボディが特徴 アルファ ロメオが2026年9月28日、イタリア・アレーゼのアルファ ロメオ博物館で、33台限定のスーパーカー、アルファ ロメオ「33ストラダーレ」の1台限りの特別仕様ペルラネーラを公開した。オーナー自身が名を選んで登録したこの個体は、ボディに塗装を一切かけず、マット仕上げの素地カーボンだけで33台中唯一の姿を得ている。

    【画像】塗装がないから見える織り目の流れ！ アルファ ロメオ「33ストラダーレ」を見る（全27枚）

    33台限定のアルファロメオ「33ストラダーレ」で唯一、塗装をまとわない個体

    33台しか作られないスーパーカーのなかで、塗装を持たない個体はこの1台だけになる。オーナーはアルファ ロメオに深く傾倒するコレクターで、外装から内装まで自身の構想を通すため、チェントロスティーレ（アルファ ロメオのデザインセンター）と対話を重ねながら仕様を詰めていった。

    ベースとなった33ストラダーレは、1967年のオリジナルに着想を得て2023年8月に発表されたモデルで、生産台数は33台に絞られている。組み立てを担うのはミラノのカロッツェリア（自動車の車体製造・カスタムを行う専門工房）であるトゥーリング・スーペルレッジェーラだ。ペルラネーラはイタリア語で黒真珠を指す言葉で、この名はオーナーが選び、正式に登録された。マット仕上げのカーボンが車体全面を覆う姿は、名前通りの黒一色にまとまる。

    カーボンを1枚ずつ手作業で積層。ボンネットのVモチーフとヘリンボーン柄

    素地のカーボンを見せる仕上げは、成形の段階から織り目の向きを管理しなければ成立しない。カーボンファイバーは金型の中で1枚ずつ手作業で置かれ、曲面の輪郭に沿うよう繊維の方向が決められている。ボンネットではアルファ ロメオらしいVモチーフを織り目が強調し、ルーフラインに沿って続くヘリンボーン（杉綾織り）柄が、前から後ろへ視線を導く要素になっている。

    積層の設計や関連する技術的な内容は、工程ごとにオーナーと共有された。厳密な品質検査から最終組み立てまで、同じ精度で管理が続けられている。単色の見え方を仕上げているのは、オールブラックのホイールと、ブランドエンブレム以外のバッジを廃した処理だ。面の連続性が途切れず、カーボンの織り目そのものが主役になる。
