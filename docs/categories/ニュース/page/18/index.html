    【写真】「揺さぶられました」と漏らした大友花恋

    ※以下ネタばれを含みます。

    情報番組「あさイチ」MC陣も朝ドラ受けした。

    あらすじは、宿題であった「父について」の作文をようやく書き上げた珠（村上蘭）。しかし、尋常小学校の先生の提案で、その作文を父親の前で発表することになってしまう。珠はリョウ（国仲涼子）に相談し、そのことを清治（渡部篤郎）に伝える。しかし、清治はあまり興味を示さない。発表の日、まばらに参観する父親の中に清治の姿はなかったが、いよいよ珠の発表が回ってきた時、清治が教室にやってきて…。珠の作文に清治も笑顔を見せる。しかしある日、ふとしたことからリョウが清治の飼っていたカナリアを逃がしてしまう。清治は激しく怒り、リョウは姿を消してしまう。

    葉野珠の幼少期を演じる12歳の村上蘭があさイチにVTR出演した。鈴木奈穂子アナウンサーは「華丸さんは村上さんの目の演技がすごいと言いながら見ていましたけれど」と言うと、華丸は「もうでも、（村上の出演が今週で）終わり？ くぎ付けですよ」と語った。

    ゲストの川村エミコは「（珠が）来週女学生になって、カナリアはどうなるんでしょうか」と心配した。大吉が「（リョウは）出ていったんですかね」と話すと、川村は「戻ってきて欲しいですね」と漏らした。大友花恋は「おととさまに書いた作文が認められて良かったね～、とほっこりしていたら…この15分の中で気持ちが上がったり下がったり…揺さぶられました」と振り返った。

    「ブラッサム」は朝ドラ第115作目で、同作は明治、大正、昭和を駆け抜け、自由を求め続けた山口県出身の作家・宇野千代をモデルに、主人公・葉野珠（はの・たま）の波瀾（はらん）万丈の人生を描くオリジナル作品。石橋静河が珠を演じ、珠の高齢期を加賀まりこが演じる。

    主題歌は、YOASOBIの「咲き誇れ」。語りは三條雅幸アナウンサーが務める。

    テレビユー山形 山形県山形市の老舗のお茶の販売会社「志鎌園」と系列会社のあわせて2社が事業を停止し、自己破産申請の準備に入ったことがわかりました。負債総額は2社あわせておよそ4億8700万円にのぼります。

    東京商工リサーチ山形支店によりますと、自己破産申請の準備に入ったのは、山形市流通センターに業務上の本社を置く茶類卸・小売の「志鎌園」と、系列で健康茶などを扱う「長寿園本舗」です。

    ■あのCMソングで有名に

    志鎌園は、1912年（大正元年）に創業した老舗の茶舗で、1980年代以降はテレビCMでも知られ、知名度を高めました。スーパーマーケットや小売店への卸売をメインに直販営業も行い、最盛期の1990年代には年間7億円を超える売り上げがありました。

    しかし、2000年代以降は流通形態の多様化などで地場問屋としての存在感が薄れて卸売が縮小したほか、量販店などとの競合激化により小売店も不採算が続き、店舗の撤退を余儀なくされました。

    さらに近年は、お茶の総体的な需要減少を受け、主力となっていた葬儀場やセレモニーホールなどへの納入量も先細りとなり、今年（2026年）3月期の売り上げはおよそ1億5000万円にまで落ち込んでいました。

    ■巻き返しを狙うも・・・

    今期に入ってからも立て直しを期して通常営業を続けていましたが、回復の見通しが立たず、過去の赤字決算に伴う資金繰りの悪化により、9月30日付けで事業を停止し、事業継続を断念したということです。系列の「長寿園本舗」も志鎌園に連鎖し、同様の措置に至っています。

    負債総額は、志鎌園がおよそ4億2200万円、長寿園本舗がおよそ6500万円で、2社あわせて4億8700万円にのぼります。事後処理を弁護士に一任しており、近く山形地方裁判所に破産を申請する予定です。

    ベッキー10年ぶりの『イッテQ』復帰に賛否…“自粛の時効”が伸び続けるワケ。昭和は数週間で復帰、令和は“年単位”に(SPA!)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 8:54 配信

    89 コメント 89 件

    2016年、スキャンダルについて会見に臨むベッキー ©産経新聞（日刊SPA!） 9月27日放送の『世界の果てまでイッテQ！』（日本テレビ系）に、ベッキーがサプライズ出演し、波紋を呼んでいる。

    この日は2時間スペシャル。出演者がタスキをつなぎながら世界遺産を巡る「世界遺産駅伝」の企画で、イタリアを訪れた内村光良が宮川大輔と合流すると、「マグネット仮面」を名乗る覆面姿の人物が現れた。その正体がベッキーだった。内村とは「完全に10年ぶり」の共演だと明かすと、内村も放送前は眠れず、いろいろと考えを巡らせていたことを打ち明けた。

    賛否両論の電撃復帰

    ロケ後の食事の席では、宮川から久々の出演の感想を問われ、感極まって涙を流す場面も。宮川と内村が、自身の番組復帰をずっと諦めずにいてくれたことにも触れ、周囲への感謝を口にした。宮川もまた涙を見せ、“イッテQファミリー”の再会は多くの視聴者の胸を打った。放送後、ベッキーは自身のInstagramで《関わってくださった全てのみなさまに心から感謝しております。ただただ、ありがたい時間でした》とつづっている。

    ベッキーは2007年の番組開始時からのレギュラーメンバー。だが2016年1月、『週刊文春』で川谷絵音との不倫が報じられ、休業とともに番組を離れた。今回は実に約10年ぶりの“帰還”となる。

    ネット上では「おかえり」と歓迎する声がある一方、やや批判的な反応も少なくない。10年という歳月を経てもなお、拒否反応は消えていなかったわけだ。

    久米宏、森本毅郎、ビートたけしは…

    では、芸能界における“不祥事の時効”とは、いったい何年なのか。過去の事例をひもとくと、意外な事実が浮かび上がる。昭和の自粛期間は、驚くほど短かったのだ。

    まずはニュースキャスターの久米宏。すでにTBSアナを辞めてフリーとして活躍していた1981年当時、すでに家庭を持っていたが、不倫相手の女性が久米に妻との離婚を迫り、自殺未遂を図ったのだ。女性の命に別状はなかったものの、黒柳徹子と司会を務めていた『ザ・ベストテン』（TBS系）を、3週間休んだ。わずか3週間である。復帰した9月17日の放送は、その動向に注目が集まったこともあり、番組史上最高の視聴率41.9％（ビデオリサーチ調べ、関東）を記録したという。

    『噂の！東京マガジン』（TBS系）の司会で知られたキャスター森本毅郎も、1988年にテレビ局職員との不倫をスクープされた。このときは1か月の謹慎に伴い、打倒『ニュースステーション』をめざして始まった『JNNニュース22プライムタイム』（同系）のキャスターをしばらく休演している。結局同番組は1年で終了。それでも翌年には『東京マガジン』がスタートしている。

    ビートたけしのケースはどうか。1986年、自身のプライベートへの行き過ぎた取材に腹を立て、軍団のメンバーとともに『FRIDAY』編集部を襲撃。翌年、懲役6か月、執行猶予2年の判決が下された。判決確定まで各局は出演を見合わせ、打ち切りとなった番組もあったが、謹慎期間は約8か月だった。
