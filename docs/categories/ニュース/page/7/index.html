    写真：家電 Watch（株式会社インプレス） パナソニック サイクルテックは、電動アシスト自転車「ビビ・EX」「ビビ・DX」「ビビ・MX」の2027年モデルを10月に発売する。価格は順に183,000円、151,000円、143,000円。

    【画像】ビビ・DX

    ショッピングモデルの電動アシスト自転車として人気の「ビビ」シリーズ。スタンドを立てると同時にハンドルが固定される「スタピタ2S」、前方だけでなく足元も照射する「足も灯4-LEDビームランプ2」、大容量の「大型スムースインバスケット3」などの快適装備が充実している。

    さらにフラッグシップモデルのビビ・EXは、電子キーによる自動解錠機能「ラクイック」を搭載。電子キーを携帯していれば、手元スイッチの電源を入れることで後輪サークル錠が自動で解錠される。

    ビビ・EXとDXの2027年モデルは「空気入れタイミングお知らせ機能」を新たに搭載。空気圧の低下をタイヤの変形量からモーターが推定し、空気を入れるタイミングを「クウキチェック」の液晶表示で知らせる。適正なタイヤ空気圧を保つことで、路面からの衝撃によるパンクやタイヤ/チューブ劣化のリスクを抑制し、バッテリーの消耗も軽減するという。

    ビビ・MXの2027年モデルは、ハンドルやバスケットなどのパーツをブラックで統一し、フレームと同色のチェーンケースを採用。細部にまでこだわった洗練されたデザインを特徴とする。

    さらに、従来より幅が広い「1-1/2WOタイヤ」を採用。太めのタイヤにより接地幅を確保するとともに、空気が多く入るため走行時の安定感も高まるという。

    いずれも車体サイズは24型と26型。内装3段変速で、EX/DX/MXの1充電あたりの走行距離は、パワーで約59km/約59km/約44km、オートマチックで約70km/約70km/約53km、ロングで約107km/約107km/約80km。充電時間は約5時間/約5時間/約4時間。

    家電 Watch,津田 昌宏

    電子書籍には、文字の拡大や「音声」読み上げ機能、しおりや検察、メモなど、電子書籍ならではの便利な機能もあるということです。

    Geminiの「Daily Brief」を使ったら、朝のメールチェックがいらなくなった（ライフハッカー・ジャパン編集部） Geminiは、もはや単なるチャットボットではありません。

    Androidの音声アシスタントを動かし、パーソナル生産性エージェント「Spark」として機能し、「Omni」のようなカスタムモデルも抱えています。

    そうしたAIツールのひとつが「Gemini Daily Brief」です。Googleはこれを、朝にその日の予定をプレビューするためのAIエージェントと説明しています。

    連携アプリから情報を集めるGeminiのDaily Brief

    Google Workspaceアプリ、Googleフォト、YouTubeに対応

    Daily Briefを使うには、まずGeminiアプリで「パーソナルインテリジェンス（Personal Intelligence）」を有効にする必要があります。

    対象ユーザーでまだ有効にしていない場合は、Geminiアプリとウェブ版にカードが表示されます。

    「開始する（Get Started）」をクリックまたはタップして、連携するアプリを選びましょう。

    選択肢は「すべて連携」「アプリを選択」「連携しない」の3つです。最初のDaily Briefを受け取るには、パーソナルインテリジェンスがGoogle Workspaceアプリと連携しており、かつGeminiのメモリ機能がオンになっている必要があります。

    設定が済むと、Geminiアプリまたはウェブ版のサイドバーにDaily Briefが表示されます。生成されるのは1日1回、たいていは朝です。

    内容は「Top of mind（最重要）」「FYI（参考情報）」「Looking ahead（今後の予定）」といった優先度別のカテゴリーに分けられます。アクション項目の優先度判定はかなり正確です。

    Daily Briefの情報源は主にGmail、Googleカレンダー、Workspaceアプリ、そしてGeminiのチャット履歴。連携したアプリによっては、YouTube、Googleフォト、Google検索など、ほかのソースからの項目が表示されることもあります。

    Daily Briefは、こうしたアプリから情報を拾い上げたうえで、実際の行動につなげられるよう設計されています。

    【社説】未成年選挙運動 重い違憲判決、禁止是正を(西日本新聞me)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:00 配信

    西日本新聞 社説 「未成年もこの国をつくる一員」という高校生の訴えが時代遅れの現状に風穴をあけたと言えるだろう。

    18歳未満の選挙運動を禁止する公選法の規定について、東京地裁は先週、違憲判決を下した。

    高校生ら17～20歳の4人が政治的表現の自由を保障する憲法に違反するとして、国に損害賠償などを求めて提訴していた。

    判決は、公選法の禁止規定が「表現の自由」を保障した憲法21条に反するとした。賠償責任は否定した。国会で具体的な検討がなく立法不作為は認めなかった。国は勝訴したことになり、原告が控訴しなければ判決は確定する。

    禁止規定を巡る司法判断は初めてだ。国会は重みを真摯（しんし）に受け止め、未成年でも選挙運動に加われるよう、法改正の議論を始めるべきだ。

    禁止規定は1952年に導入された。当時は小学生らを大量動員した人海戦術で有権者の関心を引こうとした例もあった。子どもを守り、選挙の公正さを保つために規制を急いだ。

    70年以上を経て社会状況は激変した。欧米では未成年の選挙運動を認める国が多い。若者が政治参画しやすい未来を開く画期的な判決だ。

    4人は18歳未満だった当時、選挙で特定の候補者を応援しようとするなどしたが、禁止規定を知り断念した。違反すれば1年以下の拘禁刑か30万円以下の罰金が科され、公民権も停止されるためだ。

    判決は投票権のない未成年でも表現の自由は保障され、禁止規定は「精神的自由に対する直接の制約で、それ自体が重大」として違憲判断に導いた。理にかなっている。

    国は「学業への支障も生じる」と主張したが、説得力に乏しかった。

    選挙運動は自らの関心や価値判断で取り組むもので、スポーツや音楽などの課外活動と変わらない。判決がそう指摘し、禁じる根拠を見いだし難いとした点も、国民の共感を得られるのではないか。

    一方、未成年の使用を禁じる規定は、意に沿わない選挙運動をさせられる可能性があることから合憲とした。自ら応援する意思があるか、線引きの明確化が必要だ。

    若者の政治参画を促すために2015年、選挙権年齢が18歳以上に引き下げられた。高校3年生の一部が有権者となり、学校現場では主権者教育が広がっている。

    だが、10代の投票率は低迷している。教室での学びだけで、18歳に達した途端に「主権者として投票せよ」と求めるのは無理がある。

    選挙運動に参加できれば、実践的に学ぶ機会が増え、政治参画意識も高まるはずだ。

    主権者教育も見直したい。投票行動を促すだけでなく、校則や学校行事など自分たちに関わることを自分たちで決める。そうした経験を小中学校の段階から積み重ねることこそ大切にしたい。

    西日本新聞社

    濃密な人間関係を避ける「ソロ」という選択 （写真：Ushico ／PIXTA）（東洋経済オンライン） 「ひとは幸福になるために生きているけれど、幸福になるためにデザインされていない」と提起する作家の橘玲氏。

    多くの人は自分が幸せな人生を送っているかどうかにひとかたならぬ関心を寄せ、昨日より今日、今日より明日は幸せになれるよう努力を重ねる。

    ■「ソロ」の人生を選ぶひとたち

    橘玲より ソ・ウングクさまへ

    旧石器時代の閉鎖的なムラ社会で進化してきた人類は、共同体のなかでの評判やステイタスを過度に気にする一方で、家族や友人などとのつながりから幸福を感じるように進化したという進化心理学の説明は説得力があります。

    しかしその一方で、とりわけ第2次世界大戦が終わった1960年代以降(韓国では1987年の民主化以降でしょうか)、「自分らしく生きることは素晴らしい」というリベラルの価値観が支配的になり、地域や宗教などの伝統的な共同体は「自由な人生」の障害と見なされて解体していきました。

    そしていま、欧米や日本・韓国などで家族をもたない(結婚しない)ソロを選ぶひとたちが増えています。

    行動経済学者のピーター・マグロウは『「ソロ」という選択 自分だけの特別な人生を築く』(江口泰子訳/青土社)でソロとシングルを区別し、シングルを「いまは独り身だが、いずれ結婚して家族をもちたいと思っている」こと、ソロを「家族や恋人のような濃密な人間関係は自己実現を妨げるとして、自覚的に独身を選択する」ことと定義しています。

    ■「自分らしさ」と「絆」の狭間で

    このままリベラル化が進み、「自分らしく生きる」を最大化しようとするならば、必然的にソロ化が進み、人間関係は固定的なものから、流動的なアドホックなものに変わっていくのではないかと思います。世界中を旅しながら、リモートワークで収入を得て、その場かぎりの人間関係を楽しむノマドライフはその典型でしょう。

    これに対して「(伝統的な)共同体の復活」を説くポスト・リベラルもいますが、とてつもなくゆたかで平和な社会では、共同体がかつてのような魅力をもつことはないと思います。しかしそれでも、わたしたちは他者とのつながりや絆から幸福感を得るしかないとすると、これからの社会はどうなっていくのでしょうか。ぜひソさんのご意見を聞いてみたいと思います。
