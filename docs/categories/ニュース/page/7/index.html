    【スマホを置いて本を読もう】1日6分の読書でもストレス68％低下！共感力や認知機能にも好影響（Getty Images） 最近、本を読んだのはいつ？スマートフォンや動画を見る時間が増える一方で、楽しみのために本を読む人が減っている。米国では、読書を娯楽として楽しむ人がわずか16％だったという大規模な研究も出ている。

    〈画像〉【スマホを置いて本を読もう】1日6分の読書でもストレス68％低下！共感力や認知機能にも好影響

    ■たった6分の読書でストレスが68％低下した研究も

    英ケンブリッジ大学などの研究者らが、読書と脳の健康や認知機能、心の健康との関係をまとめた論文を発表した。これまでのさまざまな研究から、読書はストレスや孤独感、他者への共感、さらには加齢に伴う認知機能の低下とも関連していることが見えてきたという。読書のメリットとして、まず注目されるのがストレスとの関係だ。過去の調査では、リラックスするための方法として「本を読む」と答えた人が38％に上り、読書は人気の高い気分転換の方法だった。さらに2015年の調査では、わずか6分間の読書が、ストレスレベルの68％低下と関連していた。

    なぜ読書でストレスが下がるのか？ケンブリッジ大学のバーバラ・サハキアン名誉教授によると、本に没頭すると意識や注意が物語に集中するため、日常の悩みから一時的に距離を置きやすくなるという。スマートフォンでSNSを眺めていると、次々と新しい情報が目に入ってくる。一方、本を読むときは目の前の文章を追い、ひとつの物語やテーマに意識を向ける。そのため、悩みを何度も繰り返し考えてしまう「反すう」が起こりにくくなる可能性がある。

    サハキアン教授は、こうした点で読書にはマインドフルネスに似た側面があると説明している。そして、読書のメリットは「リラックスできる」だけではない。

    ■小説を読むと「他人の気持ち」を理解しやすくなる？

    読書は、人とのつながりとも関係している。これまでの研究では、本を読むことで「他人の考え方を理解しやすくなった」「他者への共感が高まった」と感じる人が多く、異なる価値観に対してより寛容になったとする報告もある。特に小説など、人間関係や登場人物の感情が豊かに描かれた作品では、登場人物の立場や気持ちを想像しながら読み進めることになる。脳画像研究では、こうした読書中に、他人の立場や感情を理解する「社会的認知」に関係する脳領域が活性化することも示されている。つまり、本の中で誰かの人生を追体験することが、現実の人間関係にも関係している可能性がある。

    ■64歳以上を14年間追跡した結果、読書と認知機能にも関連

    年齢を重ねてからの読書にも、興味深い研究がある。台湾で行われた研究では、64歳以上の人を14年間追跡。その結果、読書をしていた人は、読書をしていない人に比べて認知機能の低下が少ない傾向がみられ、その関連は教育歴にかかわらず確認されたという。また、55歳以上の約5500人を対象とした研究では、読書を含む脳を刺激する余暇活動を頻繁に行う人ほど、5年間の追跡期間中に認知機能障害を発症する可能性が低かった。さらに別の研究では、新聞や雑誌、本を読むことが、アルツハイマー病のリスク33％低下と関連していた。

    ただし、ここは誤解のないようにしたい。これらの研究の多くは、読書習慣のある人とない人を比較したものだ。そのため、「本を読めば認知症を防げる」と証明されたわけではない。もともとの生活習慣や健康状態など、読書以外の要因が関係している可能性もある。それでも、長期間の追跡研究を含め、読書と認知機能の関連が繰り返し報告されている点は注目される。

    ■子どもの頃からの読書は、注意力やメンタルヘルスとも関係

    読書の研究は大人だけを対象にしたものではない。ケンブリッジ大学の研究者らが1万人を超える子ども・若者を対象に行った研究では、幼い頃から読書を楽しんでいた子どもは、思春期になった時点で、注意力や記憶力、実行機能が優れている傾向がみられた。さらに、学業成績が良く、メンタルヘルス上の問題が少ないほか、睡眠時間が長く、スクリーンを見る時間が短い傾向も確認されたという。脳画像でも、言語や学習、感情のコントロール、意思決定などに関係する脳領域に違いがみられた。

    では、大人はどのように読書を始めれば良いのか？「健康のために本を読まなければ」と考えて、いきなり分厚い長編小説を選ぶ必要はない。研究者も、自分が「読みたい」と思えるものを選ぶことが重要だとしている。小説でも、エッセイでも、趣味の本でも、雑誌でもいい。好きな映画やゲームに関連した作品から…

    住宅からショップ、オフィスまで、さまざまな空間でグリーンコーディネートを提案している。環境に合う植物選びに始まり、希望のイメージのデザイン、その後の維持・管理まで担う。

    シマトネリコ

    KONO KIYOSHI/アフロ 明るい色味の柔らかな葉が軽やかで、シンボルツリーとして人気の常緑樹、シマトネリコ。しかし、実は成長が非常に速く、気がつくと2階以上の高さに育ってしまい、剪定しにくくなることも。

    「見た目のさわやかな印象から庭に植える人が多い木ですが、玄関横のちょっとしたスペースや建物とフェンスの隙間などに植えると、窮屈になってしまうことがあります。限られたスペースにシマトネリコを植えた場合、1年に2回程度は剪定して高さやボリュームを抑えるメンテナンスをおすすめします。剪定とともに幹は太くなり、植えた頃の印象とは様変わりしていきます」

    オリーブ

    Ling Jin 「品種にもよりますが、オリーブもなかなか成長が速い植物です」と江田さん。例えば、オリーブの一種で人気のルッカは、1年で数10㎝は成長するとのこと。

    「華奢だったオリーブが、地植えして根付けばぐんぐんと生長し、あっという間に脚立なしでは手入れができない大きさに育ちます」

    育ちすぎると管理が大変になり、枝が横に広がって隣家や道路にはみ出したり、葉が落ちたりするトラブルを招くので、鉢植えで育てるか、定期的に剪定するようにしましょう。

    ミモザ

    Minh Hoang Cong / 500px 黄色い花を切り花としても楽しめるミモザ。こちらも成長が速く、定期的な手入れが不可欠な植物です。

    「ミモザは成長スピードが速く、長く伸びた枝が枝垂れて上部が重くなるのに対して、根の張り方が浅く弱いため、台風などで倒れやすいので注意が必要です」と江田さん。毎年、花を楽しんだ後に、伸びた枝の切り戻しや混み合った枝の間引きを行い、大きくなりすぎないようにメンテナンスしましょう。

    【CMカット】リスナー・業界・時代へ問う…公開された新CM

    今回のアルバムタイトルである『POPS』には、「既存の大衆音楽の常識を問い、すべての人と向き合う覚悟」が込められている。そんなタイトルを体現するように「みんなが聴いているから好き？」「ヒットチャートが正義？」「音楽に賞は必要？」など、ミセスだからこそ強く訴えかけることのできる34の問いに、音楽を聴く老若男女が、背を向けていたところから向き合っていく印象的なCMを公開。TVCMやSNSを中心に配信をした。

    『POPS』の歌詞や楽曲の世界、アルバムが問いかけるメッセージが広告となり、東京を中心に札幌・長野・名古屋・大阪・ 福岡の全国各所に出現。9曲の書き下ろし新曲を含む、全16曲で構成された『POPS』は、“全曲リード曲”と呼ばれるほど、強く、多様な世界やメッセージが込められている。その多様さを印象付けるべく、それぞれの曲の世界を表現した、16種のビジュアルが屋外広告として登場。色とりどりなポスターが一挙に並ぶ空間は、まるで美術館のような圧倒的な没入感を楽しめ、一目見るだけで、すべての曲が主役のアルバムであるというミセスの意気込みを伝える。

    クマ対策いろいろ 弥生いこいの広場再開へ(Web東奥)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 21:02 配信

    「弥生いこいの広場」を囲うように新設された電気柵。営業時間外は出入り口にも設置される＝第1駐車場入り口（東奥日報社） クマ出没の影響で休園が続いてきた青森県弘前市のレクリエーション施設「弥生いこいの広場」は1日、2日の営業再開を前にクマ対策を報道機関へ公開した。施設のほぼ全域を囲うように全長約2キロにわたって電気柵を張り巡らせるなどした。今季は11月8日まで営業する。オートキャンプ場は10月31日の宿泊分まで。動物広場は月曜休園（祝日除く）。

    電気柵は、積雪前の回収と再設置が容易な倒伏式を主に採用。動物広場、ピクニック広場、オートキャンプ場、第1駐車場を囲うように約1.7キロを新設した。通路沿いには、来園者が触れにくくするため樹脂マットを取り付けた。

    職員用通路や動物の餌を栽培する畑などには、簡易式の電気柵約400メートルを設置。事業費は約1400万円で一部に県の補助金を活用している。

    このほか、クマを寄せ付けないよう動物広場受付前など3カ所に来園者が自由に鳴らせるスイングベルを用意した。第1駐車場などの出入り口には専用の忌避剤を置く。職員向けのクマ対策管理運営マニュアルを整え、緊急時の避難先となる建物にはクマ撃退スプレーを配備した。

    施設は例年4月中旬から11月上旬にかけて営業しているが、昨季は周辺でクマ出没が相次いだため8月31日で営業を終了。丸1年以上の休園は1976年の開設以来初めてという。市都市計画課の小倉洋幸課長は「ハード、ソフト両面で対策したので安心して来てほしい」と話した。

    文/写真:ベストカーWeb編集部

    8速でも10速でもなく、あえて実績重視の6速AT

    ランドクルーザーFJは、最高出力163ps、最大トルク246Nmを発生する2.7L直列4気筒自然吸気ガソリンエンジンに、トルクコンバーター式の電子制御6速ATを組み合わせる。

    ランドクルーザー250のディーゼル車が8速AT、ランドクルーザー300が10速ATを採用する時代に、新型車が6速というのは少々地味だ。段数を増やせばエンジンの効率がいい回転域を使いやすくなり、加速の滑らかさや高速燃費の向上も期待できる。

    それでもFJが重視したのは、数字上の新しさではなかった。

    トヨタは2.7Lエンジンと6速ATの組み合わせについて、スムーズな走行性能と高い信頼性を備えると説明している。FJが目指すのは、舗装路だけを快適に走るSUVではない。砂漠や泥道、急坂などでも確実に動き、無事に帰ってくることが求められるランドクルーザーなのだ。

    もちろん、変速段数が少なければ必ず壊れにくいという単純な話ではない。耐久性は部品の強度や潤滑、冷却、制御などによって決まる。ただし、十分な使用実績を持つエンジンとATを組み合わせ、複雑さを必要以上に増やさない設計は、世界各地で長期間使われるクルマにとって大きな安心材料となる。

    修理設備や部品供給が充実した都市部だけでなく、整備環境が限られる地域まで想定するのがランクル流である。最新技術を詰め込むことより、長く使われてきた仕組みを磨き込む。その考え方は、20年以上の搭載実績を持つ2TR-FE型エンジンとも共通している。
