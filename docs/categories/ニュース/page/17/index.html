    李大統領はこの日、忠清南道（チュンチョンナムド）の鶏竜台（ケリョンデ）で開かれた国軍の日記念行事での演説を通じ、「南北関係の結び目は複雑に絡まっているが今後も忍耐心を持ってじわじわと絡まった結び目をほどいていくだろう」としながらこのように明らかにした。

    李大統領は「この地の平和と繁栄はだれかが代わりに作ってくれるのではなく、いままでそうしてきたように私たち自ら作り出すもの。戦って勝つことも重要だが戦わないで勝つことがより重要で、それよりさらに確実な安全保障は戦う必要がない平和を作ること」と強調した。

    その上で「南と北は韓半島（朝鮮半島）の平和に向けともに勝つ道を見つけ出し信頼を積み上げなければならない。信頼は一度の言葉では作られない。言葉と行動が一致する時に初めて少しずつ積もっていく」と話した。

    李大統領はまた、「自主国防はすなわち主権。今後戦時作戦権還収でその終止符を打ち、半世紀にわたり続いてきた自主国防のその夢を国民とともに必ず成し遂げるだろう」と明らかにした。

    李大統領はこの日の演説冒頭で、最近の非武装地帯（DMZ）の地雷爆発事故で負傷した将兵を慰労した。

    李大統領は「先ごろ非武装地帯で不慮の事故で負傷した将兵を考えればいまも心が痛む。われわれが享受するこの平凡な1日がだれかの危険の上に立っているということを改めて考えることになる。早期の回復を祈り、家族にも深い慰労の言葉を伝える」とした。

    ◇「国軍士官学校に速度…選択募兵制で技術副士官拡大」

    李大統領は「いまわれわれが向き合った安全保障環境は一寸先も見通し難い。規範より力が先になることが頻繁に起き世界各地で対立も次第に深まっている。人工知能とドローン、ロボットと宇宙、サイバー領域まで先端技術は戦争の様相自体をまるごと変えている」と診断した。

    続けて「人口の崖、それにともなう資源減少はわれわれの前に置かれたもうひとつの挑戦。変化に準備することが国民を守ることだ。このような挑戦を超える道は強力な国防改革だけ」と強調した。

    李大統領は「人工知能と有無人複合体系を高度化し、これに合わせて軍構造を改編して国防態勢全般を再設計し、スマート精鋭強軍として必ず跳躍する。ミサイル脅威を早期に探知して迎撃し、対応できる韓国型3軸体系もさらに高度化していくだろう」と明らかにした。

    また、「未来戦に備えて国軍士官学校を創設し統合作戦能力を備えた世界一流精鋭将軍を育てなければならないだろう。さまざま意見を聞き軍をひとつに集めて国軍士官学校創設推進に迅速かつ果敢にまい進することを願う」とした。

    合わせて「選択的募兵制を通じて技術集約副士官を増やし、兵力構造を幹部中心に転換する。青年は服務期間が短い兵士と含む期間が長いが就職や教育など未来設計が可能な技術集約副士官のうち望む服務方式を選択できるようにする」と話した。

    ◇「軍による違法内乱起きないよう制度定着させる」

    李大統領はこの日「国民主権政府は違法戒厳の残滓を清算してきた。残念だが軍内部の責任を厳正に問い、防諜司令部と情報司令部を含んだ軍情報機関を全面改編するなど民主的、制度的基盤を強固に強化した」と話した。

    その上で「今後も決して、断じて軍による不法内乱が発生しないよう軍が本来の任務にだけ専念できる環境と制度を定着させていくだろう」と付け加えた。

    「Oracle JDK 21」は無償の「NFTC」ライセンスの対象外に、10月「CPU」以降で(窓の杜)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 17:51 配信

    写真：窓の杜（株式会社インプレス） 米Oracleが提供している「Oracle JDK 21」のライセンスが、10月より変更される予定。10月20日に予定されているセキュリティアップデート「Critical Patch Update」（CPU）以降、「Oracle JDK 21」のアップデートは無償の「Oracle No-Fee Terms and Conditions」（NFTC）ではなく、「Java SE OTN」ライセンスで提供される。

    同社は「Oracle JDK 17」より、最新のJavaリリースを許容的な「NFTC」ライセンスで無償提供している。ただし、旧バージョンの更新プログラムは「Java SE OTN」ライセンスでの提供となるのが原則だ。

    このライセンス変更の影響を緩和するため、現行のLTS（長期サポート）版が登場してからの1年間は、直前のLTS版も「NFTC」で提供する“重複期間”が設けられる。しかし、2025年9月の「Oracle JDK 25」（LTS）のリリースから1年が経過し、直前のLTS版である「Oracle JDK 21」の“重複期間”が終了する。今後は「Java SE OTN」ライセンスでの提供となる。

    「Java SE OTN」ライセンスは、個人利用や開発目的の利用であれば無料。一方、商用本番環境でアップデートを利用するには、「Oracle Java SE Universal Subscription」などの購入が必要となる（OCIやOracle製品の一部として提供されている場合などを除く）。同サブスクリプションでは、「Java 21」の商用サポートが少なくとも2031年9月まで提供される。

    つまり、「Oracle JDK」を「NFTC」の下、本番環境で無償利用したいのであれば、「Oracle JDK 25」へ移行する必要がある。「Oracle JDK 25」の更新は、次のLTS版として現在予定されている「Java 29」の1年後にあたる2028年10月まで、「NFTC」で提供される予定。

    なお、「GraalVM for JDK 21」の更新も10月のCPUからは「GraalVM OTN License Including License for Early Adopter Versions」での提供となる。「GraalVM」ユーザーには「Oracle JDK」または「Oracle OpenJDK」への移行が推奨されている。

    窓の杜,樽井 秀人

    4K/75HzもフルHD/300Hzも1台で。アイオーの27型ゲーミングモニター(PC Watch)

    2026年10月1日 カテゴリー ニュース

    10/1(木) 17:48 配信

    写真：PC Watch（株式会社インプレス） 4Kの高精細とフルHDの高速リフレッシュレートを1台で使い分けられる。アイオーデータは10月1日、4K(3,840×2,160ドット)/75HzとフルHD(1,920×1,080ドット)/300Hzを切り替えられる27型ゲーミングモニター「GCFX」の「GDU271AD」シリーズを発表した。11月上旬に発売し、価格はオープンプライス。本体色はブラックとホワイトの2色を用意する。

    【画像】GDU271AD(ブラック)

    GDU271ADシリーズは、4K/75HzとフルHD/300Hzを切り替えられる「Dual Frame Rate(DFR)」機能を搭載するのが特徴。MMORPGなどでは高精細な4K表示、FPSなどでは300Hzの高速表示のように用途に合わせて切り替え可能。また、フルHD/300Hz時の内部フレーム遅延は約0.04フレーム(約0.12ms)とうたわれている。

    このほか、暗部を鮮明にする機能や色彩強調機能といったゲーム向け機能、ブルーライト低減のローブルーモードなども備える。スタンドは奥行きを抑えた超薄型台座で、キーボードやノートPCを下に収納できる。

    販路に応じて「EX-GDU271AD」、「KH-GDU271AD」、「HT-GDU271AD」の3シリーズに分かれるが、仕様は共通。パネルが非光沢AHVA、解像度が4K、表示色数が10億7,374万色(10bit入力時)、中間色応答速度が最短0.5ms。輝度が300cd/平方m、コントラスト比が1,200:1、視野角が上下/左右ともに178度。フルHD表示時は可変リフレッシュレート(VRR)もサポートする。

    インターフェイスはHDMI、DisplayPort、3.5mm音声出力。スタンドは-5～20度のチルトに対応。本体サイズは約614×173×444mm、重量は約4kg。

    また同日、15.6型フルHDモバイルモニター「LCD-YC164HX」シリーズと、これにスピーカーを搭載した「LCD-YC165HX」も発表した。LCD-YC164HXシリーズはブラックとホワイトの2色で10月下旬発売、LCD-YC165HXはブラックのみで11月中旬発売。いずれも価格はオープンプライス。

    USB Type-C接続なら映像出力と給電をケーブル1本でまかなえるほか、HDMIも備える。USB PDパススルーに対応。スタンドは本体一体型で、無段階で角度を調節可能。従来品より薄く軽いキャリングケースが付属する。

    主な仕様は、パネルが非光沢IPS(FFS)、解像度がフルHD、最大表示色が1,677万色、中間色応答速度が5ms、輝度が300cd/平方m、コントラスト比が1,000:1、視野角が上下/左右ともに178度。

    インターフェイスはHDMI、USB Type-C(DisplayPort Alt Mode) 2基(下側はファームウェアアップデートにも対応)。本体サイズはスタンド折りたたみ時で約359×16×226mm、重量はLCD-YC164HXシリーズが約790g、LCD-YC165HXが約800g。

    Argonは、ソフトウェア開発や法務、財務といった企業の知識労働、サイバーセキュリティの複雑な作業を想定する。ただし、当面は誰でも利用できるモデルではない。まずは「Fairwind Program」を通じ、Googleが「信頼できる」とするサイバーセキュリティ担当者に順次提供する。一般向けの公開時期は明らかにしていない。

    Fairwind Programは、同社が9月にサイバーセキュリティ特化の「Gemini 3.8 Flash Cyber」とともに設けた枠組みで、政府機関や重要インフラ事業者などにアクセスを提供する。一部のセキュリティ担当者とGoogle社内チームには、サイバー分野のガードレールを外したArgonも提供する。

    段階的に公開するのは、フロンティア級の能力を安全に提供するためだという。初期利用者からのフィードバックをもとに安全対策を改良し、将来的には開発者や企業、一般利用者にも広げる。本格公開後は、有料APIの利用者や「Google AI Ultra」の加入者への提供を想定する。導入価格は入力100万トークンあたり2ドル、出力100万トークンあたり10ドルで、キャッシュ済み入力は95％引きとなる。

    サイバーセキュリティでは、ソフトウェアの脆弱性を自律的に見つけ、検証し、修正パッチを作るところまでこなせるという。セキュリティ企業のWizは、病院で使われる医療用ソフトウェアから個人情報が漏れる重大な脆弱性をArgonで発見したとしている。脆弱性の修正能力を測る「CWE-bench v1」では、GPT-6 Astraと並ぶ68％だった。

    最大100万トークンを出力、Google社内でも活用

    仕様面では、1回に出力できるトークン数の上限を従来の6万4000トークンから100万トークンへ大幅に拡大した。数十万トークンを生成しながら長時間の推論を続けられるため、複雑なソフトウェア開発などに向くとしている。

    Google社内では、すでに数千人がArgonを利用している。量子コンピューターの研究では、ある処理の「時空間リソース」を従来の基準値から40％改善したほか、データセンターではArgonを使ったエージェントがメモリーの最適化方法を見つけ、300TiB以上を解放したという。C/C++で書かれたコードをRustに移植する作業にも利用し、数万行規模のライブラリから80万行を超えるFuchsiaのZirconカーネルまで対象を広げている。

    推論過程を監視、安全対策も強化

    安全面では、サイバー攻撃や化学・生物・放射性物質・核（CBRN）分野への悪用防止、プロンプトインジェクション対策、意図から外れた動きの監視、システムの堅牢化を進めている。Argonの思考過程と行動を監視し、利用者の意図から外れれば実行を止める仕組みも導入した。

    Googleは、この監視結果をあえてArgonの学習には使わなかったとしている。監視内容を学習させることで、モデル側が監視をすり抜ける方法を学ぶ可能性があるためだ。同社は、AIの推論過程を監視できる状態を維持することが重要だとしている。

    私たちは「言葉の歴史」の一部

    Photo： Getty Images（COURRiER Japon） 英単語を覚えても、すぐに忘れてしまう。外国語を学んだことのある人なら、誰もが一度は経験する悩みだろう。そんなとき、単語の「生い立ち」をたどってみると、ばらばらだった言葉が意外なところでつながり、ぐっと覚えやすくなる。

    【画像】言語学者が教える「記憶に残る語彙の覚え方」

    英オンラインメディア「サイキ」に寄稿した言語学者ダニー・ベイトは、単語の由来をたどる語源学の魅力を説く。

    ベイトは、同メディアの記事で、単語の来歴を探る「言葉の探偵」になることを勧めている。英語の語彙にはローマ人やヴァイキング、ギリシャの学者たち、1066年にイングランドを征服したノルマン人など、さまざまな人々の足跡が残っている。

    たとえば、「余波」を意味する「aftermath」は数学とは関係がなく、もとは「刈り取りの後」を指した。タンポポを意味する「dandelion」は、フランス語の「ライオンの歯」に由来する。

    こうした発見は雑学として楽しいだけではない。私たちが使う言葉は、親や教師など誰かから教わったものであり、その人たちもまた別の誰かから受け継いできた。一人ひとりが、何千年も続く言葉の鎖の一部なのだ。遠く離れた人々が言葉でつながってきたと知ることは、謙虚さや他者への敬意を育むとベイトは言う。

    語根を知れば、単語は覚えやすくなる

    語源学は、語彙の学び方も変える。ベイトが勧めるのは、単語を部品に「分解」することだ。たとえば、「subscriber（購読者）」から接頭辞のsub-と接尾辞の-erを取り除くと、ラテン語で「書く」を意味する語根scrib-が現れる。同じ語根は、「describe（描写する）」や「script（台本）」にも含まれている。ばらばらに見えた単語が、共通の部品で結びつくのだ。

    ラテン語で「父」を意味する「pater」も同様だ。「paternal（父親の）」や「patriot（愛国者）」の語根であると同時に、ラテン語より古い先史時代の語根にさかのぼり、英語の「father」にも直接つながっている。英語へと受け継がれる長い道のりのなかで、語頭のPがFに変わったのだとベイトは説明する。

    この学び方の効果は、研究でも確かめられている。イランのアラク大学による2012年の研究では、大学生59人を2つのグループに分け、6週間にわたって英単語を学ばせた。ラテン語やギリシャ語の語根をもとに学んだグループは、辞書や文脈からの推測で学んだグループよりも、事後テストの成績が高かった。

    語根で学んだ学生の約7割は「単語をよく覚えられた」と答え、約8割が3週間後も楽に思い出せたと回答している。

    慣用句でも似た傾向が報告されている。応用言語学者フランク・ボアーズらの研究によれば、慣用句がもともと使われていた具体的な場面を知ると、その情景のイメージが言葉と一緒に記憶される。その結果、思い出すための手がかりが増えるという。
