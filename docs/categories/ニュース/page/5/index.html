    【寺西拓人】

    このたびは猪俣を行った行為によって、多くの方々にご心配、ご迷惑をおかけいたしましたことを心よりおわび申し上げます。本当に申し訳ございませんでした。

    関西テレビ放送（関西テレビ） 兵庫県尼崎市で去年8月、妻の遺体を切断し川に遺棄した疑いで46歳の医師の男が逮捕されました。

    男は去年9月に警察に妻の行方不明届を提出。しかし、そのおよそ1年後には、男の供述に基づいて妻の骨が川から見つかることになります。

    いつ“行方不明者の夫”から“容疑者”に変わったのか。

    元刑事部長が警察の捜査を分析し今後のポイント捜査のポイントについて解説しました。

    ■事件の経緯 “行方不明届”から逮捕までの約1年に何が

    死体損壊および死体遺棄の疑いで逮捕されたのは、精神科医の下村憲司容疑者（46）です。

    去年8月、自宅で妻（当時41歳）の遺体を刃物で切断し、尼崎市内の川に遺棄した疑いがもたれています。

    そのひと月後の去年9月、下村容疑者は警察に対して「妻の行方不明届」を提出しました。その際、「8月に妻と口論になり、妻が出て行った。その後、連絡がない」と相談していたということです。

    そして下村容疑者の供述に基づいて捜査員が現場を確認したところ、川から妻とみられる骨が発見されました。

    これを受け、9月30日、下村容疑者の逮捕に至ったということです。

    ■逮捕に至った捜査のポイント 下村容疑者の届け出内容と“生存の証”

    「喧嘩したからいなくなった」その一方で…（関西テレビ） 元兵庫県警 刑事部長の棚瀬誠氏は、警察が着目するポイントを解説します。

    【棚瀬誠氏】「容疑者の供述、すなわち『喧嘩したから奥さんがいなくなった』、これを前提にするのであれば、その奥さんからすると、夫から離れたいということだけですから、実生活が伴うはずです。

    ですから、夫が知らない場所で実生活を営むのであれば、携帯電話の使用状況やクレジットカードを使っている、いわば“生存の証”というのがすぐ取れるわけですが、そうじゃないんだとすると（“生存の証”がとれないとすると）、まず怪しいと。

    そもそも行方不明届というのが本当なのかどうかという着想に至ると思います」

    ■警察が“着目”は届出を出した夫側の行動にも

    棚瀬氏はさらに、警察は届出を出した夫側の行動にも着目すると指摘しました。

    【棚瀬誠氏】「行方不明届を警察に提出するとなった際には、その前に、例えば家族の周り、奥様の立ち回り先などを様々探した上で、帰ってこない、あるいはどこにもいないから“行方不明届”という文脈になる。

    しかし、その探すような作業をしていなかったとすると『なんで探してないんだ』、『突然なんで行方不明なんだ』という話でピンとくるということは考えられると思います」

    つまり、もし妻が本当に家出をしたのであれば、夫として懸命に妻を探す行動が先に来るはずです」

    行方不明者の“実生活”、届け出た人物の行動の有無を慎重に見たうえで、下村容疑者が早い段階で“容疑者”となった可能性があると分析します。

    なぜ秋に抜け毛が増えるのか、そしてこの時期にやってはいけないNGケアと正しい対策について、美容室「Grace Avenue」（東京都港区）サロンマネジャーで美容師の原木佳祐さんに聞きました。

    「夏の蓄積ダメージ」が原因で抜け毛に

    Q.なぜ9月、10月は1年の中で最も抜け毛が増える時期と言われているのでしょうか。

    原木さん「季節の変わり目によるホルモンバランスの乱れに加え、7月、8月に受けた『夏の紫外線ダメージ』が、数カ月遅れて一気に現れるからです。

    夏の強烈な紫外線によって毛根がダメージを受けると、本来ならそのまま成長を続けるはずだった髪の毛が、成長をやめて『休止期』に入ってしまいます。休止期に入った髪はすぐに抜けるわけではなく、数週間から数カ月かけて徐々に抜け落ちていきます。

    つまり、『夏の間はそんなに抜けなかったから大丈夫』と思っていても、毛根が受けたダメージは確実に蓄積されており、そのタイムラグとして9月、10月に『遅れてやってくる抜け毛』となって現れるのです」

    美容室や自宅でやってはいけない「NG行動」とは？

    Q.抜け毛が気になる時期に、美容室でのカラー・パーマや、自宅でのスカルプケアで「絶対にやってはいけないNG行動」はありますか。

    原木さん「美容室では『頭皮に負担のかかる施術』、自宅では『熱いお湯と摩擦』が絶対NGです。夏のダメージを引きずった9月・10月の頭皮は非常にデリケートになっているため、以下のような行動は追い打ちをかけてしまいます。

    【美容室でのNG】

    ・頭皮に負担のかかる薬剤・施術

    ブリーチ、ダブルカラー、頭皮にベタ塗りする白髪染めなどは毛根に負担をかけます。また、縮毛矯正や強めのパーマなど、髪を強く引っ張る施術も要注意です。

    ・強すぎるヘッドスパ

    頭皮が傷んだり炎症を起こしたりしている状態での力強いマッサージは、かえって負担になります。

    【自宅でのNG】

    ・42度以上の熱いお湯で洗う

    頭皮の必要な皮脂まで奪い、深刻な乾燥を招きます。

    ・爪を立てたゴシゴシ洗い・強いブラッシング

    弱った頭皮を傷つけてしまいます。

    強く結ぶポニーテールやヘアアレンジも、抜け毛が気になる場合は少し控えた方がいいでしょう。

    ■2日（金）は東京で朝の雨に備えを 北日本は強風に注意・警戒

    気象庁の1日午後5時発表の予報では、東京地方は2日（金）、曇りで朝から昼前に雨が降る見込みです。通勤・通学の時間帯に重なるため、出発前に雨の予報を確認してください。

    北海道では、発達する低気圧の西側から上空に冷たい空気が流れ込み、大気の状態が非常に不安定となる見込みです。2日は落雷や突風、ひょう、急な強い雨に注意し、局地的には竜巻などの激しい突風にも注意してください。

    北日本では2日、非常に強い風が吹く所がある見込みです。強風に注意・警戒し、3日（土）にかけて高波にも注意してください。

    雨風シミュレーションでは、2日正午に北海道や東北の日本海側、関東南部などに雨域が見られます。

    一方、2日は名古屋や大阪、広島、福岡などで晴れる予報です。沖縄では2日にかけて、落雷や突風、急な強い雨に注意してください。

    ■3日（土）は晴れる所も 4日（日）は福岡・広島で雨予想

    3日（土）は、東京や名古屋、大阪、広島、福岡などで晴れる予報です。札幌や新潟でも晴れ間が出る見込みです。

    ただ、北日本では3日にかけて強風や高波に注意が必要です。東日本から西日本の太平洋側でも、3日は波が高くなる所があるため、海沿いのレジャーは波の予報も確認してください。

    4日（日）から5日（月）にかけては、高気圧が日本の東へ離れ、低気圧が朝鮮半島付近から日本海へ進む見込みです。西日本には前線が延びる予想です。

    雨風シミュレーションでは、4日朝は四国の太平洋側などに雨域が見られ、夕方から夜にかけて中国地方や九州の一部にも雨域がかかる予測となっています。

    各地の予報では、4日は福岡や広島で雨、大阪は曇りの見込みです。西日本で日曜日に外出する方は、帰る時間帯も含めて雨の予報を確認してください。

    「ひとえの着物」着物プロデューサーや裏千家正教授…着物愛好家の着こなしのコツは？10月まで楽しむためのポイントも(婦人画報)

    10/1(木) 21:10 配信

    それぞれ立場の違うの着物巧者に、近年の気候やライフスタイルを踏まえ、“私流”ひとえの着こなしのコツを伺いました。

    松嶋菜々子さん、藤原紀香さん、高島礼子さん…美しすぎる【女優さんの着物コーデ集】

    勝山さと子さん（着物プロデューサー）

    Satoko Katsuyama ■ひとえの素材感や透け感、帯合わせを意識し、場に応じた装いを心掛けています

    京都・西陣の機屋に生まれ、現在は自身のブランドを立ち上げ、着物や帯の制作を行っている勝山さと子さん。「2月の展示会にひとえの発表があるため、昨年はその頃からひとえを着て、秋は10月いっぱい楽しみました」

    先取りひとえを着用する場合は、「帯合わせや小物には季節感を意識し、全体の印象が先走り過ぎないように心掛けています」

    作り手としては、今の時代の気候や暮らしに合ったひとえ用着尺を提案されています。「素材の開発、糸選び、精練を工夫し、例えば一般的に緯糸に使う糸を経糸に用いたりして快適な素材を研究しています。軽やかな『春ひとえ』、涼やかな『ひとえ』、生地に落ち着き感や、深みのある表情を重視した『秋ひとえ』とひとえを細分化し、それぞれの時季に適した作品を制作しています」

    北見雅子さん（裏千家正教授）

    Masako Kitami ■お稽古では5月の連休後から容認される傾向に。無理のない範囲でルールを守ればいいと思います

    衣替えに厳格といわれる茶道の世界でも、昨今の気候などにより少し緩和傾向にあるという見解の北見雅子さん。「最近では5月の大型連休後のお稽古は、ひとえが大活躍です。秋も、9月中旬から10月中旬まで着用しました。この時季に歴代宗匠の恩忌の茶会があるのですが、こうした正式な茶事・茶会には昔ながらの時季の装いを守ります」

    コーディネートに参考しているのは、季節のお菓子の色目だとか。

    「例えば、5月なら新緑や水色の帯にして、薄紫を帯〆や帯あげに使ったり、秋には実りの色や温かみなどお菓子の色を意識します」

    また、暑さばかりに目が向きがちですが寒さ対策も必要だとも。

    「空調により寒く感じる場面も多く、新幹線やクーラーの効いた場所に長くいるときは大判スト―ルやアームウォーマーが必携です」
