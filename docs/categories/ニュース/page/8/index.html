    その「HIIT動画」、本来のHIITとは別物です。脂肪燃焼・筋肉・体力、目的別に選び直すヒント（ライフハッカー・ジャパン編集部） 2010年代に話題を呼んだ「高強度インターバルトレーニング」、通称「HIIT（ヒット）」。

    短時間のハードな運動で、長時間のジョギングやサイクリングと同じ有酸素運動の効果が得られる、という強みが注目されました。しかし、現在ストリーミング再生できるHIIT動画の多くは、本来の形とはかなり違っていて、時間をかける意味があまりないものが少なくありません。

    具体的な違いについてお話しする前に、1つだけはっきりさせておきたいことがあります。もし、「HIIT」と書かれた動画を見るのが好きで、それが心から楽しいと思える運動習慣の一部になっているなら、ぜひそのまま続けてください。好きなことを奪うつもりはまったくありません。

    ただ、それが目標を達成するためのベストな方法だと感じていたり、トレーナーやインフルエンサーの「カロリーを大量に消費する」「理想のスタイルになれる」といった言葉を信じてやっていたりするのなら、少し立ち止まって見直してみるのも手です。

    本来の「HIIT」とはどんなもの？

    「高強度インターバルトレーニング」という言葉は、運動科学者たちが無酸素運動能力の測定テスト「ウィンゲートテスト」を繰り返すたび、人々の成績が向上することに気づいたことから広まりました。

    ウィンゲートテストのやり方は、固定されたエアロバイクのペダルを重くして、吐き気をもよおすほど全力で30秒間こぐ、というもの。その後4分間休んで、また同じことを繰り返します。

    さらに実験を重ねた結果、研究者たちは、有酸素運動の能力向上などに見られるメリットが、他の「休息と運動」の組み合わせでも引き出せることを発見。たとえば「タバタ式トレーニング」もその1つです。こちらも研究用のエアロバイクを使い、20秒の運動と10秒の休息をセットにして、限界に達するまで「7〜8回」繰り返します。時間にして合計4分ほどです。

    これらは、決して遊び感覚でできる運動ではありません。実際に体験した人の話を思い返しても、誰もが「ただただ苦痛だった」と口を揃えます。科学者たちもよく指摘していますが、このやり方を自分1人で再現できるほど、自分を限界まで追い込める人はめったにいないのです。

    すべての学科で4年次まで少人数ゼミを必修とし、スタディスキルから卒業研究まで、ゼミでの学修を通して主体的に学ぶ力を養っている沖縄大学。東京大学や京都大学など、「都道府県名」＋「大学」という名称の国立大学が多いことも、国立大学のような印象につながったのではないでしょうか。なお、沖縄県に本部を置く国立大学には、琉球大学があります。

    ●第2位：神奈川大学

    同率第2位の2校目は、「神奈川大学」でした。神奈川県横浜市神奈川区に本部を置く神奈川大学は、1928年に創立された「横浜学院」を前身とし、学制改革により1949年に設置された私立大学です。「質実剛健・積極進取・中正堅実」を建学の精神としています。

    11学部を有する総合大学で、横浜キャンパスに「理学部」「工学部」「建築学部」「化学生命学部」「情報学部」の理工系5学部を集結させている神奈川大学。こちらも「県名」＋「大学」という組み合わせが、国立大学のような印象を抱かせるのかもしれません。なお、神奈川県に本部を置く国立大学には、横浜国立大学や総合研究大学院大学などがあります。
