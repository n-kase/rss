    先月30日、子どもたちが通学する時間に合わせて、安全な道路の渡り方などを呼び掛ける「全国一斉街頭指導」が行われました。

    長野県松本･里山辺の落石 風化･浸食が原因 県が報告書まとめる 対策で防護柵設置へ(市民タイムスWEB)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 9:35 配信

    落石現場を調査する県職員ら（県森林づくり推進課提供）（株式会社市民タイムス） 県は30日、長野県松本市里山辺で5月に発生した、巨石の落石災害の報告書をまとめた。現場は松くい虫被害などで岩肌がむき出しになった場所で、落石の原因は長年の風雨で軟らかい泥岩が風化・浸食され、残った硬い岩が浮き石化したことだと結論付けた。県は令和6年度に枯損木を整理する治山事業を行っていたが、落石を誘発した作業は確認されなかったとした。

    落石は5月7日に発生し、最大約11トンの巨石3個が斜面を転がり落ち、民家の車庫や市道に被害が出た。県は8月から斜面にある不安定な岩を固定する対策を進めている。

    恒久対策として来年度以降、防護柵の設置も計画する。松枯れ被害に対しては、植樹を行わず自然に広葉樹などが生えて回復する「天然更新」で森林を再生したい考えだ。

    今回の落石を受け、県は森林整備などの治山事業を行う際、計画段階で落石のリスクを確認する仕組みを、来年度事業分から導入する。周辺に人家や道路がある場合、落石の危険性と対策の実施可能性を確認し、事業を行うかどうか判断する。

    県森林づくり推進課は「県内ではこれまで治山事業の現場での落石事例があまりなかった。今回を契機に、そのリスクを計画段階から認識して対策していきたい」としている。

    株式会社市民タイムス

    10/1(木) 9:33 配信

    7 コメント 7 件

    フェリペ6世（ABEMA TIMES） スペインの飛び地セウタでモロッコから大量の不法移民が押し寄せた問題をめぐり、スペイン国王のフェリペ6世は「EU全体に責任がある」として支援を訴えました。

    【映像】「EU全体に責任がある」としたフェリペ6世

    セウタには7月末、モロッコから7万人以上の不法移民が流入し現在も1万人ほどが、仮設シェルターや路上などで生活しています。

    スペインの国王フェリペ6世は29日、フランスのマクロン大統領を迎えた晩餐会で、不法移民問題の対応は本来、EU全体が責任を負うべきだと主張しました。

    その上で、「EUの外郭国境にあたる国だけが単独で責任を負うのは不可能だ」と述べ支援を訴えました。

    この問題をめぐってはイタリアが一時的にスペインとの国境でシェンゲン協定を停止して国境検査を再開するなど、加盟国の間で分断が表面化しています。

    スペイン政府は不法移民の送還手続きを迅速化するため亡命ルールの変更を模索していますが、NGOや人権派弁護士から「人権条約に違反する懸念がある」と批判が上がっています。

    こうした事態を受け、EUは29日、国境警備を担う機関「フロンテックス」の権限を強め、不法移民が殺到するなど緊急時に現地へ警備隊をすぐに派遣できるよう「常設部隊」を設ける計画を発表しています。（ANNニュース）

    MBS藤林温子アナウンサー（2025年9月撮影）（Nikkan Sports News.） MBSラジオ「ヤマヒロのぴかッとモーニング」で木曜パートナーの藤林温子アナウンサー（33）が1日、前日に結婚を発表した読売テレビ諸國沙代子アナの結婚を祝福した。藤林アナと諸國アナは、ともに2015年の同期入社で、局の垣根を越えて交流があった。

    【写真】結婚を発表したYTV諸國沙代子アナ

    藤林アナが「おめでとうございます。でも、お互いにプロソロになろうって、言ってたんですけど」と明かすと、メーンパーソナリティーの山本浩之（64）は「プロソロって何？」と疑問。「ひとりで何でもやっていく人です。そう言うと、諸國さんは『藤林さんは一度（結婚の）経験があるからいいけど、私はイヤだ』と返されました」と藤林アナは笑って説明した。

    諸國アナのお相手についてもふれ「さわやかイケメンなんですよ。いっしょに甲子園観戦に行って、諸國さんが（夫を）阪神タイガースファンに育てあげたんです。『周囲に騒がれるでしょ？』と言うと『バレてもいいの！』と答えてました。私はプロソロを貫きますから」と、藤林アナは宣言していた。
