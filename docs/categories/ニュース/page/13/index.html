    レクサス『LX』改良モデル向け「F SPORT PARTS」発売、全ボディカラー向け塗装品を用意(レスポンス)

    2026年10月1日 カテゴリー ニュース

    （写真：レスポンス）（レスポンス） トヨタカスタマイジング＆ディベロップメントは、レクサス『LX』の一部改良・追加にあわせ、レクサスブランド向けスポーツパーツ「F SPORT PARTS」を発売した。

    【画像】レクサス『LX』改良モデル向け「F SPORT PARTS」

    今回設定されたF SPORT PARTSは、空力性能のトータルバランスを高めるエアロパーツを中心に構成されている。一体感のある造形によりLXが持つ力強さを強調し、LXにふさわしいスタイリングを実現している。

    フロントバンパースポイラー、サイドステップ、リヤバンパースポイラーを組み合わせることで、車両のワイドで力強いスタンスをさらに際立たせる。さらにアウターミラーカバーとウィングレットを組み合わせることで空気を整流し、走行安定性と操縦の楽しさを両立している。

    車両に設定のある全ボディカラーに対して塗装済み用品が用意されている点も特徴だ。

    10月1日より順次販売を開始、全国のレクサス販売店で購入できる。車両登録後の取付を前提としている。

    保証期間はパーツを車両に装着した日から3年間。ただし、その期間内でも走行距離が6万km以内であることが条件となる。

    詳細はTRDカタログサイトのレクサスLX用ページで確認することができる。

    【全画像をみる】令和8年、キティちゃん「探す」対応化を果たす

    そんなキティさんこと「ハローキティ」の新たなコラボ先は、「スマートタグ」でした。

    そう、キティちゃんを頼りに荷物の場所を探せるのです。

    スマートタグにサンリオキャラたちの専用カバーが付属

    こちらはグリーンハウスから登場した忘れ物防止スマートタグ「GH-SMTD」シリーズ。

    忘れ物防止タグ本体は、一番左にある丸いボタンみたいなやつで、そこに、「ハローキティ」「クロミ」「シナモロール」「マイメロディ」の専用カバーが付属します。

    カラビナフックも付いているので、推しキャラを鍵やバッグなどにチャーム的に取り付けて持ち運べるってわけですね。いいじゃん！

    アクセサリーとして可愛いのは言わずもがな（クロミさま可愛いですね）。

    Appleの「探す」ネットワークに対応しているので、iPhoneやiPad、Macの「探す」アプリから持ち物の場所を突き止めることができます。

    電池交換式（CR2032）なので、バッテリーが切れたらそこまでよ…じゃないのもいいのでは？

    忘れ物防止タグは「隠す」から「見せる」時代へ

    そういえばAirTagが出た時って、自転車のベルに隠したり、子どもの靴に仕込んだりと、「どうやって隠すか？」「どうすれば目立たないか？」みたいなところばかり注目されていた気がします。

    防犯上そっちの方が良いシーンもありますが、こうしたデザイン押しで、ワンポイントとして楽しむようなアイテムまで出てくるってことは、「置き忘れを防げる」「突き止められる」というユーザーが感じる安心感や結果が、より広く浸透してきたのでしょうね。

    忘れ物防止タグ、もうすっかり身近で当たり前なモノになってるんだなぁ。

    アイオーデータ、4K/75HzとFHD/300Hzとの切り替えに対応した27型4Kゲーミングモニター(PHILE WEB)

    2026年10月1日 カテゴリー ニュース

    本文

    10/1(木) 19:29 配信

    （写真：PHILE WEB）（PHILE WEB 編集部） アイオーデータは、ゲーミングブランドの “GigaCrystaシリーズ” の思想を踏襲した“GCFXシリーズ”より、27型ゲーミングモニター「 EX-GDU271AD」を11月上旬に発売する。価格はオープンだが、Amazonの予約注文価格は32,980円。ブラック（EX-GDU271ADB）とホワイト（EX-GDU271ADW）の２色を展開する。

    ゲームサポートの機能も

    なお販路により型番先頭の2文字が異なり、ECサイト向けが「EX」、特定販路向けが「KH」、家電量販店向けが「HT」を冠して展開する。

    「速さだけを追求して、ラグを脱ぎ捨てろ」をコンセプトに、ゲームジャンルに合わせて4KとFHDの表示切り換えに対応した27型ゲーミングモニター。FPSやMMORPGなど幅広いジャンルのゲームで、速さと高精細を使い分けたい方におすすめだと同社は説明している。

    4K/75HzとFHD/300Hzを切り換えられるDFR（Dual Frame Rate）機能を搭載。4KパネルをフルHDに切り換えることによって、4つのピクセルを1つとして表示し、リフレッシュレートを4倍にできるという。

    可変リフレッシュレート技術である「Adaptive-Sync」を搭載。対応機器をDisplayPortで繋いだ際に最大300Hzをサポートし、ティアリングやスタッタリングを抑えて快適にゲームをプレイできる。

    また、HDMI 2.1規格のVRR機能にも対応した。ゲームプレイ中のフレームレートの変化に合わせてモニターのリフレッシュレートを同期させることで、スムーズな映像表示を実現するとしている。

    パネルには上下左右178度の広視野角なAHVAパネルを採用。これにより、見る位置や角度による色やコントラストの変化が少ないよう配慮した。どこから見ても映像をくっきりと鮮やかに映し出すと同社は案内している。ディスプレイ自体でブルーライトを低減させる「ローブルーモード」も備える。

    応答速度を切り替える「ダイナミックOD」機能を搭載。レベル3に設定することで、最大0.5ms（GTG）まで高めることが可能だ。超解像機能を有効にしていても内部遅延時間が約0.04フレームと少なく、操作と表示のズレを抑えるという。

    また、HDR10に対応。白飛びしてしまいがちな明るい部分や、黒つぶれしやすかった暗部の色合いも再現され、より広い色表現を楽しめるとしている。

    暗いシーンを鮮明に表示する機能や、映像にメリハリを加える色彩強調機能など、ゲーム向け専用機能を搭載。コンテンツに応じた映像表示が簡単にできる「画面モード」も備えている。

    デザイン面では、パネルとフレームによる段差がない3辺フラットなフレームレスパネルを採用。スタンドには、ノートPCやキーボードを安定して収納できる超薄型台座を採用している。壁際までぴったり設置できる直角デザインにより、限られたスペースでもすっきり収まるとアピールしている。

    端子群はHDMIとDisplayPortをそれぞれ1系統、オーディオジャックを1系統搭載。購入後1か月以内であれば、輝点が1つでもあった場合に交換できる「無輝点保証」にも対応する。

    外形寸法（スタンドあり）は約614×173×444mmで、質量は約4.0kg。VESAマウント（100×100mm）に対応し、別売のアーム「DA-ARMS5シリーズ」などを使用できる。

    ボディには「全崑崙玄武アーキテクチャ」を採用した（崑崙は中国古代の伝説上の山岳の名称）。本体のガラスにはすべて同社の強化ガラス「崑崙ガラス」を使い、カメラレンズ部分には新たに「光学崑崙ガラス」を採用。これに「玄武」と呼ぶボディ構造や高耐久素材「錦繊」を組み合わせて耐衝撃性を高めた。

    同社によると、Mate 80 Proと比べて本体の耐落下性能は50％、レンズは20倍向上したという。防水・防塵性能は、水深6mで30分間の耐水性能を持つIP68と、高温・高圧の噴流水に耐えるIP69に対応する。ディスプレイは第2世代の「霊瓏屏」で、ピーク輝度は1万2000ニト。直射日光下でも見やすいとしている。

    カメラは、色を忠実に再現する「第3世代紅楓原色カメラ」と、撮影時に構図や集合写真のポーズを提案するAI機能「XMAGE智拍」を備える。Mate 90 Pro Maxは、大型センサーを採用した2億画素の望遠カメラや、18EVのダイナミックレンジに対応するメインカメラを搭載する。別売の外付けカメラモジュール「睿影 Z10」（5999元）も発表した。1インチセンサーと24～240mm相当の10倍光学ズームレンズを備え、Mate 90 Pro Max 典蔵版やMate 90 RS ULTIMATE DESIGNに装着して撮影機能を拡張できる。

    通信面では、同社が「5A」と謳う高速通信や、Wi-Fiとセルラーのアンテナを統合した構造を採用した。最大4台の端末が互いの通信を補い合って通信速度を高める機能や、画像も送れる「北斗衛星メッセージ」（中国本土のみ）にも対応する。Pro Maxは物理SIMとeSIMを組み合わせて最大4回線を登録でき、うち3回線の同時待ち受けが可能だ。

    バッテリー容量は、Mate 90 Proが6600mAh、Mate 90 Pro Maxが6800mAh。いずれも最大100Wの有線充電と、最大50Wのワイヤレス充電に対応する。
